## 今日高危漏洞

### 1. CVE-2026-20501 — Android vdec 堆缓冲区溢出（本地提权）

vdec（视频解码器）组件存在堆缓冲区溢出导致的越界写入漏洞。攻击者可在受限进程中利用此漏洞实现本地权限提升，获取更高系统权限。该漏洞影响 Android 内核层的视频解码子系统。

- **CVSS**：8.4
- **影响组件**：Android vdec 视频解码子系统
- **与当前栈关联**：无直接关联。多乐士 CMS 技术栈为 Java/Spring Boot/MySQL/Nginx/Node.js，不涉及 Android 平台。

### 2. CVE-2026-20502 — Android vdec 越界写入（缺少边界检查）

同样是 vdec 组件，因缺少边界检查导致越界写入。与 CVE-2026-20501 属于同一子系统不同路径的漏洞，可导致本地权限提升。这两个漏洞可能被串联利用。

- **CVSS**：8.4
- **影响组件**：Android vdec 视频解码子系统
- **与当前栈关联**：无直接关联。

### 3. CVE-2026-86313 — Samsung Walrus 越界写入

Samsung 开源项目 Walrus 存在越界写入漏洞，允许攻击者通过构造恶意输入触发缓冲区溢出，可能导致代码执行或服务崩溃。Walrus 是 Samsung 的开源存储相关组件。

- **CVSS**：7.8
- **影响组件**：Samsung Walrus（开源存储组件）
- **与当前栈关联**：无直接关联，但需关注是否间接依赖该组件。

### 4. CVE-2026-86261 — sfturing hosp_order 认证绕过类漏洞

sfturing hosp_order（医院订单系统，commit 至 627f4263）中被识别出安全弱点，攻击者可利用认证或授权相关缺陷访问未授权功能。该系统虽非通用组件，但漏洞模式（认证绕过）值得开发团队参考防范。

- **CVSS**：7.3
- **影响组件**：sfturing hosp_order（医院订单管理系统）
- **与当前栈关联**：无直接关联。但认证绕过模式提示多乐士 CMS 应检查 Spring Security 配置是否存在类似缺陷。

### 5. CVE-2026-86262 — sfturing hosp_order 功能层安全漏洞

同一 hosp_order 项目的另一个漏洞，影响功能层的未知函数。具体细节尚未完全披露，但已被标记为高危，可能涉及注入或逻辑缺陷。

- **CVSS**：7.3
- **影响组件**：sfturing hosp_order
- **与当前栈关联**：无直接关联。

### 6. CVE-2026-86263 — sfturing hosp_order 数据完整性漏洞

hosp_order 项目的第三个漏洞，影响数据完整性相关功能。三个漏洞集中在同一项目同一时间段，表明该项目存在系统性安全缺陷。

- **CVSS**：7.3
- **影响组件**：sfturing hosp_order
- **与当前栈关联**：无直接关联。

### 7. CVE-2026-86268 — itsourcecode School Management System SQL 注入

itsourcecode 学校管理系统 1.0 版本中存在 SQL 注入漏洞，攻击者可通过特制输入操纵数据库查询，可能导致数据泄露或篡改。该漏洞模式与多乐士 CMS 使用的 MySQL 后端相关。

- **CVSS**：7.3
- **影响组件**：itsourcecode School Management System 1.0
- **与当前栈关联**：虽然项目本身不相关，但 SQL 注入漏洞模式直接对应多乐士 CMS 的 MySQL 后端风险。需确认项目中所有数据库查询均使用参数化方式，无拼接 SQL。

## 建议动作

**立即处理：**
1. 排查多乐士 CMS 前端 Node.js 层（PM2 管理的 next-ai-draw-io 服务）是否使用 headless Chromium/Puppeteer，若有需确认 Chromium 版本不受 CVE-2026-85046 影响。
2. 确认项目中所有数据库交互均使用 MyBatis 参数化查询或 JPA，无手动拼接 SQL 的代码路径，应对 CVE-2026-86268 和 Sangoma SQL 注入模式。

**跟踪观察：**
- 关注 Starlette HTTP 请求走私漏洞（CVE-2026-48710），若未来架构引入 Python 微服务需评估影响。
- 关注 Samsung Walrus 越界写入漏洞（CVE-2026-86313），确认基础设施未间接依赖该组件。
- Dropbox 数据泄露事件提醒：检查团队是否在云存储中存放明文凭证，必要时迁移到本地加密存储。

**无需动作：** Android vdec 漏洞（CVE-2026-20501/20502）与移动端无关；sfturing hosp_order 三连漏洞（CVE-2026-86261/86262/86263）为独立项目不影响当前栈；LiteLLM、Kestra OSS、JFrog Artifactory、SonicWall、PaperCut 等 CISA KEV 条目均与当前基础设施无直接关联。
