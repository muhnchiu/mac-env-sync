## 今日高危漏洞

### 1. CVE-2026-87438 — Google Chrome WebGL 越界写入漏洞

Google Chrome on Android 在 153.0.8010.36 之前的版本中，WebGL 组件存在越界写入漏洞。远程攻击者可通过构造恶意网页内容触发该漏洞，导致在浏览器进程上下文中执行任意代码。该漏洞 CVSS 评分高达 9.6，属于严重级别，且已出现在 CISA KEV 目录中，表明已有被活跃利用的证据。

- **CVSS**：9.6
- **影响组件**：Google Chrome (Android) WebGL 组件，版本 < 153.0.8010.36
- **与当前栈关联**：不直接影响多乐士 CMS 服务端栈。若开发或测试人员使用 Android 设备访问受影响 Chrome 版本，存在客户端侧风险。

### 2. CVE-2026-87448 — Google Chrome DevTools Use-After-Free 漏洞

Google Chrome 在 153.0.8010.36 之前的版本中，DevTools 组件存在 Use-After-Free 漏洞。远程攻击者可利用该漏洞在浏览器中执行任意代码。该漏洞 CVSS 9.6，已被 CISA KEV 收录，确认已被活跃利用。

- **CVSS**：9.6
- **影响组件**：Google Chrome DevTools 组件，版本 < 153.0.8010.36
- **与当前栈关联**：不直接影响服务端栈。开发人员若使用受影响 Chrome 版本进行前端调试，存在被攻击风险。

### 3. CVE-2026-87455 — Google Chrome Aura Use-After-Free 漏洞

Google Chrome 在 153.0.8010.36 之前的版本中，Aura 组件存在 Use-After-Free 漏洞。远程攻击者可通过恶意网页内容触发，可能导致任意代码执行。CVSS 9.6，已被 CISA KEV 收录。

- **CVSS**：9.6
- **影响组件**：Google Chrome Aura 组件，版本 < 153.0.8010.36
- **与当前栈关联**：不直接影响服务端栈。属于客户端浏览器漏洞。

### 4. CVE-2026-87464 — Google Chrome WebGL Use-After-Free 漏洞

Google Chrome 在 153.0.8010.36 之前的版本中，WebGL 组件存在另一个 Use-After-Free 漏洞。远程攻击者可利用该漏洞在浏览器进程上下文中执行任意代码。CVSS 9.6，已被 CISA KEV 收录。

- **CVSS**：9.6
- **影响组件**：Google Chrome WebGL 组件，版本 < 153.0.8010.36
- **与当前栈关联**：不直接影响服务端栈。属于客户端浏览器漏洞。

### 5. CVE-2026-53939 — OpenIDC/cjose 拒绝服务漏洞

OpenIDC/cjose 是一个实现 JOSE（Javascript Object Signing and Encryption）的 C 库。在 0.6.1 至 0.6.2.2 版本中存在漏洞，可被远程攻击者利用导致拒绝服务或潜在的内存破坏。CVSS 9.1。该库通常用于 mod_auth_openidc 等 Apache 模块，涉及 OIDC 认证场景。

- **CVSS**：9.1
- **影响组件**：OpenIDC/cjose 0.6.1 - 0.6.2.2，常见于 mod_auth_openidc Apache 模块
- **与当前栈关联**：多乐士 CMS 使用 Nginx 而非 Apache + mod_auth_openidc，直接影响较小。但若未来引入 OIDC 认证方案，需关注此库的安全性。

### 6. CVE-2026-19490 — Citrix NetScaler 认证绕过漏洞

Citrix NetScaler 存在认证绕过漏洞，攻击者可利用备用认证路径绕过身份验证，获取未授权访问。该漏洞已于 2026-09-09 被 CISA KEV 收录，确认已被活跃利用。

- **CVSS**：未提供（CISA KEV 已收录，默认高危）
- **影响组件**：Citrix NetScaler（所有受影响版本）
- **与当前栈关联**：不直接影响多乐士 CMS 技术栈。但若网络架构中使用 Citrix NetScaler 作为负载均衡或网关设备，需立即排查。

### 7. CVE-2026-20079 — Cisco FMC 认证绕过漏洞

Cisco Secure Firewall Management Center (FMC) 和 Security Cloud Control (SCC) 存在认证绕过漏洞，攻击者可利用备用认证路径绕过身份验证。已于 2026-09-09 被 CISA KEV 收录。

- **CVSS**：未提供（CISA KEV 已收录，默认高危）
- **影响组件**：Cisco Secure Firewall Management Center 和 Security Cloud Control
- **与当前栈关联**：不直接影响多乐士 CMS 技术栈。若基础设施中使用 Cisco 防火墙产品，需立即排查。

## CISA KEV 新增（已知被利用漏洞）

今日 CISA KEV 目录新增条目重点关注以下几项：

1. **CVE-2026-19490 (Citrix NetScaler)** — 认证绕过，已被活跃利用。Citrix 网关产品在企业和云环境中广泛部署，若组织使用 Citrix ADC/NetScaler 作为反向代理或 VPN 网关，需立即升级并检查是否已被入侵。

2. **CVE-2025-25249 (Fortinet 多产品)** — 堆溢出漏洞，已被活跃利用。Fortinet 的 FortiOS/FortiProxy 等产品在企业网络边界广泛使用，需检查版本并应用补丁。

3. **CVE-2026-87491 (Google Chromium V8)** — 越界写入，已被活跃利用。与今日 NVD 报告的 Chrome 系列漏洞属同一轮次修复，需确保浏览器更新至 153.0.8010.36 及以上。

4. **CVE-2026-20079 (Cisco FMC/SCC)** — 认证绕过，已被活跃利用。影响 Cisco 防火墙管理平台。

5. **CVE-2026-75650 (Adobe Commerce/Magento)** — SQL 注入类漏洞。多乐士 CMS 虽非 Magento 架构，但若电商相关业务有接触 Adobe Commerce 组件，需关注。

6. **CVE-2026-85880 (Microsoft Windows)** — 堆溢出漏洞。影响 Windows 系统，需关注本月 Windows 安全更新。

总体来看，本轮 CISA KEV 更新以网络边界设备（Citrix、Fortinet、Cisco）和浏览器为主，与多乐士 CMS 的 Java/Spring/Nginx/MySQL 栈无直接交叉。
