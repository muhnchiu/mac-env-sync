## 今日高危漏洞

### 1. CVE-2026-12793 — JetFormBuilder WordPress 插件权限提升漏洞

JetFormBuilder Dynamic Blocks Form Builder 插件在所有版本中存在权限提升漏洞，未授权攻击者可利用此漏洞提升权限获取管理员级别的访问权限。该漏洞影响所有使用该插件的 WordPress 站点，攻击者可通过精心构造的请求绕过权限校验。

- **CVSS**：9.8
- **影响组件**：JetFormBuilder WordPress 插件（PHP/WordPress）
- **与当前栈关联**：无直接关联。多乐士 CMS 基于 Java/Spring Boot 栈，不使用 WordPress 插件体系。

### 2. CVE-2026-14349 — TrueBooker 预约系统插件授权绕过漏洞

TrueBooker Appointment Booking and Scheduler System 插件存在授权绕过漏洞，未认证用户可绕过访问控制执行本应受限的操作。CVSS 9.8，属于极高风险，可导致未授权数据访问和系统操控。

- **CVSS**：9.8
- **影响组件**：TrueBooker WordPress 插件（PHP/WordPress）
- **与当前栈关联**：无直接关联。WordPress/PHP 生态，与 Java/Spring Boot CMS 栈无关。

### 3. CVE-2026-78088 — Contest Gallery 插件未授权访问漏洞

Contest Gallery WordPress 插件存在未授权访问漏洞，攻击者可在无需认证的情况下访问和操作图库功能，包括上传、投票等。涉及 PayPal 和 Stripe 支付集成，可能导致支付信息泄露。

- **CVSS**：8.8
- **影响组件**：Contest Gallery WordPress 插件（PHP/WordPress）
- **与当前栈关联**：无直接关联。

### 4. CVE-2026-86108 — VeloCloud Edge 管理工作流输入校验不足漏洞

VMware VeloCloud Edge 设备在管理和配置工作流中对输入数据校验不充分，攻击者可通过构造恶意管理请求获取未授权访问或篡改设备配置。影响 VeloCloud Edge 设备的管理平面安全。

- **CVSS**：8.0
- **影响组件**：VMware VeloCloud Edge（网络设备）
- **与当前栈关联**：无直接关联。若基础设施中使用 VeloCloud SD-WAN 设备则需关注，但当前多乐士 CMS 环境未涉及。

### 5. CVE-2026-92299 — @jitsi/electron-sdk contextBridge 暴露漏洞

@jitsi/electron-sdk 10.0.5 之前版本通过 contextBridge 暴露 getDesktopSources() 方法，未要求活跃的 getDisplayMedia 权限校验，可能导致基于 Electron 的应用（如 Jitsi Meet 桌面端）在未授权情况下捕获桌面屏幕内容。

- **CVSS**：7.4
- **影响组件**：@jitsi/electron-sdk（Node.js/Electron）
- **与当前栈关联**：低关联。多乐士 CMS 前端使用 Node.js/Next.js，但不依赖 @jitsi/electron-sdk。若本机或其他项目使用 Jitsi 桌面应用则需留意升级。

### 6. CVE-2026-92215 — a2ui-project a2ui HTTP 输入验证漏洞

a2ui-project 的 a2ui 0.10.7 及之前版本中 httpx.go 相关功能存在输入验证不足漏洞，可被利用构造恶意 HTTP 请求触发非预期行为。

- **CVSS**：7.3
- **影响组件**：a2ui-project a2ui（Go）
- **与当前栈关联**：无关联。Go 项目，与 Java/Node.js 栈无关。

### 7. CVE-2026-73446 — Arista EOS IS-IS 广播接口未认证攻击漏洞

Arista EOS 设备在广播接口上配置 IS-IS 协议时，未认证攻击者可利用特制 IS-IS 报文触发异常行为，影响网络路由稳定性。

- **CVSS**：7.4
- **影响组件**：Arista EOS（网络设备操作系统）
- **与当前栈关联**：无关联。网络设备层漏洞，与应用栈无关。

## CISA KEV 新增（已知被利用漏洞）

近一周 CISA KEV 目录新增 10 条记录，主要涉及：

- **Cisco 产品（2 条）**：CVE-2026-76460（Identity Services Engine 权限管理错误，9月16日新增）和 CVE-2026-76461（Secure Email Gateway SQL 注入，9月14日新增）。Cisco ISE 漏洞可导致攻击者获取身份认证系统的高级权限；Secure Email Gateway SQL 注入可影响邮件网关安全。若基础设施中使用 Cisco 网络设备或邮件网关，需优先排查。
- **JFrog Artifactory（2 条）**：CVE-2026-42016（授权错误）和 CVE-2026-42018（认证不当），9月11日新增。Artifactory 作为制品仓库广泛使用，若 CI/CD 流程中使用了 JFrog Artifactory 需及时升级。
- **GitLab CE/EE（1 条）**：CVE-2026-85706（路径遍历），9月11日新增。若使用 GitLab 进行代码管理或 CI/CD，需关注此路径遍历漏洞，攻击者可利用其访问受限文件。
- **ConnectWise ScreenConnect（1 条）**：CVE-2026-84869（权限管理不当），9月11日新增。远程支持工具，若使用该产品需立即升级。
- **MikroTik RouterOS（2 条）**：CVE-2026-86060（参数分隔符注入）和 CVE-2026-67277（关键功能缺少认证），9月10日新增。若网络中使用 MikroTik 路由器需优先处理。
- **Acronis Backup（1 条）**：CVE-2026-87886（默认权限不当），9月16日新增。备份软件权限问题，若使用 Acronis 需排查。
- **Google Pixel（1 条）**：CVE-2026-58704（授权不当），9月16日新增。移动设备漏洞，与服务器栈无关。

与当前多乐士 CMS 基础设施（Java/Spring Boot/MySQL/Nginx/Node.js）直接相关的 KEV 条目：无。但 GitLab 和 JFrog Artifactory 漏洞值得关注，若开发流程中使用这些工具需及时升级。
