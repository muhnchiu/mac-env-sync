## 今日高危漏洞

### 1. CVE-2026-90847 — EFM ipTIME C200E 未授权漏洞

EFM ipTIME C200E 固件 1.094 版本中存在严重安全漏洞，攻击者可通过 iux_settings 等接口未授权访问或修改设备配置。该漏洞影响网络设备安全，可能导致设备被完全接管。

- **CVSS**：9.1
- **影响组件**：EFM ipTIME C200E 固件 <= 1.094
- **与当前栈关联**：无直接关联。当前基础设施未使用 ipTIME 设备，但若办公网络中存在该设备需注意隔离。

### 2. CVE-2026-91771 — Weights & Biases wandb 任意文件写入

Weights & Biases wandb SDK 在 0.29.0 之前版本中，File.download 函数未对服务器返回的文件名进行校验，攻击者可通过恶意服务器响应触发路径遍历，导致任意文件写入。若项目中使用 wandb 进行机器学习实验追踪，需立即升级。

- **CVSS**：8.8
- **影响组件**：wandb < 0.29.0（Python SDK）
- **与当前栈关联**：低风险。多乐士 CMS 技术栈未使用 wandb，但若有内部 ML 项目引用需排查。

### 3. CVE-2026-91751 — Flextype CMS REST API 未授权访问

Flextype CMS 1.0.0-alpha.3 及之前版本的 Entries REST API 未正确校验 id 和 new_id 参数，攻击者可未授权修改或访问内容条目。该漏洞仅影响 Flextype CMS，利用门槛低。

- **CVSS**：8.3
- **影响组件**：Flextype CMS <= 1.0.0-alpha.3
- **与当前栈关联**：无关联。CMS 技术栈为 Java/Spring Boot，不使用 Flextype。

### 4. CVE-2026-91752 — GNU libextractor 栈溢出

GNU libextractor 1.15 之前版本中 process_star_office 函数存在栈缓冲区溢出漏洞，攻击者可通过特制文档触发。若服务端处理用户上传的文档文件并调用 libextractor，可导致远程代码执行。

- **CVSS**：7.5
- **影响组件**：GNU libextractor < 1.15
- **与当前栈关联**：低风险。多乐士 CMS 后端为 Java，通常不直接调用 libextractor，但需确认是否有 C 扩展或文档处理依赖间接引用。

### 5. CVE-2026-90852 — zstd-jni 压缩库漏洞

zstd-jni（Java 的 Zstandard 压缩绑定库）1.5.7-13 及之前版本中 ZstdCompressCtx 函数存在漏洞。若 Java 项目使用 zstd-jni 进行数据压缩且压缩输入来自不可信来源，可能触发内存安全问题。

- **CVSS**：7.3
- **影响组件**：zstd-jni <= 1.5.7-13
- **与当前栈关联**：需排查。多乐士 CMS 为 Java/Spring Boot 项目，若 pom.xml 中引入了 zstd-jni 依赖需关注。建议检查项目依赖树。

### 6. CVE-2026-90880 — D-Link DSL-3782 命令注入

D-Link DSL-3782 路由器 2016-07-28 固件版本中 /cgi-bin/system 函数存在命令注入漏洞，攻击者可未授权执行系统命令。该设备已停止维护。

- **CVSS**：7.4
- **影响组件**：D-Link DSL-3782
- **与当前栈关联**：无直接关联。但若办公网络中使用该路由器设备，需关注网络隔离。
