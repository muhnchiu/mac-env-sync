## 今日高危漏洞

### 1. CVE-2026-90510 — dromara orion-visor HostKeyService 接口安全漏洞

dromara orion-visor（开源运维管理面板）2.5.7 及以下版本的 HostKeyServiceI 接口存在安全漏洞，攻击者可利用该接口进行未授权操作，可能导致主机密钥信息泄露或被篡改。该组件基于 Java 技术栈，与多乐士 CMS 同属 Java 生态，需关注是否引入相关依赖。

- **CVSS**：8.3
- **影响组件**：dromara orion-visor <= 2.5.7（Java 运维管理面板）
- **与当前栈关联**：Java 生态组件，若未使用 orion-visor 则无直接影响；但需确认项目依赖中是否包含该库

### 2. CVE-2026-90493 — Tonec Internet Download Manager 权限提升漏洞

Tonec Internet Download Manager 6.42 Build 63 及以下版本（Windows 平台）存在权限提升漏洞，攻击者可利用受影响功能获取更高权限。属于客户端漏洞，影响开发机环境而非服务端。

- **CVSS**：8.8
- **影响组件**：Tonec Internet Download Manager <= 6.42 Build 63（Windows）
- **与当前栈关联**：客户端工具漏洞，不影响多乐士 CMS 服务端；若开发机安装此软件需升级

### 3. CVE-2026-90651 — Socket Firewall TLS 证书校验缺失

Socket Firewall（socketdev/socket-registry-firewall）2.0.0 之前版本在 registry 模式下不验证上游 TLS 证书，攻击者可中间人攻击截获或篡改包数据。影响 Node.js/npm 供应链安全工具。

- **CVSS**：8.1
- **影响组件**：socket-registry-firewall < 2.0.0（npm 生态安全工具）
- **与当前栈关联**：Node.js 生态工具，若项目使用 socket-dev 进行依赖安全扫描需升级到 2.0.0+

### 4. CVE-2026-90678 — HAProxy HTTP/3 请求头拒绝服务

HAProxy 3.3.0 至 3.4.4 及 3.5-dev1 至 3.5-dev5 版本在处理 HTTP/3 请求时存在漏洞，攻击者可发送特制 HTTP 请求导致服务崩溃。HAProxy 常用作负载均衡器，与 Nginx 同属基础设施层。

- **CVSS**：7.5
- **影响组件**：HAProxy 3.3.0-3.4.4, 3.5-dev1-3.5-dev5
- **与当前栈关联**：多乐士 CMS 使用 Nginx 而非 HAProxy，无直接影响；若其他环境使用 HAProxy 需升级

### 5. CVE-2026-90668 — UnrealIRCd HTTP 请求头数量无限制拒绝服务

UnrealIRCd 6.0.5 至 6.2.6（6.2.7 之前）版本的 webserver 不限制 HTTP 请求头数量，攻击者可发送大量请求头导致内存耗尽和服务拒绝。

- **CVSS**：7.5
- **影响组件**：UnrealIRCd 6.0.5-6.2.6
- **与当前栈关联**：与当前技术栈无关，不使用 IRC 服务

### 6. CVE-2026-90498 — lenve vhr 权限管理漏洞

lenve vhr 1.0-SNAPSHOT（基于 Spring Boot 的人力资源管理系统）存在权限管理漏洞，部分功能缺少适当的访问控制。该项目是 Spring Boot 生态开源项目，与多乐士 CMS 技术栈高度一致，需重点关注权限设计模式。

- **CVSS**：7.3
- **影响组件**：lenve vhr 1.0-SNAPSHOT（Spring Boot 应用）
- **与当前栈关联**：同为 Spring Boot 生态，虽不直接使用 vhr，但需审视多乐士 CMS 中类似权限控制场景是否有同类问题

### 7. CVE-2026-90509 — dromara orion-visor ExposeApiAspect 接口暴露漏洞

dromara orion-visor 2.5.7 及以下版本的 ExposeApiAspect 功能存在漏洞，可能导致内部接口暴露给未授权用户。与 CVE-2026-90510 同属一个组件的不同漏洞。

- **CVSS**：7.3
- **影响组件**：dromara orion-visor <= 2.5.7
- **与当前栈关联**：Java 生态，若未使用 orion-visor 无直接影响

### 8. CVE-2026-89080 — WordPress Really Simple Security 插件未授权重置漏洞

WordPress Really Simple Security 插件 9.8.1 之前版本允许未认证请求重置安全设置，攻击者可绕过安全配置。该漏洞影响 WordPress 生态，与多乐士 CMS 无关。

- **CVSS**：7.5
- **影响组件**：WordPress Really Simple Security 插件 < 9.8.1
- **与当前栈关联**：与当前技术栈无关

## 建议动作

**立即处理：**
1. 确认多乐士 CMS 及本机环境是否使用 dromara orion-visor 组件，若使用需升级至 2.5.8+（CVE-2026-90510/90509，CVSS 8.3/7.3）
2. 排查多乐士 CMS 中类似 lenve vhr 的权限控制场景，检查是否存在同类未授权访问问题（CVE-2026-90498，Spring Boot 生态参考）
3. 若开发机安装了 Internet Download Manager，升级至 6.42 Build 64+（CVE-2026-90493，CVSS 8.8）
4. 若使用 GitLab 进行代码托管，优先排查 CVE-2026-85706 路径遍历漏洞并升级

**跟踪观察：**
- HAProxy HTTP/3 拒绝服务漏洞（CVE-2026-90678），当前使用 Nginx 无影响，但若后续引入 HAProxy 需关注
- socket-registry-firewall TLS 校验问题（CVE-2026-90651），若使用 socket-dev 工具链需升级到 2.0.0+
- Chromium V8 越界写入漏洞（CVE-2026-87491）已加入 CISA KEV，关注 Node.js 运行时是否会受 V8 漏洞连锁影响

**无需动作：** WordPress 插件漏洞三件（CVE-2026-80071/86406/89080）、UnrealIRCd（CVE-2026-90668）、Feng Office（CVE-2026-90495）、WARP-Clash-API（CVE-2026-90504）、School Registration System（CVE-2026-90514）、ConnectWise/JFrog/MikroTik/Citrix/Fortinet/Cisco 等 CISA KEV 条目，均与当前技术栈无直接关联。
