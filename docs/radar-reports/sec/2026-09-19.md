## 今日高危漏洞

### 1. CVE-2026-93467 — OAKlouds 不安全反序列化远程代码执行

HGiga 开发的 OAKlouds 存在不安全反序列化漏洞，未认证的远程攻击者可通过构造恶意序列化数据执行任意代码，获得服务器控制权。CVSS 9.8，属于无需认证即可利用的严重漏洞。

- **CVSS**：9.8
- **影响组件**：HGiga OAKlouds
- **与当前栈关联**：虽然产品不直接相关，但 Java 反序列化漏洞模式与多乐士 CMS 后端（Java/Spring Boot）属于同类风险面，建议关注项目是否引入了不可信的反序列化操作

### 2. CVE-2026-93452 — snappy-java 缓冲区溢出漏洞

snappy-java 通过 1.1.10.8 版本在 Snappy.compress(ByteBuffer, ByteBuffer) 方法中存在缓冲区溢出漏洞，攻击者可构造恶意输入数据导致内存越界写入，可能引发拒绝服务或代码执行。

- **CVSS**：7.5
- **影响组件**：snappy-java（Java 压缩库，广泛用于大数据和微服务场景）
- **与当前栈关联**：snappy-java 是 Java 生态常用压缩库，若多乐士 CMS 后端或其依赖链（如 Kafka、HBase 等）引入了 snappy-java，需排查版本并升级至安全版本

### 3. CVE-2026-93453 — SOGo 密码重置链接伪造漏洞

SOGo 5.12.11 之前版本在构造密码重置链接时使用客户端提供的 Origin 头作为权威来源，攻击者可伪造 Origin 头生成恶意重置链接，诱使受害者点击后劫持密码重置流程。

- **CVSS**：8.3
- **影响组件**：SOGo（Webmail/群件系统）5.12.11 之前版本
- **与当前栈关联**：不直接影响多乐士 CMS，但密码重置链接安全性是 Web 应用通用关注点，建议确认多乐士 CMS 的密码重置流程不受类似 Origin 头注入影响

### 4. CVE-2026-93456 — django-page-cms CSRF 防护绕过

django-page-cms 2.0.13 及之前版本在 pages/admin/views.py 中对五个管理操作视图免除了 CSRF 保护，允许攻击者通过构造恶意页面诱导已登录管理员执行未授权操作。

- **CVSS**：8.2
- **影响组件**：django-page-cms（Django CMS 插件）2.0.13 之前版本
- **与当前栈关联**：不直接影响多乐士 CMS（基于 Java/Spring Boot），但 CSRF 防护策略具有参考价值，建议确认 Spring Security 的 CSRF 配置覆盖所有管理接口

### 5. CVE-2026-18912 — ManageEngine DataSecurity Plus SQL 注入漏洞

ManageEngine DataSecurity Plus 6310 之前版本存在已认证 SQL 注入漏洞，已登录用户可通过构造恶意查询读取或修改数据库内容。

- **CVSS**：7.7
- **影响组件**：ManageEngine DataSecurity Plus < 6310
- **与当前栈关联**：虽然产品不同，但 SQL 注入模式与多乐士 CMS（MySQL 后端）属于同类风险，建议确认后端所有用户输入均经过参数化查询处理

### 6. CVE-2026-93371 — yt-dlp-web-ui 远程代码执行漏洞

marcopiovanello yt-dlp-web-ui v4 之前版本在 NextExportServer 函数中存在安全漏洞，可被远程攻击者利用执行代码。yt-dlp-web-ui 是基于 Node.js 的 yt-dlp Web 界面。

- **CVSS**：8.3
- **影响组件**：yt-dlp-web-ui < v4（Node.js 应用）
- **与当前栈关联**：多乐士测试环境使用 PM2 管理 Node.js 应用（next-ai-draw-io），同属 Node.js 生态，建议关注 PM2 管理的应用是否有已知依赖漏洞

### 7. CVE-2026-62874 — Azure Billing 权限提升漏洞

Azure Billing 存在数据真实性验证不足问题，未授权攻击者可利用此漏洞提升权限，获取对 Azure 订阅和计费数据的未授权访问。

- **CVSS**：10.0
- **影响组件**：Azure Billing
- **与当前栈关联**：Azure 基础设施层面漏洞。多乐士 CMS 生产环境部署在 Azure 上，需关注 Azure 平台安全公告及补丁状态

### 8. CVE-2026-85878 — Azure Database for PostgreSQL 授权不当漏洞

Azure Database for PostgreSQL 存在授权不当问题，已认证攻击者可在网络层面提升权限，可能获取对数据库实例的未授权访问。

- **CVSS**：9.9
- **影响组件**：Azure Database for PostgreSQL
- **与当前栈关联**：多乐士 CMS 使用 MySQL 而非 PostgreSQL，但 Azure 托管数据库服务的安全模型值得关注，确保数据库网络访问规则配置正确

## CISA KEV 新增（已知被利用漏洞）

本周 CISA KEV 目录新增条目重点关注以下：

- **Linux Kernel（CVE-2025-39964、CVE-2026-53266、CVE-2025-39682）**：9月18日新增三条 Linux 内核漏洞，涉及竞态条件、越界写入和异常检查不当。虽然多乐士测试环境为 Rocky Linux 9.7，但内核漏洞通常需要特定利用条件。建议关注系统内核更新。
- **Cisco ISE（CVE-2026-76460）**：Cisco 身份服务引擎权限使用不当，属于网络基础设施安全范畴，与当前栈无直接关联。
- **Cisco Secure Email Gateway（CVE-2026-76461）**：SQL 注入漏洞，已被 actively exploit。邮件网关类产品，与当前栈无直接关联，但 SQL 注入模式再次提醒输入验证的重要性。
- **Acronis Backup（CVE-2026-87886）**：默认权限不当，已被利用。备份产品类漏洞，需关注备份系统安全。
- **ConnectWise ScreenConnect（CVE-2026-84869）**：权限管理不当，已被利用。远程支持工具类漏洞。
- **JFrog Artifactory（CVE-2026-42016、CVE-2026-42018）**：授权和认证不当，已被利用。制品库类产品，若 CI/CD 流程中使用了 Artifactory 需重点关注。

## 建议动作

**立即处理：**
1. 排查多乐士 CMS 后端 Java 依赖链是否引入 snappy-java（CVE-2026-93452），若存在则升级到安全版本。可在项目根目录执行 `mvn dependency:tree | grep snappy` 快速确认。
2. 检查多乐士测试环境 Rocky Linux 内核版本，确认是否受 CISA KEV 新增三条内核漏洞影响，关注系统更新计划。
3. 确认 Azure 托管服务（若生产环境使用 Azure Database）的网络访问规则和权限配置，应对 CVE-2026-85878 和 CVE-2026-62874。

**跟踪观察：**
- 关注 OAKlouds 反序列化漏洞（CVE-2026-93467）的技术细节披露，审视多乐士 CMS 后端反序列化安全面。
- 关注 JFrog Artifactory 两个已被利用漏洞（CVE-2026-42016/42018），若 CI/CD 流程涉及 Artifactory 需尽快排查。
- 关注 Gecko Security AI 漏洞发现工具的进展，评估是否可用于多乐士 CMS 代码安全审计。

**无需动作：** Azure Portal XSS、M365 Copilot 权限、SOGo 密码重置、django-page-cms CSRF、GPAC RCE、WordPress ShortPixel、yt-dlp-web-ui、OAKlouds 文件读取等漏洞与当前技术栈无直接关联，保持常规关注即可。
