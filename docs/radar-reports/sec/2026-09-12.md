## 今日高危漏洞

### 1. CVE-2026-19991 — UsersWP WordPress 插件任意文件删除漏洞

UsersWP 插件 1.2.70 及以下版本存在任意文件删除漏洞，攻击者可利用该漏洞删除服务器上的任意文件，可能导致 WordPress 核心文件被删除后触发重装攻击，完全接管站点。该漏洞需要已认证用户权限（Author 及以上角色）。

- **CVSS**：8.1
- **影响组件**：UsersWP WordPress 插件 <= 1.2.70
- **与当前栈关联**：不直接影响多乐士 CMS 技术栈，但任意文件删除漏洞模式值得关注——Java 应用中类似的路径遍历导致文件操作问题同样需要防范。

### 2. CVE-2026-78133 — strongSwan IKEv2 重协商 use-after-free

strongSwan 6.0.0 至 6.0.7 的 libcharon 在处理 IKEv2 重协商冲突时存在 use-after-free，远程攻击者可触发该漏洞导致守护进程崩溃（DoS）或可能执行任意代码。strongSwan 是 Linux 下主流的 IPsec/IKEv2 VPN 实现。

- **CVSS**：7.5
- **影响组件**：strongSwan 6.0.0 - 6.0.7（libcharon）
- **与当前栈关联**：如果测试环境或云基础设施使用了 strongSwan 作为 VPN 网关，需关注。多乐士 CMS 本身不依赖 strongSwan，但基础设施层面可能涉及。

### 3. CVE-2026-78130 — strongSwan x509 插件 NULL 指针解引用

strongSwan 4.2.0 至 6.0.7 的 x509 插件在解析属性证书时存在 NULL 指针解引用，攻击者可发送特制证书导致 strongSwan 崩溃（DoS）。

- **CVSS**：7.5
- **影响组件**：strongSwan 4.2.0 - 6.0.7（x509 插件）
- **与当前栈关联**：同上，基础设施层面关注。strongSwan 连续爆出 4 个漏洞（CVE-78130/78132/78133/78134），如果使用了该组件需立即升级至 6.0.8+。

### 4. CVE-2026-78132 — strongSwan x509 插件无限循环

strongSwan 5.1.3 至 6.0.7 的 x509 插件在解析 ietfAttrSyntax 属性证书时存在无限循环，攻击者发送特制证书可导致进程挂起（DoS）。

- **CVSS**：7.5
- **影响组件**：strongSwan 5.1.3 - 6.0.7（x509 插件）
- **与当前栈关联**：与上述 strongSwan 系列漏洞同组，基础设施层面。

### 5. CVE-2026-15462 — Sticky Chat Widget WordPress 插件 SQL 注入

Sticky Chat Widget 插件通过 scw_form_fields 参数数组键存在 SQL 注入漏洞，未授权攻击者可从数据库中提取敏感信息。

- **CVSS**：7.5
- **影响组件**：Sticky Chat Widget WordPress 插件
- **与当前栈关联**：不直接影响多乐士 CMS。但 SQL 注入模式提醒：Spring Boot + MyBatis/JPA 项目中应确认所有用户输入参数化处理，特别是动态 SQL 场景。

### 6. CVE-2026-18561 — Unlimited Elements for Elementor WordPress 插件 SQL 注入

Unlimited Elements for Elementor 插件通过 addontype 参数存在 SQL 注入漏洞，未授权攻击者可操纵数据库查询。

- **CVSS**：7.5
- **影响组件**：Unlimited Elements for Elementor WordPress 插件
- **与当前栈关联**：不直接影响多乐士 CMS。同类 SQL 注入防护建议同上。

### 7. CVE-2026-78134 — strongSwan eap-ttls/eap-peap 访问控制缺陷

strongSwan 4.5.0 至 6.0.7 的 eap-ttls 和 eap-peap 插件存在访问控制缺陷，可能导致本应被拒绝的连接被接受，绕过身份验证。

- **CVSS**：7.1
- **影响组件**：strongSwan 4.5.0 - 6.0.7（eap-ttls/eap-peap 插件）
- **与当前栈关联**：基础设施层面。身份验证绕过类漏洞风险较高，若使用 strongSwan 做 EAP 认证需立即升级。

### 8. CVE-2026-81825 — Simple Ajax Chat WordPress 插件存储型 XSS

Simple Ajax Chat 插件通过 HTTP_X_FORWARDED_FOR 头部存在存储型 XSS 漏洞，攻击者注入的脚本将在管理员页面执行，可能窃取会话或进行后台操作。

- **CVSS**：7.2
- **影响组件**：Simple Ajax Chat WordPress 插件
- **与当前栈关联**：不直接影响多乐士 CMS。但 X-Forwarded-For 头部注入攻击模式值得注意——Nginx 反代场景下应确认对该头部的处理和后端消费方式，避免类似注入风险。
