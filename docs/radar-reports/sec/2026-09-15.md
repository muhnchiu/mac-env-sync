## 今日高危漏洞

### 1. CVE-2026-90605/90606/90607/90608 — Totolink A3002MU 多功能栈溢出漏洞群

Totolink A3002MU 路由器固件 Hh-B20211125.1046 中 formFilter、formIp、formNewSchedule、formPortFw 四个函数均存在未授权远程命令注入/栈溢出漏洞，攻击者可通过构造特制 HTTP 请求直接执行任意代码，无需认证即可完全控制设备。四个漏洞均为 CVSS 9.9（临界）。

- **CVSS**：9.9（四个均为 9.9）
- **影响组件**：Totolink A3002MU 路由器固件 Hh-B20211125.1046
- **与当前栈关联**：无直接关联。多乐士 CMS 技术栈为 Java/Spring Boot/MySQL/Nginx/Node.js，不涉及 Totolink 设备。但若办公网络中使用了该型号路由器需关注。

### 2. CVE-2026-31278 — Suprema BioStar 2 未授权 SQL 注入

Suprema BioStar 2 2.9.12 之前版本的 /api/v2/setting/adserversetting 端点存在 SQL 注入漏洞，攻击者可绕过认证执行恶意 SQL 语句，可能导致敏感数据泄露或数据库被篡改。BioStar X 1.0.3 之前版本同样受影响。CVSS 7.7。

- **CVSS**：7.7
- **影响组件**：Suprema BioStar 2 < 2.9.12、BioStar X < 1.0.3
- **与当前栈关联**：不直接影响多乐士 CMS。但 SQL 注入模式值得注意 -- MySQL 是多乐士后端数据库，应确认应用层参数化查询和 ORM 框架（MyBatis/JPA）是否严格使用预编译语句。

### 3. CVE-2026-23789 — Samsung Exynos MFC 权限提升

Samsung Exynos 系列 SoC 的 MFC（Multi-Function Codec）组件存在本地权限提升漏洞，影响 Exynos 850/1080/2100/1280/2200/1380/1480/2400/1580/2500/2600/1680 等多款芯片。攻击者利用恶意媒体文件可在内核层执行代码。CVSS 7.8。

- **CVSS**：7.8
- **影响组件**：Samsung Exynos 全系列 SoC（手机/可穿戴处理器）
- **与当前栈关联**：与多乐士 CMS 和本机环境（Mac Mini）无关，仅影响 Samsung 移动设备用户。

### 4. CVE-2026-33963 — Samsung Exynos Camera 权限提升

Samsung Exynos 1330/1380/1480/2400/1580/2500/2600/1680 处理器的摄像头组件存在本地权限提升漏洞，攻击者通过特制媒体文件可在内核上下文中执行任意代码。CVSS 7.5。

- **CVSS**：7.5
- **影响组件**：Samsung Exynos 多款移动处理器
- **与当前栈关联**：与当前基础设施无关。

### 5. CVE-2026-90617/90618/90619 — 开源安全工具命令注入漏洞

GH05TCREW PentestAgent 和 0x4m4 HexStrike AI 两个开源安全/渗透测试工具中存在多个命令注入漏洞，攻击者可通过特制输入在执行上下文中注入命令。均为 CVSS 7.3。

- **CVSS**：7.3
- **影响组件**：GH05TCREW PentestAgent（<= cf882da）、0x4m4 HexStrike AI（<= d689933）
- **与当前栈关联**：不使用这些工具，无影响。
