## 今日高危漏洞

### 1. CVE-2026-94083 — Suricata DoH2 类型混淆导致无效释放

Suricata 8.0.7 之前版本中，DoH2（DNS over HTTP/2）处理存在类型混淆问题，可导致无效内存释放（invalid free）。攻击者可通过构造特制的 HTTP/2 流量触发此漏洞，可能导致 Suricata 进程崩溃或潜在代码执行。Suricata 作为 IDS/IPS 部署时风险更高。

- **CVSS**：9.4
- **影响组件**：Suricata < 8.0.7（网络入侵检测/防御系统）
- **与当前栈关联**：无直接关联。多乐士 CMS 环境未部署 Suricata，但如未来引入网络层入侵检测则需关注。

### 2. CVE-2026-94084 — Suricata Http2ThreadMultiBuf 释放后使用

Suricata 8.0.7 之前版本中，当事务被使用 http.response_body 等规则检查时，Http2ThreadMultiBuf 存在 use-after-free 漏洞。攻击者可构造恶意 HTTP/2 流量触发释放后使用，可能导致服务崩溃或远程代码执行。

- **CVSS**：9.4
- **影响组件**：Suricata < 8.0.7
- **与当前栈关联**：无直接关联。同上，当前基础设施未使用 Suricata。

### 3. CVE-2026-93958 — D-Link R95 BE9500 路由器命令注入

D-Link R95 BE9500 固件 1.00.16 中 /bin/ 路径下 system 函数存在命令注入漏洞。攻击者可通过特制请求执行任意系统命令，完全控制路由器设备。

- **CVSS**：9.1
- **影响组件**：D-Link R95 BE9500 路由器固件 <= 1.00.16
- **与当前栈关联**：无直接关联。但需检查办公网络中是否使用该型号路由器。

### 4. CVE-2026-86553 — SmartLife 应用认证参数动态生成问题

SmartLife 应用的运行时进程中动态生成新的应用认证参数，存在认证绕过风险。攻击者可利用此特性获取未授权访问。

- **CVSS**：8.8
- **影响组件**：SmartLife 应用（IoT 智能家居平台）
- **与当前栈关联**：无直接关联。

### 5. CVE-2026-87067 — Forminator Forms WordPress 插件反序列化漏洞

WordPress Forminator Forms 插件 1.57.2.1 之前版本在反序列化时未限制可实例化的类，攻击者可通过构造恶意序列化对象实现远程代码执行。需要 WordPress 站点安装了该插件。

- **CVSS**：8.5
- **影响组件**：WordPress Forminator Forms 插件 < 1.57.2.1
- **与当前栈关联**：无直接关联。多乐士 CMS 不使用 WordPress。

### 6. CVE-2026-93962 — Kamailio SIP 服务器共享内存释放后使用

Kamailio SIP 服务器在 5.8.8/6.0.7/6.1.4/6.2.0-dev1 之前版本中，shm_malloc 相关函数存在释放后使用漏洞。攻击者可通过构造特制 SIP 消息触发此漏洞，可能导致服务崩溃或代码执行。

- **CVSS**：8.3
- **影响组件**：Kamailio <= 5.8.8 / 6.0.7 / 6.1.4
- **与当前栈关联**：无直接关联。多乐士 CMS 环境未部署 Kamailio。

### 7. CVE-2026-82842 — WordPress SAML Single Sign On 插件认证绕过

WordPress SAML Single Sign On 插件 6.0.0 之前版本未正确执行传入 SAML 断言与现有用户账号的关联条件检查，可能导致攻击者绕过认证或冒充其他用户。

- **CVSS**：8.1
- **影响组件**：WordPress SAML Single Sign On 插件 < 6.0.0
- **与当前栈关联**：无直接关联。多乐士 CMS 使用自研认证，非 WordPress SAML 插件。但 SSO 认证绕过模式值得参考，确保自研 SSO 逻辑严格校验用户关联。

## CISA KEV 新增（已知被利用漏洞）

本周 CISA KEV 目录新增条目重点关注以下：

- **Linux Kernel 漏洞三连**（2026-09-18 新增）：
  - CVE-2025-39964 — Linux 内核竞态条件漏洞
  - CVE-2026-53266 — Linux 内核越界写入漏洞
  - CVE-2025-39682 — Linux 内核异常条件检查不当
  这三个 Linux 内核漏洞已被确认在野利用，影响范围广。多乐士测试环境运行 Rocky Linux 9.7，需关注内核版本是否受影响并及时更新。

- **Cisco Secure Email Gateway SQL 注入**（CVE-2026-76461，2026-09-16 新增）：Cisco 邮件网关产品存在 SQL 注入漏洞，已被在野利用。与当前栈无直接关联，但如使用 Cisco 邮件设备则需紧急排查。

- **ConnectWise ScreenConnect**（CVE-2026-84869，2026-09-11 新增）：远程管理工具权限管理不当，已被在野利用。如组织内使用该工具需紧急升级。

- **JFrog Artifactory**（CVE-2026-42016 / CVE-2026-42018，2026-09-11 新增）：Artifactory 存在授权不当和认证不当漏洞，已被在野利用。如 CI/CD 流程中使用 Artifactory 作为制品仓库需紧急排查。
