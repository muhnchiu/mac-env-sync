## 今日高危漏洞

### 1. CVE-2026-94097 — Netcore NBR200V2 路由器 CGI 远程代码执行

Netcore NBR200V2 路由器固件 1.3.241127.071246 中存在严重漏洞，影响 /www/cgi- 目录下的未知组件，攻击者可通过 CGI 接口远程执行任意代码。该漏洞 CVSS 10.0，为今日最高危漏洞。Netcore 路由器在企业网络边缘广泛部署，若暴露管理接口可被直接接管。

- **CVSS**：10.0
- **影响组件**：Netcore NBR200V2 固件 1.3.241127.071246，CGI 模块
- **与当前栈关联**：不直接影响多乐士 CMS 技术栈，但若办公网络使用 Netcore 路由器需关注

### 2. CVE-2026-82187 — WordPress Web to Print Online Designer 插件任意文件上传

Web to Print Online Designer WordPress 插件 2.15.0 之前版本未验证上传文件的类型或扩展名，攻击者可通过上传恶意文件（如 PHP webshell）获取服务器控制权。CVSS 9.8，利用难度低，影响所有未升级的安装。该插件常用于印刷/设计类业务网站。

- **CVSS**：9.8
- **影响组件**：WordPress 插件 "Web to Print Online Designer" < 2.15.0
- **与当前栈关联**：多乐士 CMS 未使用 WordPress，无直接关联

### 3. CVE-2026-47321 — CompressionFilter ZLib 解压漏洞

CompressionFilter 类使用 ZLib 对发送和接收数据进行 deflate/inflate 处理。在 inflate 接收数据时存在安全缺陷，可能导致内存耗尽或拒绝服务。该漏洞影响使用 CompressionFilter 的 Java Web 应用框架。CVSS 7.5，通过网络可利用。

- **CVSS**：7.5
- **影响组件**：使用 CompressionFilter（ZLib 压缩）的 Java Web 框架/中间件
- **与当前栈关联**：需排查多乐士 CMS 后端（Java/Spring Boot）是否启用了 GZIP 压缩过滤器。若使用 Spring Boot 的 server.compression 或 Tomcat CompressionFilter，需确认组件版本是否受影响

### 4. CVE-2026-15801 — CRI-O 容器检查点恢复漏洞

CRI-O 容器运行时在检查点与恢复（checkpoint/restore）功能中存在安全漏洞。当 CRI-O 配置启用了容器检查点功能时，攻击者可能利用该缺陷逃逸容器隔离或导致节点崩溃。CVSS 8.0。

- **CVSS**：8.0
- **影响组件**：CRI-O 容器运行时（启用 checkpoint 功能时）
- **与当前栈关联**：多乐士 CMS 测试环境直接运行 jar，未使用 CRI-O/Kubernetes，无直接关联。若未来容器化部署则需关注

### 5. CVE-2026-94143 / CVE-2026-94144 — drogon framework ORM SQL 注入

drogonframework drogon 1.9.13 及之前版本中，Mapper::order 和 makeCriteria 函数存在 SQL 注入漏洞。攻击者可通过构造恶意查询参数绕过过滤或执行任意 SQL。CVSS 7.3。

- **CVSS**：7.3
- **影响组件**：drogon C++ Web 框架 ORM 模块 <= 1.9.13
- **与当前栈关联**：drogon 是 C++ 框架，与多乐士 CMS（Java/Node.js）无关，无需处理

### 6. CVE-2026-94110 — QCMS 任意文件上传

QCMS 6.0.6 及之前版本中 self_Tmp 函数存在文件上传漏洞，攻击者可上传恶意文件执行代码。CVSS 7.3。

- **CVSS**：7.3
- **影响组件**：QCMS <= 6.0.6
- **与当前栈关联**：不使用 QCMS，无关联

### 7. CVE-2026-94128 / 94129 / 94142 / 94146 — BioStar 多产品本地提权

BioStar 多款产品（VIVID LED DJ、VALKYRIE AURORA、Temperature Monitor、BIOS Update Utility）存在本地权限提升漏洞，影响 sub_1105C / sub_110BC 等函数。CVSS 8.8。需要本地访问权限才能利用。

- **CVSS**：8.8
- **影响组件**：BioStar VIVID LED DJ 4.0.2411.1500、VALKYRIE AURORA 2.10.2411.0800、Temperature Monitor 1.2.1806.2200、BIOS Update Utility 1.9.7.3
- **与当前栈关联**：与多乐士 CMS 和本机环境无关

### 8. CVE-2026-94095 / 94096 / 94098 / 94099 / 94100 / 94101 — Netcore NBR200V2 多漏洞集合

Netcore NBR200V2 路由器固件中存在 6 个独立高危漏洞（CVSS 9.1-9.9），涉及多个 CGI 函数（wan_config_set_vlan、v 系列等），均可远程利用。结合 CVE-2026-94097（CVSS 10.0），该路由器共 7 个漏洞同时披露，基本等同设备完全不受保护。

- **CVSS**：9.1 - 9.9
- **影响组件**：Netcore NBR200V2 固件 1.3.241127.071246
- **与当前栈关联**：不影响多乐士 CMS 技术栈，但若办公/机房使用该型号路由器需立即更新固件
