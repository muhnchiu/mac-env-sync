- **CVSS**：9.8 / CRITICAL
- **EPSS**：暂无数据
- **CISA KEV**：否
- **利用状态**：暂无明确利用证据
- **影响组件**：Apache 组件（涉及 java.lang.reflect.Proxy 的 acceptMatchers 过滤器），2026-06-02 修复版本仍可被绕过
- **与当前栈关联**：直接相关 — Java/Spring 生态核心机制
- **判断依据**：CVSS 9.8 + Java 反射代理直接关联当前技术栈 + 修复绕过说明原修复方案有缺陷

### 5. CVE-2026-47321 — Apache CompressionFilter ZLib 解压 DoS

Apache CompressionFilter 使用 ZLib 对收发数据进行压缩/解压，解压入站数据时不控制结果大小，可创建超大缓冲区导致内存耗尽拒绝服务。CVSS 7.5，远程无需认证即可触发。影响使用 Apache CompressionFilter 的 Java Web 应用。

- **CVSS**：7.5 / HIGH
- **EPSS**：0.002910 / percentile=0.218410
- **CISA KEV**：否
- **利用状态**：暂无明确利用证据
- **影响组件**：Apache CompressionFilter（Java Web 应用组件）
- **与当前栈关联**：间接相关 — Java 生态，但需确认当前项目是否使用 CompressionFilter
- **判断依据**：Java 生态 + 可远程触发 DoS + 无需认证
