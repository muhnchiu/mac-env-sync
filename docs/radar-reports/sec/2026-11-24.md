## 今日高危漏洞

### 1. CVE-2026-134882 — TOTOLINK A7100RU 7.4cu.2313_B20191024 exportOvpn 功能缺陷

TOTOLINK A7100RU 固件 7.4cu.2313_B20191024 的 exportOvpn 功能存在漏洞，CVSS 10.0，属于严重级别。攻击者可利用该缺陷实施未授权访问或配置篡改。

- **影响组件**：TOTOLINK A7100RU 7.4cu.2313_B20191024

- **来源等级**：official
- **来源名称**：NVD

### 2. CVE-2026-115873 — 分布式任务系统 Worker 组 Read Only 权限提升

远程攻击者需具备至少一个 Worker Group 的 Read Only 访问权限并能够到达 Leader 节点，即可利用该漏洞实施未授权操作。CVSS 9.9，属于严重级别。

- **CVSS**：9.9
- **影响组件**：分布式任务调度系统（具体组件未确认）
- **与当前栈关联**：未确认，当前基础设施是否部署该分布式任务系统未检索到明确证据
- **来源等级**：official
- **来源名称**：NVD

### 3. CVE-2026-115899 — REST Collector 上游分页数据未校验导致注入

- **CVSS**：9.8
