## 今日高危漏洞

### 1. CVE-2026-87796 — WordPress Multi Uploader for Gravity Forms 任意文件上传漏洞

该漏洞存在于 WordPress 的 Multi Uploader for Gravity Forms 插件中，所有版本（包括 3.1 及更早版本）均受影响。攻击者可通过上传恶意文件在服务器上执行任意代码，导致完整的远程代码执行。CVSS 评分高达 9.8，属于严重级别。

- **CVSS**：9.8
- **影响组件**：WordPress Multi Uploader for Gravity Forms 插件（< 3.2）
- **与当前栈关联**：无直接关联。多乐士 CMS 基于 Java/Spring Boot，不使用 WordPress。但若有周边站点使用 WordPress，需排查。

### 2. CVE-2026-25283 — Qualcomm 内存损坏漏洞

该漏洞因从外部源复制未经验证的数据超过已分配缓冲区大小导致内存损坏。可能被邻近系统利用实现提权或代码执行。

- **CVSS**：8.8
- **影响组件**：Qualcomm 芯片组/固件（蓝牙/WiFi 模块）
- **与当前栈关联**：无关联。属移动设备/嵌入式芯片层面，不影响 Java/Spring/Nginx/MySQL 栈。

### 3. CVE-2026-87935 — WordPress Paid Downloads 插件任意文件上传漏洞

该漏洞存在于 WordPress Paid Downloads 插件中（3.1 及更早版本），攻击者可利用任意文件上传漏洞在服务器上执行任意代码。

- **CVSS**：8.1
- **影响组件**：WordPress Paid Downloads 插件（<= 3.1）
- **与当前栈关联**：无关联。同属 WordPress 生态，不影响当前技术栈。

### 4. CVE-2026-25282 — Qualcomm 临时拒绝服务漏洞

处理来自邻近系统的未验证数据时导致越界内存访问，引发临时拒绝服务。

- **CVSS**：7.9
- **影响组件**：Qualcomm 芯片组/固件
- **与当前栈关联**：无关联。属芯片/固件层面漏洞。

### 5. CVE-2026-81546 — Affinity by Canva 边界检查不足漏洞

Affinity by Canva 应用在 3.3.0 之前版本未执行充分的边界检查，处理特制文件时可导致内存损坏，可能被利用执行任意代码。

- **CVSS**：7.7
- **影响组件**：Affinity by Canva 桌面应用（< 3.3.0, 2026年9月版本）
- **与当前栈关联**：无关联。属设计软件客户端，不影响服务端栈。

### 6. CVE-2026-92838 — GeoVision GV-Remote E-Map DLL 劫持漏洞

GeoVision GV-Remote E-Map 桌面应用存在 DLL 劫持漏洞，应用加载一个或多个 DLL 时未使用安全路径，攻击者可放置恶意 DLL 实现代码执行。

- **CVSS**：7.8
- **影响组件**：GeoVision GV-Remote E-Map 桌面应用
- **与当前栈关联**：无关联。属安防监控桌面软件，不影响服务端栈。

### 7. CVE-2025-59607 — 内存损坏漏洞

复制超大输入数据时超出正常分配限制导致内存损坏。影响 Qualcomm 多个芯片组件。

- **CVSS**：7.8
- **影响组件**：Qualcomm 芯片组/固件
- **与当前栈关联**：无关联。属芯片层面漏洞。

### 8. CVE-2026-85128 — WordPress Choose User Role at Registration 插件漏洞

该插件在 1.3.3 之前版本未验证注册时请求的角色，允许用户在注册时自行选择不应获得的角色，导致权限提升。

- **CVSS**：7.5
- **影响组件**：WordPress Choose User Role at Registration 插件（< 1.3.3）
- **与当前栈关联**：无关联。属 WordPress 生态漏洞。

## CISA KEV 新增（已知被利用漏洞）

本周 CISA KEV 目录新增 10 条记录，重点关注以下与基础设施可能相关的条目：

- **CVE-2026-76461 — Cisco Secure Email Gateway SQL 注入**：影响邮件安全网关，SQL 注入可导致信息泄露或提权。若网络中部署了 Cisco 邮件网关需重点关注。
- **CVE-2026-85706 — GitLab CE/EE 路径穿越**：GitLab 社区版和企业版存在路径穿越漏洞，已被 actively exploit。若内部使用 GitLab 需立即升级。
- **CVE-2026-42016 / CVE-2026-42018 — JFrog Artifactory 授权与认证漏洞**：两个 Artifactory 漏洞均已被利用，影响制品仓库安全。若 CI/CD 流程中使用了 Artifactory 需排查。
- **CVE-2026-84869 — ConnectWise ScreenConnect 权限管理漏洞**：远程支持工具 ScreenConnect 存在权限管理缺陷，已被利用。
- **CVE-2026-76460 — Cisco ISE 授权漏洞**：Cisco 身份服务引擎存在授权绕过，影响网络准入控制安全。
- **CVE-2026-86060 / CVE-2026-67277 — MikroTik RouterOS 漏洞**：两个路由器操作系统漏洞（参数注入和缺少认证），已被利用，影响网络边界安全。
- **CVE-2026-58704 — Google Pixel 授权漏洞**：移动设备授权绕过，属终端安全范畴。
- **CVE-2026-87886 — Acronis Backup 默认权限漏洞**：备份软件默认权限不当，可能导致数据泄露。

## 建议动作

**立即处理：**
1. 排查网络中是否存在 Cisco Secure Email Gateway（CVE-2026-76461）或 MikroTik RouterOS 设备（CVE-2026-86060/67277），这些已被 actively exploit 且影响网络边界安全。
2. 排查内部是否使用 GitLab CE/EE（CVE-2026-85706 路径穿越已被利用），若有需立即升级至安全版本。
3. 排查 CI/CD 流程中是否使用 JFrog Artifactory（CVE-2026-42016/42018），两个漏洞均已被利用。

**跟踪观察：**
- CVE-2026-87796（WordPress Gravity Forms 插件 CVSS 9.8）：虽然不影响当前技术栈，但若周边营销站点使用 WordPress，需确认插件已更新。
- Gecko Security AI 漏洞扫描工具值得关注，未来可考虑集成到代码安全审计流程中。
- Qualcomm 芯片系列漏洞（CVE-2026-25283/25282/25290 等）批量修复，若有 Android 设备管理需关注厂商 OTA 更新。

**无需动作：** 今日 NVD 高危漏洞主要集中在 WordPress 插件生态（4 条）、Qualcomm 芯片固件（多条）和桌面应用（Canva/GeoVision），与多乐士 CMS 技术栈（Java/Spring Boot/MySQL/Nginx/Node.js）无直接关联。GitHub Security Advisories 本周无 maven/npm/pip 生态新公告，当前项目依赖未受影响。
