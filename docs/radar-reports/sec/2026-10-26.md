## 今日高危漏洞

### 1. CVE-2026-116068 — Dokploy 授权绕过漏洞

Dokploy 0.30.10 及以下版本存在授权绕过漏洞：任何组织的 owner 或 admin 可通过该缺陷越权访问/操作其他组织资源。CVSS 8.8，属高危；若当前环境部署了 Dokploy 作为基础设施或部署编排工具，需立即核查版本并升级/限制访问。

- **CVSS**：8.8
- **影响组件**：Dokploy 0.30.10 及以下
- **与当前栈关联**：未确认（当前 Java 后端/前端技术栈未使用 Dokploy；如本地有部署需自查）
- **来源等级**：official
- **来源名称**：NVD
