## 今日高危漏洞

### 1. CVE-2026-85504 — FreeIPMI 栈缓冲区溢出（libfreeipmi）

FreeIPMI 1.6.19 之前版本中，_ipmi_sel_oem_fujitsu_get_sel_entry_long_text 函数存在基于栈的缓冲区溢出。攻击者可通过构造恶意 SEL（系统事件日志）条目触发溢出，导致任意代码执行或服务崩溃。FreeIPMI 广泛用于服务器 BMC 远程管理。

- **CVSS**：9.8
- **影响组件**：FreeIPMI < 1.6.19（libfreeipmi 库）
- **与当前栈关联**：低。多乐士 CMS 测试环境为 VMware 虚机，不直接使用 FreeIPMI。但若物理主机使用 IPMI 管理工具需关注。

### 2. CVE-2026-85506 — FreeIPMI ipmi-oem Dell 系统信息栈溢出

FreeIPMI 1.6.19 之前版本中，ipmi-oem 工具的 _get_dell_system_info_idrac_info 函数存在栈缓冲区溢出。攻击者可通过恶意 BMC 响应触发，导致 ipmi-oem 进程崩溃或任意代码执行。

- **CVSS**：9.8
- **影响组件**：FreeIPMI < 1.6.19（ipmi-oem 工具）
- **与当前栈关联**：低。同上，VMware 虚机环境不直接涉及。

### 3. CVE-2026-85509 — FreeIPMI FRU 数据读取栈溢出

FreeIPMI 1.6.19 之前版本中，_read_fru_data 函数处理 BMC 返回的 FRU（现场可更换单元）数据时存在栈缓冲区溢出。恶意 BMC 可构造超长 FRU 数据触发漏洞。

- **CVSS**：9.8
- **影响组件**：FreeIPMI < 1.6.19（libfreeipmi/fru/ipmi-fru.c）
- **与当前栈关联**：低。同上。

### 4. CVE-2026-85146 — SmartIT Desktop Manager 硬编码凭据

SmartIT Desktop Manager 存在硬编码凭据漏洞，未认证的远程攻击者可利用内置默认凭据直接访问管理接口，获取系统控制权限。

- **CVSS**：9.8
- **影响组件**：SmartIT Desktop Manager（Lightstar）
- **与当前栈关联**：无。桌面管理工具，与多乐士 CMS 服务端栈无关。

### 5. CVE-2026-11613 — Divi Ajax Filter WordPress 插件本地文件包含

WordPress Divi Ajax Filter 插件（5.0 及以下所有版本）存在本地文件包含（LFI）漏洞。攻击者可通过构造请求包含服务器上的任意文件，可能导致敏感信息泄露或远程代码执行。

- **CVSS**：9.8
- **影响组件**：Divi Ajax Filter WordPress plugin <= 5.0
- **与当前栈关联**：无。多乐士 CMS 不使用 WordPress。

### 6. CVE-2026-15354 — ACPT Premium WordPress 插件权限提升

WordPress ACPT（Premium）插件 2.0 及以下版本存在权限提升漏洞。低权限用户可利用该漏洞提升为管理员权限，完全接管站点。

- **CVSS**：9.8
- **影响组件**：ACPT (Premium) WordPress plugin <= 2.0
- **与当前栈关联**：无。

### 7. CVE-2026-19224 — Hummingbird Performance WordPress 插件权限绕过

WordPress Hummingbird Performance 插件 3.21.2 之前版本未将网络级别设置限制为网络管理员，导致子站点管理员可修改全网络配置，引发配置篡改。

- **CVSS**：7.2
- **影响组件**：Hummingbird Performance WordPress plugin < 3.21.2
- **与当前栈关联**：无。

### 8. CVE-2026-16281 — Classified Listing WordPress 插件越权访问

Classified Listing WordPress 插件 6.1.1 之前版本未验证调用者是否有权编辑目标列表项，导致任意用户可修改他人发布的信息。

- **CVSS**：7.1
- **影响组件**：Classified Listing WordPress plugin < 6.1.1
- **与当前栈关联**：无。

4. **CVE-2026-49869**（2026-09-02）— Kestra OSS 操作系统命令注入。编排调度工具的命令注入，已被利用。

5. **CVE-2026-82329**（2026-09-02）— JFrog Artifactory 认证不当漏洞。制品仓库认证绕过。

6. **CVE-2026-9586**（2026-09-02）— Sangoma Switchvox SQL 注入。PBX 通信系统注入。

7. **CVE-2026-83548 / CVE-2026-83549**（2026-09-02）— SonicWall SMA1000 SSRF 和 OS 命令注入。SSL VPN 设备两个漏洞同时被利用。

8. **CVE-2026-82078 / CVE-2026-81578**（2026-08-31）— PaperCut NG/MF 不安全反射和关键功能缺失认证。打印管理系统的两个漏洞。

## 建议动作

**立即处理：**
1. 关注 CVE-2026-85046（Chromium V8 类型混淆，已入 CISA KEV 被利用列表）— 检查多乐士 CMS 前端是否有 Node.js 服务依赖的 V8 版本受影响，确认 Node.js 运行时是否需要升级。
2. 检查网络环境中是否有 SonicWall SMA1000 设备 — 若有需立即升级（SSRF + 命令注入双漏洞已入 KEV）。

**跟踪观察：**
- FreeIPMI 系列漏洞（CVE-2026-85504/85506/85507/85508/85509）— 若物理主机使用 IPMI 工具管理 BMC，需升级至 1.6.19。
- CVE-2026-48710（Starlette 请求走私）— 若后续多乐士 CMS 引入 Python 微服务（如 FastAPI），需关注 Starlette 版本。
- Dropbox 数据泄露事件 — 关注后续官方公告，检查是否有相关账号受影响。

**无需动作：** WordPress 插件系列漏洞（Divi Ajax Filter、ACPT、Hummingbird、Classified Listing）和 SmartIT Desktop Manager 漏洞与当前技术栈无关。Hospital Information System、Doctor Appointment System 等小项目漏洞不影响生产环境。GitHub Security Advisories 近 7 天无 maven/npm/pip 生态新公告，项目依赖无已知风险。
