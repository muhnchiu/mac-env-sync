## 今日高危漏洞

### 1. CVE-2026-85706 — GitLab CE/EE 路径穿越漏洞（CVSS 10.0）

GitLab CE/EE 存在路径穿越漏洞，影响 18.7 至 19.1.8、19.2 至 19.2.6 及 19.3 以上版本。攻击者可通过构造恶意路径访问服务器上任意文件，可能导致敏感信息泄露甚至远程代码执行。该漏洞已被 CISA 列入 KEV 目录，表明已在野外被积极利用。

- **CVSS**：10.0
- **影响组件**：GitLab CE/EE（自托管 GitLab 实例）
- **与当前栈关联**：间接相关。若团队使用自托管 GitLab 管理代码仓库，需立即升级。SaaS 版 GitLab 已由官方修复，无需额外动作。

### 2. CVE-2026-87719 — GitLab EE 认证绕过漏洞（CVSS 9.9）

GitLab EE 存在严重漏洞，影响 18.3 至 19.1.8、19.2 至 19.2.6 及 19.3 以上版本。漏洞细节未完全公开，但涉及认证与授权层面，攻击者可能绕过认证获取未授权访问。

- **CVSS**：9.9
- **影响组件**：GitLab EE（企业版自托管实例）
- **与当前栈关联**：同上，取决于是否使用自托管 GitLab。

### 3. CVE-2026-82845 — Masteriyo LMS WordPress 插件反序列化漏洞（CVSS 9.9）

Masteriyo LMS WordPress 插件 3.4.1 以下版本未对用户可控的 metadata 值进行反序列化保护，攻击者可通过注入恶意序列化对象实现远程代码执行。该漏洞无需认证即可利用。

- **CVSS**：9.9
- **影响组件**：Masteriyo LMS WordPress 插件 < 3.4.1
- **与当前栈关联**：无直接关联。多乐士 CMS 不使用 WordPress，但若其他项目中使用了该插件需立即更新。

### 4. CVE-2026-75800 — Frontegg SAML SSO WordPress 插件认证绕过漏洞（CVSS 9.8）

Frontegg SAML SSO WordPress 插件 1.0.1 及以下版本未验证 SAML 认证响应的签名或签发者，攻击者可伪造 SAML 断言绕过认证，直接以任意用户身份登录。

- **CVSS**：9.8
- **影响组件**：Frontegg SAML SSO WordPress 插件 <= 1.0.1
- **与当前栈关联**：无直接关联。当前栈不使用 WordPress，但该漏洞模式（SAML 签名验证缺失）值得安全设计参考。

### 5. CVE-2026-85681 — WP Component WordPress 插件权限提升漏洞（CVSS 9.8）

WP Component 插件 2.2.4 及以下版本在某 AJAX action 上未做能力检查或 nonce 验证，未认证用户可执行特权操作，可能导致权限提升和站点接管。

- **CVSS**：9.8
- **影响组件**：WP Component WordPress 插件 <= 2.2.4
- **与当前栈关联**：无直接关联。

### 6. CVE-2026-89266 — stb_vorbis 堆缓冲区溢出（CVSS 8.2）

stb_vorbis 1.22 及以下版本在 start_decoder() 函数中存在堆缓冲区溢出，处理构造的 Ogg Vorbis 文件时可导致崩溃或潜在的代码执行。该库常用于游戏引擎和多媒体应用中。

- **CVSS**：8.2
- **影响组件**：stb_vorbis <= 1.22
- **与当前栈关联**：无直接关联。当前栈不涉及 Ogg Vorbis 音频处理。
