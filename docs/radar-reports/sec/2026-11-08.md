## 今日高危漏洞

### 1. CVE-2026-97229 — GitLab CE/EE 整数溢出

GitLab Community Edition 和 Enterprise Edition 存在整数溢出漏洞，CISA 于 2026-10-29 将其收录进 KEV（已知被利用漏洞）目录。整数溢出在 Web 应用上下文中可被利用以绕过访问控制、实现权限提升，影响 GitLab 自托管实例的访问边界。

- **CVSS**：未确认（KEV 条目未给出分数）
- **影响组件**：GitLab CE/EE
- **与当前栈关联**：若内部使用自托管 GitLab 实例，需核对版本与补丁状态；若仅使用 SaaS 版（gitlab.com），影响有限。当前 Java 后端技术栈不直接使用 GitLab 组件，关联为未确认
- **来源等级**：official
- **来源名称**：CISA KEV（收录日期 2026-10-29）

### 2. CVE-2026-118527 — Ivanti Connect Secure 可预测随机数

Ivanti Connect Secure 存在可预测数字生成（PRNG）问题，CISA 于 2026-10-30 将其收录进 KEV。同日内 Ivanti Connect Secure 另一漏洞 CVE-2026-111357（关键功能缺失认证）也进入 KEV，两个条目均涉及 Ivanti 零信任网关。

- **CVSS**：未确认（KEV 条目未给出分数）
- **影响组件**：Ivanti Connect Secure
- **与当前栈关联**：当前基础设施是否使用 Ivanti 产品未确认；若使用则需立即核对补丁。未使用的情况下可忽略
- **来源等级**：official
- **来源名称**：CISA KEV（收录日期 2026-10-30）

### 3. CVE-2026-93754 — payever WooCommerce Gateway 任意文件上传（CVSS 9.8）

payever（WooCommerce Gateway）WordPress 插件存在任意文件上传漏洞，可导致远程代码执行。CVSS 9.8 为最高分档，属于典型的 WordPress 插件供应链类高危漏洞。

- **CVSS**：9.8
- **影响组件**：WordPress + payever WooCommerce Gateway 插件
- **与当前栈关联**：当前技术栈为 Java/Spring Boot/MySQL/Nginx/Node.js，不使用 WordPress；低相关
- **来源等级**：official
- **来源名称**：NVD

### 4. CVE-2026-17362 — IBM API Connect 远程攻击者可创建/修改/删除租户（CVSS 9.8）

IBM API Connect 12.1.0.0 至 12.1.1.2 存在缺失授权，远程攻击者可创建、修改或删除租户。CVSS 9.8 表明该漏洞可导致跨租户数据泄露。

- **CVSS**：9.8
- **影响组件**：IBM API Connect 12.1.0.0 - 12.1.1.2
- **与当前栈关联**：当前基础设施是否使用 IBM API Connect 未确认；未使用则无需动作
- **来源等级**：official
- **来源名称**：NVD
