## 今日高危漏洞

### 1. CVE-2026-93741 — Totolink A3002MU 路由器命令注入漏洞

Totolink A3002MU（固件 Hh-B20211125.1046）存在安全缺陷，攻击者可利用该漏洞在设备上执行任意命令，可能导致路由器被完全接管，进而对内网发起进一步攻击。

- **CVSS**：10.0
- **影响组件**：Totolink A3002MU 路由器固件
- **与当前栈关联**：不直接影响多乐士 CMS 技术栈，但如果办公网络使用该型号路由器，存在被接管后内网渗透的风险，建议排查办公网络设备型号。

### 2. CVE-2026-84434 — Gravity Forms WordPress 插件任意文件上传漏洞

Gravity Forms WordPress 插件 3.1 及之前所有版本存在任意文件上传漏洞，未经认证的攻击者可上传恶意文件（如 webshell），导致服务器远程代码执行。

- **CVSS**：9.8
- **影响组件**：Gravity Forms WordPress 插件（<= 3.1）
- **与当前栈关联**：与当前栈无直接关联（不使用 WordPress），但攻击模式（任意文件上传导致 RCE）值得作为安全测试参考。

### 3. CVE-2026-86591 — Botiga Pro WordPress 插件授权缺失漏洞

Botiga Pro WordPress 插件 1.6.5 之前版本在某 REST 路由上未执行授权检查，允许未认证用户调用受限功能，可能导致站点数据泄露或篡改。

- **CVSS**：9.8
- **影响组件**：Botiga Pro WordPress 插件（< 1.6.5）
- **与当前栈关联**：与当前栈无直接关联。但 REST API 授权缺失是通用模式，建议检查多乐士 CMS 后端 Spring Boot REST 接口是否有类似的授权缺失问题。

### 4. CVE-2026-89274 — WP Recipe Maker WordPress 插件任意 Shortcode 执行漏洞

WP Recipe Maker 插件在所有版本中存在任意 Shortcode 执行漏洞，攻击者可注入并执行任意 shortcode，可能导致服务器端代码执行和数据泄露。

- **CVSS**：9.1
- **影响组件**：WP Recipe Maker WordPress 插件
- **与当前栈关联**：与当前栈无直接关联。

### 5. CVE-2026-92229 — Forminator Forms WordPress 插件任意文件上传漏洞

Forminator Forms 插件存在任意文件上传漏洞，攻击者可上传任意文件到服务器，可能导致远程代码执行。

- **CVSS**：9.1
- **影响组件**：Forminator Forms WordPress 插件
- **与当前栈关联**：与当前栈无直接关联。

### 6. CVE-2026-93922 — SiYuan 笔记应用存储型 XSS 漏洞

SiYuan 3.8.4 及之前版本在 Daily Note 选择器对话框中将笔记本名称作为原始 HTML 渲染而未转义，攻击者可注入恶意脚本，在用户打开对话框时执行，可能导致数据泄露或会话劫持。

- **CVSS**：8.8
- **影响组件**：SiYuan 笔记应用（<= 3.8.4）
- **与当前栈关联**：与当前栈无直接关联。

### 7. CVE-2026-92807 — Save as PDF Plugin by PDFCrowd WordPress 插件任意函数调用漏洞

Save as PDF Plugin by PDFCrowd 插件在所有版本中存在任意函数调用漏洞，攻击者可调用 PHP 内置函数，可能导致远程代码执行。

- **CVSS**：8.8
- **影响组件**：Save as PDF Plugin by PDFCrowd WordPress 插件
- **与当前栈关联**：与当前栈无直接关联。

### 8. CVE-2026-87909 — WP Photo Album Plus WordPress 插件远程代码执行漏洞
