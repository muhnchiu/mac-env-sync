## 今日高危漏洞

### 1. CVE-2026-44756 — Extended Passport Protocol (EPP) 库内存安全漏洞

EPP 协议处理库在特定条件下存在内存安全漏洞，攻击者可利用此漏洞导致内存损坏，可能实现远程代码执行。该漏洞影响使用 EPP 协议的系统组件。

- **CVSS**：10.0
- **影响组件**：Extended Passport Protocol (EPP) 处理库
- **与当前栈关联**：无直接关联。多乐士 CMS 技术栈（Java/Spring Boot/MySQL/Nginx/Node.js）不涉及 EPP 协议。

### 2. CVE-2026-58240 — SAP NetWeaver Message Server 组件认证漏洞

SAP NetWeaver Message Server 未充分验证内部应用服务器组件的真实性，攻击者可伪装为合法应用服务器发起恶意请求，可能导致未授权访问和系统控制。

- **CVSS**：9.8
- **影响组件**：SAP NetWeaver Message Server
- **与当前栈关联**：无关联。SAP 生态系统，与多乐士 CMS 技术栈无关。

### 3. CVE-2026-86510 — D-Link DIR-822A L2TP 隧道参数注入漏洞

D-Link DIR-822A 路由器的 L2TP 隧道参数设置函数存在漏洞，攻击者可通过特制请求触发该漏洞，导致设备完全被控制。

- **CVSS**：9.9
- **影响组件**：D-Link DIR-822A（固件 A_101）
- **与当前栈关联**：无关联。网络设备漏洞，不影响服务器端应用栈。

### 4. CVE-2026-86509 — D-Link DIR-895L DHCP 功能漏洞

D-Link DIR-895L 路由器的 sendOffer/sendACK 函数存在漏洞，可被远程攻击者利用执行任意代码，获取设备控制权。

- **CVSS**：9.6
- **影响组件**：D-Link DIR-895L A1（固件 102b07）
- **与当前栈关联**：无关联。网络设备漏洞。

### 5. CVE-2026-76969 — @sap/cds-mtxs NPM 库多租户功能漏洞

SAP 的 @sap/cds-mtxs NPM 库在多租户 CAP 应用中未对特定功能执行充分检查，攻击者可利用此漏洞在多租户环境中提权或越权访问数据。

- **CVSS**：9.4
- **影响组件**：@sap/cds-mtxs（NPM 包）
- **与当前栈关联**：低风险。虽为 NPM 生态，但该包是 SAP CAP 框架专用，多乐士 CMS 前端（Next.js）不依赖此包。

### 6. CVE-2026-66768 — SAP GUI for Java 信任级别策略绕过

SAP GUI for Java 未正确执行从连接后端调用的某些功能的信任级别策略，攻击者可绕过安全限制执行未授权操作。

- **CVSS**：9.0
- **影响组件**：SAP GUI for Java
- **与当前栈关联**：无关联。虽涉及 Java，但为 SAP 客户端工具，与 Spring Boot 后端无关。

### 7. CVE-2026-76958 — SAP Integration Suite XML 文档验证不足

SAP Integration Suite 未充分验证来自不可信来源的 XML 文档，攻击者可通过特制 XML 文档触发解析漏洞，可能导致信息泄露或服务中断。

- **CVSS**：8.5
- **影响组件**：SAP Integration Suite
- **与当前栈关联**：无直接关联。SAP 集成平台，与当前技术栈无关。

### 8. CVE-2026-66767 — SAP NetWeaver ABAP 未授权请求漏洞

SAP NetWeaver Application Server for ABAP 允许未认证用户发送特制请求，可能导致信息泄露或服务中断。

- **CVSS**：7.7
- **影响组件**：SAP NetWeaver AS for ABAP / ABAP Platform
- **与当前栈关联**：无关联。SAP/ABAP 生态系统。
