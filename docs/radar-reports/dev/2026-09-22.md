## 今日最值得关注

### 1. Claude Code v2.1.277 — AGENTS.md 支持

Claude Code v2.1.277 新增 AGENTS.md 支持：当项目没有 CLAUDE.md 时，Claude Code 自动读取 AGENTS.md。这与 OpenClaw 的 AGENTS.md 工作流完全对齐。同时新增 send-now 快捷键（ctrl+enter）、skills/plugins 从 claude.ai 同步到终端会话、以及 gateway 上游静态 headers 支持。

- **类型**：AI Coding / Agent
- **开放情况**：闭源，Claude 订阅
- **核心变化**：AGENTS.md 原生支持 + skills/plugins 云端同步 + send-now 快捷键
- **价值判断**：AGENTS.md 支持意味着 Claude Code 和 OpenClaw 的 workspace 约定完全统一，不再需要维护两套文件
- **与当前栈关联**：直接相关 — 当前 OpenClaw workspace 使用 AGENTS.md，Claude Code 原生支持后不再需要 CLAUDE.md 桥接
- **建议**：升级 — 确认 v2.1.277+ 已生效，验证 AGENTS.md 读取行为

### 2. Claude Code v2.1.278 — Auto Mode 服务端分类器

v2.1.278 将 auto mode 默认切换到服务端分类器，不再为分类器开销计费。Bedrock/Vertex/Foundry/gateway 用户也可通过 CLAUDE_CODE_AUTO_MODE_SERVER=0 退出。/status 新增 auto mode 服务端行显示分类器运行位置。

- **类型**：AI Coding / Agent
- **开放情况**：闭源，Claude 订阅
- **核心变化**：Auto mode 分类器从客户端移到服务端，不再计费分类器开销
- **价值判断**：降低 auto mode 使用成本，改善计费透明度
- **与当前栈关联**：直接相关 — 当前使用 Claude Code auto mode
- **建议**：升级 — 确认 v2.1.278 生效，检查 /status 中 auto mode server 行

### 3. GitHub Changelog — Grok 4.7 进入 Copilot + 部分模型弃用

GitHub Copilot 新增 Grok 4.7（xAI 最新推理模型），定位为 agentic coding 和复杂多步工作流。同时公告 10 月 19 日将弃用部分旧 Copilot 模型。Copilot code review 改进：更清晰的变更时间线、智能自动解决建议、接受建议时生成 commit message。

- **类型**：AI Coding / GitHub
- **开放情况**：GitHub Copilot 订阅
- **核心变化**：Grok 4.7 进入 Copilot + 旧模型弃用 + code review 改进
- **价值判断**：模型选择扩大，但旧模型弃用可能影响 Copilot 使用习惯
- **与当前栈关联**：间接相关 — 当前主力是 Claude Code，但 Copilot 模型弃用需关注
- **建议**：跟踪观察 — 10 月弃用前确认是否有影响

### 4. Foremerge — 并行 Agent 意图冲突检测

Show HN 项目，检测多个 coding agent 并行修改代码时的意图冲突。当多个 AI agent 同时操作时，分析各 agent 的修改意图，在合并前发现逻辑冲突。42 points, 14 comments。

- **类型**：AI Coding / Agent
- **开放情况**：开源
- **核心变化**：新项目，解决多 agent 并行编程的实际痛点
- **价值判断**：当前 OpenClaw sub-agent 架构可能触发并行修改场景，方向有价值
- **与当前栈关联**：间接相关 — sub-agent 并行编程场景目前不多但未来可能增加
- **建议**：跟踪观察 — 等多 agent 并行场景增多后再评估

### 5. GitHub Changelog — Agentic CLI 自定义指标进入 Usage API

GitHub Copilot CLI 新增 agentic 活动指标：skills、custom agents、MCP servers、slash commands、plugins 的使用量数据进入 Usage Metrics API。同时新增 npm stage-only token 和 PR 页面改版 GA。

- **类型**：DevOps / GitHub
- **开放情况**：GitHub Enterprise
- **核心变化**：CLI agentic 指标可查 + npm token 更安全 + PR 页面改版
- **价值判断**：agentic 指标可观测性提升，对监控 Agent 使用情况有参考价值
- **与当前栈关联**：间接相关 — MCP/agent 使用指标可参考
- **建议**：跟踪观察
