## 今日最值得关注

### 1. codenotch (GitHub 1386 stars, Swift)

一款 macOS 原生应用，可在菜单栏实时显示 Claude Code、Cursor、Codex 等工具的使用量限制和剩余配额。解决了多工具并行使用时难以追踪各自额度的问题，界面简洁，原生 Swift 实现。

- **类型**：macOS 应用 / AI 编程工具辅助
- **价值判断**：直接解决 AI 编程工具用量焦虑，多工具用户刚需
- **与当前栈关联**：日常使用 Claude Code，配额监控正好补充 OpenClaw 生态

### 2. okf-agent-memory (GitHub 549 stars, Go)

为 AI 编码代理提供 Git 原生的持久化记忆。将记忆文件直接存于 Git 仓库中，实现跨会话、跨项目的上下文延续。实现了 Google OAuto 的相关协议规范。

- **类型**：CLI / AI 编程工具基础设施
- **价值判断**：Git-native 思路比数据库方案更轻量，与 AGENTS.md/MEMORY.md 模式高度契合
- **与当前栈关联**：OpenClaw 的 memory 体系可借鉴其 Git-native 设计理念

### 3. tokentab (GitHub 245 stars, Python)

一个 CLI 工具，读取 Claude Code、Codex 和 Gemini CLI 的会话日志，生成 token 用量统计表格。帮助开发者直观了解各工具的 token 消耗分布。

- **类型**：CLI / AI 编程工具辅助
- **价值判断**：token 成本可视化是 AI 编程工具管理的关键一环
- **与当前栈关联**：直接适用于 Claude Code 使用分析，辅助优化 token 消耗策略

### 4. anything2explainer (GitHub 711 stars, TypeScript)

一个 Claude Code / Codex 的 skill，输入任意主题，自动生成带旁白的讲解视频。将复杂概念快速可视化，适合知识分享和文档制作。

- **类型**：AI 编程工具 Skill
- **价值判断**：将 AI 编程工具能力延伸到内容创作领域，拓展了 skill 边界
- **与当前栈关联**：可作为 OpenClaw skill 生态的参考案例，展示 skill 的非编程应用

### 5. claude-adhd (GitHub 100 stars, JavaScript)

为 Claude Code 设计的扩展，在会话开始时提醒用户上次未完成的线程和任务。解决 AI 编程工具会话间上下文断裂的问题，减少遗忘和重复工作。

- **类型**：IDE 扩展 / AI 编程工具辅助
- **价值判断**：直击多会话工作流的痛点，轻量实用
- **与当前栈关联**：与 OpenClaw 的 memory 延续机制目标一致，可对比实现思路

### 6. PlanBridge (Hacker News, Show HN)

开源工具，对 AI 编码代理的计划（plan）提供精准反馈。帮助开发者在代理执行前审查和修正计划，减少方向性错误。

- **类型**：CLI / AI 编程工具辅助
- **价值判断**：在 agentic coding 流程中增加人类审查节点，提升安全性和效率
- **与当前栈关联**：Claude Code 的 plan 模式可结合使用，多乐士后端开发中减少返工

### 7. Cordium (Hacker News, Show HN)

自由开源的自托管沙箱平台，定位为 GitHub Codespaces / E2B / Daytona 的替代方案。支持自建开发环境隔离沙箱，数据完全自主掌控。

- **类型**：开发环境基础设施
- **价值判断**：自托管方案适合有安全要求的团队，但运维成本需评估
- **与当前栈关联**：多乐士测试环境可考虑用于隔离构建，但当前优先级不高

### 8. Finterm.ai (Hacker News, Show HN)

定位为 "Claude Code 的 Bloomberg 终端"，在终端中以仪表盘形式展示 Claude Code 的使用指标、成本分析、会话历史等。将分散的 CLI 数据整合为可视化面板。

- **类型**：CLI / AI 编程工具辅助
- **价值判断**：终端内可视化是 CLI 工具的好搭档，信息密度高
- **与当前栈关联**：Claude Code 深度用户的管理利器，与 codenotch 互补

### 9. Shine (Hacker News, Show HN)

终端 Markdown 预览器和文档 linter，直接在终端中渲染 Markdown 并检查文档规范。轻量、无需浏览器，适合 CLI 工作流。

- **类型**：CLI / 文档工具
- **价值判断**：终端 Markdown 渲染 + lint 一体化，减少上下文切换
- **与当前栈关联**：日常在 Ghostty 中工作，编写文档和 README 时直接预览，减少切窗

### 10. CodePress (Hacker News, Show HN)

声称可每月节省 $50k+ 的 Cloud Agents 成本方案，针对云端 AI 代理执行的成本优化。通过本地化调度和缓存策略降低云端调用费用。

- **类型**：AI 编程工具 / 成本管理
- **价值判断**：数字夸张但方向值得关注，云 agent 成本是真实痛点
- **与当前栈关联**：token 成本管理一直重要，可关注其优化策略
