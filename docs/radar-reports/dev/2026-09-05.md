## 今日最值得关注

### 1. profullstack/hqtui

TypeScript 编写的终端 UI 框架，定位为"btop-grade terminal dashboard"，可构建高质量终端仪表盘。200 星，本周新仓。

- **类型**：npm 包 / CLI 工具
- **价值判断**：终端 UI 正在复兴，这个库可能成为 ink/blessed 之外的现代替代方案。
- **与当前栈关联**：OpenClaw 和 Claude Code 都重度依赖终端交互，hqtui 可用于构建自定义终端仪表盘或 monorepo 状态监控面板。

### 2. op7418/guizang-yingzao-skill

Claude Code / Codex 的 skill 插件，专注中国古建筑文化建模。317 星，Python。展示了 Skill 生态向非编程领域扩展的趋势。

- **类型**：AI 编程工具扩展
- **价值判断**：Skill 生态正在从纯开发工具向创意/文化领域渗透，说明 Claude Code Skill 模式已被社区接受并扩展。
- **与当前栈关联**：直接关联 OpenClaw 和 Claude Code 的 Skill 体系，可参考其 Skill 结构设计模式。

### 3. gozen3ji/consulting-pptx-skill

另一个 Claude Code Skill，专注于用 AI 生成规范 PPTX，包含 62 种幻灯片模板。216 星，JavaScript。

- **类型**：AI 编程工具扩展
- **价值判断**：将 AI 生成能力落地到具体文档格式，实用性强。
- **与当前栈关联**：Skill 生态的文档生成方向，可借鉴其模板化思路用于飞书文档自动化。

### 4. lnkiai/m3e-canvas

浏览器内 Material 3 Expressive 设计稿草图工具，可直接转换为代码。1974 星，TypeScript，本周爆款。

- **类型**：前端工具 / 设计到代码
- **价值判断**：设计到代码的工作流一直是热点，Material 3 Expressive 是 Google 最新设计语言。
- **与当前栈关联**：多乐士前端项目如需 Material Design 风格组件，可试用此工具加速原型设计。

### 5. TokensBurned (Parsifal1986)

隐私优先的 AI 编码活动追踪器，在 GitHub Profile 展示 AI 编码占比。107 星，JavaScript。

- **类型**：CLI / GitHub Profile 工具
- **价值判断**：轻量有趣，量化 AI 辅助编码的比例，适合个人开发者自省。
- **与当前栈关联**：可量化 Claude Code / OpenClaw 在日常编码中的实际参与度。

### 6. PlanBridge (Hacker News Show HN)

开源工具，对 AI 编码 agent 的计划提供精确反馈，定位为 coding agent plan 的质量评估层。

- **类型**：AI 编程工具 / 测试框架
- **价值判断**：填补了 AI agent 生成计划的质量评估空白，属于 AI 编程工具链的补全方向。
- **与当前栈关联**：可评估 Claude Code 生成的执行计划质量，辅助 Skill 设计和 review 流程。

### 7. Cordium (Hacker News Show HN)

开源自托管沙箱平台，定位为 Codespaces / E2B / Daytona 的替代方案。

- **类型**：DevOps 工具 / 沙箱
- **价值判断**：自托管开发环境是降本和控数据的关键方向，开源替代 SaaS 沙箱有实际需求。
- **与当前栈关联**：OpenClaw 的 exec 沙箱机制可参考，或作为多乐士测试环境的隔离方案。

### 8. Personal Context MCP (Hacker News Show HN)

MCP (Model Context Protocol) 的个人上下文实现，让 AI agent 获取个人数据。

- **类型**：AI 编程工具 / MCP 服务
- **价值判断**：MCP 生态持续扩展，个人上下文 MCP 是 OpenClaw 工作区模式的另一种实现路径。
- **与当前栈关联**：与 OpenClaw 的 AGENTS.md / SOUL.md / MEMORY.md 体系理念一致，可对比设计思路。

### 9. Sageling (Hacker News Show HN)

- **类型**：AI 编程工具 / 本地推理
- **价值判断**：Mac 本地推理 agent 的新尝试，MLX 路线值得关注。
- **与当前栈关联**：与 MacMini 硬件直接相关，可关注其本地推理性能表现。

### 10. Coder Eval (Hacker News Show HN)

专用于 AI 编码 agent 的 Eval 框架。

- **类型**：测试框架
- **价值判断**：AI 编码工具的评估标准化是行业刚需，目前缺乏统一基准。
- **与当前栈关联**：可用于评估不同 model 在 OpenClaw 下的实际编码能力差异。
