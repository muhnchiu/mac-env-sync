### 1. Claude Code v2.1.301（2026-10-15）

Claude Code 官方 Release。v2.1.301 增加无人值守重试看门狗的环境变量（CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS，在用量限额重置太远时结束请求而非空等）、vim 模式 % 括号跳转、OpenTelemetry 追踪指引；修复 worktree 退出误删、Grep/Glob 空匹配、VTE 终端杂字符、iTerm2 杂字符等问题。对无人值守 AI 编程工作流和终端稳定性直接相关。

- **类型**：AI 编程工具
- **价值判断**：无人值守重试与终端修复提升长时间批量任务的可靠性
- **与当前栈关联**：当前 AI Coding 工作流核心工具链之一，升级可降低中断成本
- **来源等级**：official
- **来源名称**：GitHub Releases (anthropics/claude-code)

### 2. Claude Code v2.1.300（2026-10-14）

官方 Release。mods 装饰增加 virtualText（渲染在提示框内但不进入草稿/提交文本）、/advisor 命令（Claude Platform on AWS，按需启用）、OpenTelemetry 缓存写入按时长拆分（cache_creation_5m/1h_tokens）、RTL 文本支持；修复会话压缩与用量信用问题。

- **类型**：AI 编程工具
- **价值判断**：mods 扩展能力与可观测性增强，适合定制工作流
- **与当前栈关联**：mods 机制可用于扩展当前 AI Coding 工作流
- **来源等级**：official
- **来源名称**：GitHub Releases (anthropics/claude-code)

### 3. Claude Code v2.1.299 空闲压缩（2026-10-14）

官方 Release。终端内 200K+ token 的会话闲置约 54 分钟后、在一小时 prompt cache 过期前自动压缩，避免下一条消息全量重处理。可用 CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS 调整阈值，或设置 "idleCompaction": false 关闭。

- **类型**：AI 编程工具
- **价值判断**：直接降低长会话的 token 成本，行为可配置
- **与当前栈关联**：与当前 AI Coding 工作流的高 token 消耗场景直接相关
- **来源等级**：official
- **来源名称**：GitHub Releases (anthropics/claude-code)
