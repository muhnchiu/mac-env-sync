## 今日最值得关注

### 1. fast-jev-compaction

Claude Code 插件，用 Jev 决策树替换默认的 compaction summary 机制，让上下文压缩更精准、减少信息丢失。对于长期会话和大型项目频繁触发 compaction 的场景，能显著提升上下文保留质量。

- **类型**：IDE 扩展 / AI 编程工具插件
- **价值判断**：解决 Claude Code 长会话上下文压缩的痛点，实用性强
- **与当前栈关联**：直接增强 Claude Code 使用体验，适合日常开发流程

### 2. jev-review

基于 staged code-review 的工作流工具，带本地 dashboard，用 TypeSafe 构建。提供结构化的代码审查流程，适合在 AI 辅助开发中建立质量门禁。

- **类型**：CLI / 开发者工具
- **价值判断**：把 code review 流程化、可视化，对 AI 辅助开发质量把控有价值
- **与当前栈关联**：可与 Claude Code 工作流结合，作为提交前质量检查环节

### 3. jev-router

为 Claude Code 提供模型路由能力，根据任务类型自动选择最便宜的模型，降低 API 成本。轻量级方案，配置简单。

- **类型**：CLI / AI 编程工具
- **价值判断**：直接降低 Claude Code 使用成本，ROI 明确
- **与当前栈关联**：与当前 Claude Code + 多模型使用场景直接相关

### 4. gap-trap

把 vibe coding 转化为高质量代码的工具，在项目中设置规则和门禁，自动检查 AI 生成代码的质量。适合在 AI 辅助开发中建立工程规范。

- **类型**：CLI / 开发者工具
- **价值判断**：AI 编程质量保障方向，解决 vibe coding 产出质量不可控的问题
- **与当前栈关联**：可作为 Claude Code / OpenClaw 工作流的质量门禁补充

### 5. CRT (Code Review Tool)

HN Show HN 新品，本地代码审查工具，专为 agentic development 场景设计。对 AI agent 产生的代码变更进行审查，适合 AI 密集开发场景。

- **类型**：CLI / 代码审查工具
- **价值判断**：针对 AI agent 开发场景的 code review，方向新颖
- **与当前栈关联**：与 OpenClaw / Claude Code agent 工作流互补

### 6. Agentgit

HN 热门（7 分），为 AI agent 设计的 Git 托管服务，无需账号、token、key。agent 可以直接 push 代码，降低 AI 编程的版本管理门槛。

- **类型**：服务 / 开发者工具
- **价值判断**：解决 AI agent 的代码托管痛点，思路独特
- **与当前栈关联**：可为 OpenClaw agent 自动化提交提供更简洁的 git 工作流

### 7. PlanBridge

开源工具，对 coding agent 的计划提供精确反馈。帮助开发者在 AI agent 执行前审查和校正计划，减少错误执行。

- **类型**：CLI / 开发者工具
- **价值判断**：AI agent 计划审查方向，提升 agent 执行准确率
- **与当前栈关联**：与 OpenClaw / Claude Code 的 plan 机制互补

### 8. TypeSeer

macOS 本地运行的自动补全工具，为所有文本输入框提供 on-device 补全。不依赖云端，隐私友好。

- **类型**：桌面应用 / 输入工具
- **价值判断**：全系统级别的 AI 补全，覆盖面广
- **与当前栈关联**：作为 Ghostty + VS Code Insiders 之外的系统级输入增强

### 9. ToolReplay

审计 AI agent 工具调用记录的工具，提供 hash-chain 密封和确定性回放。适合需要审计 AI agent 行为的场景。

- **类型**：CLI / 审计工具
- **价值判断**：AI agent 行为审计方向，对安全合规有价值
- **与当前栈关联**：可用于审计 OpenClaw / Claude Code 的 tool call 链路

### 10. OnPanda

开源平台，在 token 级别引导和操控 LLM 及 agent 行为。提供细粒度的模型行为控制能力。

- **类型**：服务 / AI 编程工具
- **价值判断**：token 级别的模型引导，技术方向前沿
- **与当前栈关联**：可作为 OpenClaw / Claude Code 模型行为优化的研究工具

## npm 下载趋势
