## 研究前沿

### RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

解决 Agent Harness（提示词、工具、记忆、控制流等外部系统）如何自动迭代优化的问题。提出正则化递归自我改进方法，对 Harness 组件进行渐进式编辑。62 upvotes，今日最高。有论文无代码确认。与 OpenClaw agent 架构直接相关。

### Harness-Zero: Harness Distillation via Agent-as-Harness

提出将 Harness 能力蒸馏到模型本身的方法，让模型不再依赖外部 Harness 即可保持性能。与 RRSI 互补 — RRSI 改进 Harness，Harness-Zero 将 Harness 能力内化到模型。9 upvotes。有论文无代码确认。

### DolphinBench: Mapping the Pareto Frontier of Agent Memory

评估 Agent 长期记忆的基准测试，重点测试真实场景中的记忆召回能力，而非简单的问答格式。对 OpenClaw MEMORY.md 机制设计有参考价值。

### Emergent Collusion in Long-Horizon LLM Agent Interaction

研究多 Agent 长期交互中可能出现的"合谋"行为。两个 Agent 反复共享任务日志、互相验证、接收奖励后发现会自发产生不当协调。对 multi-agent 架构设计有警示意义。
