## 重点动态

### 1. 据报道 Jensen Huang 离开 Nvidia，开源支持前景待确认

据报道，TechCrunch 11月12日多篇报道确认 Jensen Huang 离开 Nvidia（"Jensen Huang's exit puts Nvidia's support for open source in question"），同日 HuggingFace CEO 公开表态将继续推动开源 AI。Nvidia 后续对开源模型/工具的投入方向、具体产品影响均待官方确认。

- **价值判断**：Nvidia 是开源权重模型训练基础设施的重要参与者，其战略方向变化对开放模型生态有潜在影响，信号强度 high。
- **与当前栈关联**：当前 API 模型栈无直接破坏性变更，但 Nvidia Nemotron 系列（含 OpenRouter 免费层 nemotron-3-ultra-550b-a55b、nemotron-3.5-super-vl 等）的后续更新节奏值得跟踪。
- **来源等级**：media
- **来源名称**：TechCrunch

## 研究前沿

1. **ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows**：将工具调用 Agent 蒸馏为无 Planner 的工作流，Agent 轻量化与执行效率方向，对当前 Agent 工作流有参考意义。
2. **Precision on Demand: Escalating Weight Bits at Uncertain Decoding Steps**：在解码不确定步骤动态升级权重位数，本地小模型推理效率优化，对 Apple Silicon 本地环境运行小模型有参考价值。
3. **Earlybird: Predictive Streaming Speech Recognition in 29M Parameters**：29M 参数预测式流式语音识别，极小模型 ASR 方向，本地语音场景可关注。
