# AI 雷达日报 2026-09-04

## 重点动态

**1. OpenAI 发布 Astra 新模型**
TechCrunch 报道 OpenAI 推出 Astra，被描述为"强大但有争议"的新模型。可能是多模态推理方向的旗舰级更新。值得持续关注其 API 定价和能力基准。与我当前模型栈：如果 Astra 开放 API，可作为 OpenAI 侧的升级选项测试，替代现有 GPT 系列调用。

**2. Nvidia 确认 129 亿美元收购 Hugging Face**
重磅行业事件。Nvidia 将 HF 纳入版图，意味着模型托管+推理生态进一步集中。短期内不影响百炼/OpenAI 使用，但长期看开源模型托管平台的中立性可能受影响。收藏关注即可。

**3. GLM-5.3 及 GLM-5.3-Flash 登顶 HF 热门模型**
zai-org 发布 GLM-5.3（15 万下载）和 GLM-5.3-Flash（51 万下载），均为近期上传。我当前主力是百炼 glm-5.2，GLM-5.3 是直系升级。**建议立即测试百炼是否已开放 GLM-5.3 接口**，能力提升值得切换主力。

**4. Qwen3.8-Flash-Next 发布**
Qwen3.8-Flash-Next（26 万下载）和 Qwen3.8-27B（525 万下载）持续热门。Qwen3.8-27B 的 unsloth GGUF 量化版下载量高达 955 万，说明本地部署需求旺盛。与百炼栈：可关注百炼是否上线 Qwen3.8-Flash-Next。

**5. OpenRouter 新增多个免费模型**
- `z-ai/glm-5.2:free` — 我当前模型免费版，可做备用
- `google/gemma-4-26b-a4b-it:free` — Google 新开源模型
- `nvidia/nemotron-3-ultra-550b-a55b:free` — Nvidia 大模型免费
- `thinkingmachines/inkling:free` — Thinking Machines 初创公司产品
- `cohere/north-mini-code:free` — Cohere 代码模型
值得在 OpenRouter 上测试 inkling 和 nemotron-3-ultra 的实际表现。

**6. Thinking Machines 融资 10 亿美元（估值 400 亿）**
Accel 领投，这家初创公司同时在 OpenRouter 上提供免费模型。资金充足+产品可见，值得收藏关注其走向。

**7. Fable Orchestrator（GitHub 325 星）**
编排 GPT-5.6 Luna 和 DeepSeek V4 Flash 的多模型编排框架。对于多模型栈（百炼+OpenAI+Agnes）有参考价值，可研究其编排模式。

**8. reverify（GitHub 769 星）— AI Agent 反幻觉工具**
针对读取二进制的 AI agent 做反幻觉。虽然场景偏窄，但反幻觉思路对 agent 生态有借鉴价值。

## 开源模型新趋势

| 模型 | 参数量 | 许可证 | Mac 本地可跑 |
|------|--------|--------|-------------|
| GLM-5.3 / 5.3-Flash | 未明确 | 待确认 | Flash 版本大概率可跑 |
| Qwen3.8-27B | 27B | Apache 2.0 | 可以，GGUF 量化版已大量下载 |
| Qwen3.8-Flash-Next | 未明确 | 待确认 | Flash 系列优化推理，应可跑 |
| DeepSeek-V4-Flash-Vision-Exp | 未明确 | 实验版 | 视觉模型，需较大显存 |
| Gemma 4 26B (A4B) | 26B (A4B MoE) | Google 开源 | 可以，MoE 架构激活参数仅 4B |
| Nemotron 3 Ultra 550B (A55B) | 550B (A55B MoE) | Nvidia 开源 | 太大，Mac 跑不了完整版 |
| LTX-2.5 | 未明确 | 待确认 | 视频生成模型，需 GPU |
| Breeze-TTS-2 | 未明确 | 待确认 | TTS 模型，轻量可能可跑 |

趋势：MoE 架构成为主流（Gemma 4 A4B、Nemotron A55B），大总参数+小激活参数，让大模型在有限硬件上可推理。Qwen3.8-27B 的 unsloth GGUF 下载量近千万，说明本地部署需求强劲。
