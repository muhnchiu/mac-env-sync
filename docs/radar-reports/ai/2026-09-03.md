## 重点动态

### 1. GLM-5.3 发布（zai-org，08-25）

GLM-5.3 及 GLM-5.3-Flash 已上架 HuggingFace，Flash 版下载量已达 44 万。Flash 为 image-text-to-text 多模态模型，标准版纯文本。GLM-5.3-Flash 的 GGUF 量化版也已由 unsloth 发布（6.3 万下载）。

- **价值判断**：这是我当前主力模型 GLM-5.2 的下一代，百炼平台上线是时间问题。Flash 多模态能力（图文理解）是显著增量。
- **与当前栈关联**：百炼 GLM-5.2 → 可关注百炼是否已开放 GLM-5.3 试用；OpenRouter 上 GLM-5.2 已免费，5.3 免费可期。建议等百炼官方支持后切换主力。

### 2. Qwen3.8 系列爆发（Qwen，08-24/08-05）

Qwen3.8-27B 下载量近 500 万，Flash-Next 版 20 万下载，均为 image-text-to-text。unsloth 的 GGUF 量化版下载量高达 935 万，社区热度极高。已有多个 uncensored 变体。

- **价值判断**：27B 参数量可在 Mac 上量化运行（4-bit 约 16GB），是本地部署的强力选项。
- **与当前栈关联**：作为本地备选模型值得收藏；Flash-Next 可关注 OpenRouter 是否提供免费额度。

### 3. DeepSeek-V4-Flash-Vision-Exp（08-31）

DeepSeek 发布 V4 实验版多模态模型，1.8 万下载。继 V3 之后 V4 首次加入视觉能力。

- **价值判断**：DeepSeek 一向以高性价比著称，V4 多模态值得跟踪其正式版发布。
- **与当前栈关联**：百炼已支持 DeepSeek 系列，正式版上线后可作为备用多模态选项。

### 4. OpenRouter 免费模型扩容

新增/值得关注的免费模型：

- **z-ai/glm-5.2:free** — 我当前用的模型已免费，可直接用 OpenRouter 替代百炼调用
- **google/gemma-4-26b-a4b-it:free** — Gemma 4 新版，26B MoE 架构
- **nvidia/nemotron-3-ultra-550b-a55b:free** — NVIDIA 550B 大模型免费
- **minimax/minimax-m3:free** — MiniMax M3 免费
- **cohere/north-mini-code:free** — Cohere 代码模型
- **thinkingmachines/inkling:free** + **inkling-small:free** — Thinking Machines 新玩家
- **poolside/laguna-s-2.1:free** + **laguna-xs-2.1:free** — Poolside 模型

- **价值判断**：免费池持续扩大，GLM-5.2 免费意味着可以零成本兜底。Gemma 4 26B 和 Nemotron Ultra 值得试用对比。
- **与当前栈关联**：可作为低优先级任务/测试的备用通道。

### 5. MiniMax-H3 + LTX-2.5（视频生成）

MiniMax-H3（image-text-to-video，550 万下载）和 LTX-2.5（image-to-video，123 万下载）热度高。FastVideo 已出 H3 四步加速版。

- **价值判断**：视频生成赛道竞争白热化，MiniMax H3 是当前社区最热选择。
- **与当前栈关联**：视频生成不在当前主栈，LTX-2.5 开源权重可本地部署，有需求时作为候选。

### 6. GitHub 趋势：slotstream — Mac 上跑 Qwen3.8-Flash-Next 125B MoE

⭐246，专门解决在 Mac 上运行 125B MoE 模型（4-bit 约 104GB），对 Mac 用户有直接价值。

- **价值判断**：如果 Mac Mini 有足够内存，这是跑大模型的实操方案。
- **与当前栈关联**：⭐ 强相关，本机 Mac arm64，值得实测。

### 7. OpenAI 安全争议 & 版权判决

TechCrunch 报道 OpenAI 新推理技术引发安全专家担忧；美国政府支持 OpenAI 在版权材料上训练 LLM。

- **价值判断**：政策层面的重大信号，版权训练合法化趋势利好闭源大模型迭代速度。
- **与当前栈关联**：间接影响——闭源模型迭代加速，百炼/OpenAI 侧模型能力提升可期。

### 8. 学术关注：Agent Memory 授权洗白

HuggingFace 热门论文揭示 Agent Memory 可成为授权洗白攻击面——对 Agent 框架安全设计有警示意义。

- **价值判断**：对使用 memory 机制的 agent 系统有安全参考价值。
- **与当前栈关联**：OpenClaw 的 memory 机制也涉及信任边界，值得关注防护思路。
