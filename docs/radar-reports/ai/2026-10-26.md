## 重点动态

### 1. OpenAI 称不再用实时互联网训练模型

据报道，OpenAI 表示将不再在实时互联网上训练模型，理由是存在显著风险。该消息目前仅看到 TechCrunch 报道口径，未检索到官方原始公告，具体范围、替代数据策略和生效时间待确认。

- **价值判断**：若属实，会影响后续模型数据新鲜度与实时信息能力预期，需要跟踪官方口径。
- **与当前栈关联**：当前 API 模型栈若依赖强实时信息，应保留 web search 或实时检索层作为兜底。
- **来源等级**：media
- **来源名称**：TechCrunch

### 2. Grok 发布 AI 生成作品《Odyssey》前七分钟

据报道，Grok 发布了其 AI 生成作品 Odyssey 的前七分钟内容。该动态主要反映多模态生成与长内容生成能力，属于能力展示型发布，是否形成可稳定调用的 API 能力待确认。

- **价值判断**：多模态长内容生成能力信号较强，但商业接口与质量基线未确认。
- **与当前栈关联**：可作为视频/多模态生成能力观察项，暂不进入生产 API 栈。
- **来源等级**：media
- **来源名称**：TechCrunch

### 3. Block 新语音模型接近人类表现

据报道，Block 发布了新的语音模型，媒体报道称其听感接近人类。目前未见官方技术报告或可公开调用入口，实际质量、延迟、成本与授权方式待确认。

- **价值判断**：语音合成方向值得跟踪，但现阶段缺少可验证指标。
- **与当前栈关联**：若当前工作流有语音输出需求，可先做小样本试听，不急于接入。
