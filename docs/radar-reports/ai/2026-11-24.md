## 研究前沿

1. **MemOnce：面向 LLM 的可扩展记忆架构**（Chang Nie 等）——提出可扩展的 LLM 记忆架构，针对长上下文 Agent 的记忆管理问题，是长程 Agent 工作流的基础方向。
2. **Non-penetrating World Models**（Yuhang Dai 等）——探讨非穿透式世界模型，与 Agent 对环境的建模方式相关。
3. **arXiv cs.LG：Don't Discard Your Rollouts: Reusing Teacher RL Traces for Student Distillation**——研究复用教师 RL 轨迹进行学生蒸馏，对推理成本与训练效率有潜在影响。另有 LEAN（基于库的异步联邦微调）与 Depth-Linked Residual Tokens for Multimodal Retrieval and Generation 值得关注。
