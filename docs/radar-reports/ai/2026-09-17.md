## 重点动态

### 1. DeepSeek-V4.1-Flash 发布，多模态图文理解

DeepSeek 发布 V4.1-Flash 版本，定位为 image-text-to-text 多模态模型，上线 HuggingFace 即获 36 万次下载。这是 DeepSeek V4 系列的轻量快速变体，延续了其高性价比路线。

- **价值判断**：DeepSeek 持续在开源多模态领域发力，Flash 版本通常意味着推理成本显著降低，适合大批量调用场景。
- **与当前栈关联**：百炼平台若接入可作为多模态备选；当前栈以文本为主，该模型填补了图文理解的低成本选项。

### 2. GLM-5.2 登录 OpenRouter 免费模型列表

OpenRouter 免费模型新增 `z-ai/glm-5.2:free`，即智谱 GLM-5.2 可通过 OpenRouter 免费调用。同时还有 Nex-N2.5-Mini/Pro、Ling 3.0 Flash VL 等多款新免费模型上架。

- **价值判断**：GLM-5.2 免费可用意味着可以直接通过 OpenRouter 做 A/B 测试和 fallback，零成本验证效果。
- **与当前栈关联**：当前主力模型即 GLM-5.2（百炼渠道），OpenRouter 免费版可作为备用通道，提升可用性。

### 3. JustFit：24GB 显存服务 200K Token 上下文

HuggingFace 热门论文 JustFit 提出"即时状态管理"方案，实现在 24GB 显存笔记本上服务 200K token 上下文的 LLM，通过按需加载 KV 状态大幅降低内存占用。

- **价值判断**：长上下文推理的内存瓶颈一直是本地部署痛点，该方案若工程化落地将显著降低硬件门槛。
- **与当前栈关联**：Mac Mini 本地部署长上下文模型时可参考该方案；当前百炼 API 调用不受显存限制，但对本地实验有价值。

### 4. Anthropic 合并 Claude Chat 与 Cowork 界面

TechCrunch 报道 Anthropic 将 Claude 对话界面与 Cowork（多 agent 协作）功能合并为统一界面，意味着用户可在同一会话中切换单轮对话与多 agent 编排。

- **价值判断**：产品形态向"对话即编排"演进，降低了多 agent 使用门槛，是 AI 工具产品化的重要趋势。
- **与当前栈关联**：Agnes（agent 框架）可借鉴该思路，在统一交互层支持从简单对话到复杂编排的无缝切换。

### 5. Edge0-35B-A3B-preview：MoE 架构 35B 总参/3B 激活

Edge0 发布 35B 参数 MoE 模型预览版，每次推理仅激活 3B 参数，兼顾大模型容量与低推理成本。上线即获近 2.8 万下载。

- **价值判断**：MoE 架构在中型模型规模上持续验证有效性，3B 激活量意味着推理成本接近小模型但能力接近大模型。
- **与当前栈关联**：若百炼后续支持 MoE 部署，可关注其性价比表现；当前栈无需本地部署此规模模型。

### 6. AgentVerse-OS：开发者个人云 OS for AI Agents

GitHub 新仓库 AgentVerse-OS（679 星）定位为"开发者和其 AI agents 的个人云操作系统"，在单一平台上管理多个 agent 的生命周期、资源和协作。

- **价值判断**：Agent 基础设施正在从框架层向操作系统层演进，类似早期 Docker 之于容器化，值得早期关注。
- **与当前栈关联**：OpenClaw 本身已具备 agent 管理能力，可参考其架构设计思路，评估是否有可借鉴的资源调度方案。

### 7. AI Agent 可控制 Google Home 设备

TechCrunch 报道 AI agents 现已可控制 Google Home 智能设备，标志着 AI agent 从数字世界向物理 IoT 场景延伸。

- **价值判断**：AI agent 与 IoT 结合是智能家居自动化的关键一步，但隐私和安全审计仍是核心顾虑。
- **与当前栈关联**：若后续需要扩展 agent 能力到 IoT 控制，可关注 Google Home API 的开放程度和鉴权机制。

## 开源模型新趋势

| 模型 | 参数量 | 许可证 | Mac 本地可行性 |
|------|--------|--------|----------------|
| DeepSeek-V4.1-Flash | 未公开（Flash 轻量） | 待确认 | 中等，需等 GGUF 量化版 |
| Edge0-35B-A3B-preview | 35B（激活 3B） | 待确认 | 较高，MoE 激活量低，量化后可跑 |
| openbmb/MiniCPM5-2B | 2B | 开源 | 高，2B 量级 Mac 无压力 |
| nex-agi/Nex-N2.5-mini | 未公开（mini） | 开源 | 高，mini 定位适合本地 |
| TokenRhythm/NeoHorse-1-4B | 4B | 开源 | 高，4B Mac 可流畅运行 |
| Qwen3.8-27B（持续热门） | 27B | Apache 2.0 | 中等，需 Q4 量化 + 16GB+ 统一内存 |

**趋势观察**：
1. MoE 架构在中等规模模型中普及加速（Edge0-35B-A3B 等），"大总参小激活"成为性价比标配方案。
2. 小模型（2B-4B）持续迭代（MiniCPM5-2B、NeoHorse-4B），本地部署门槛进一步降低，Mac 可直接跑。
3. OpenRouter 免费模型池快速扩充，GLM-5.2、Ling 3.0、Nex-N2.5 等多款免费上架，API 层零成本试错窗口扩大。
