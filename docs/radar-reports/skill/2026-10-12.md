## 今日新发现

### 1. azure-diagnostics（含 microsoft-foundry / azure-prepare / azure-ai）

微软官方 azure-skills 仓库（github.com/microsoft/azure-skills）下的 Azure 诊断技能家族，Linkly 榜单显示 azure-diagnostics WIS 55.3（第 95 位），同仓库还有 microsoft-foundry（55.2）、azure-prepare（55.1）、azure-ai（55.0）。本次已通过 GitHub API 直接核验该仓库存在且含插件化技能结构（.claude-plugin、.cursor-plugin 目录）。具体功能覆盖范围以仓库文档为准，未确认。

- **来源**：Linkly Top 100（数据集 CC BY 4.0）+ GitHub API 一手核验
- **价值判断**：与现有 Azure 告警邮件监控、aiq.sh 日志排查工作流直接相关，是最贴近日常运维的一条线索
- **与当前栈关联**：现有流程每天处理 Azure Monitor 告警并查询应用日志，官方诊断技能可能补充排障知识；试用后才能确认增量价值
- **来源等级**：official
- **来源名称**：Microsoft（GitHub）+ Linkly

### 2. agent-browser

vercel-labs 官方出品，GitHub 描述为"Browser automation CLI for AI agents"。Linkly 榜单排名第 1（WIS 80.1），skills.sh 安装量约 108 万。本次经 GitHub API 核验：仓库存在，43,822 stars，最近推送 2026-10-11（活跃）。Star 数与安装量只反映短期热度，不等于成熟度；具体能力边界未确认。

- **来源**：Linkly Top 100 第 1 位 + GitHub API 一手核验
- **价值判断**：当前 AI 工作流已有本地应用层的窗口控制能力，agent-browser 补的是无头/网页层自动化，二者互补
- **与当前栈关联**：网页抓取、登录态操作、前端页面验证等场景可用；当前 web 抓取工具无浏览器自动化能力，此为潜在补充
- **来源等级**：official
- **来源名称**：Vercel Labs + Linkly

### 3. frontend-design

Anthropic 官方技能仓库（anthropics/skills）中的前端设计技能，Linkly 榜单第 2（WIS 73.8），skills.sh 安装量约 97 万。未做仓库级一手核验，发布方归属来自 Linkly 数据集标注。

- **来源**：Linkly Top 100 第 2 位
- **价值判断**：官方出品的前端设计规范类技能，适合有 UI 交付要求的场景
- **与当前栈关联**：dulux CMS 等项目有前端迭代需求，可提升界面产出质量；与已装的 archify（架构图）不重叠
- **来源等级**：official
- **来源名称**：Anthropic + Linkly

### 4. Lark 官方技能家族（6 项）

发布方为 open.feishu.cn（飞书开放平台官方），Linkly 榜单收录 lark-markdown（55.9）、lark-apps（55.9）、lark-vc-agent（55.4）、lark-task（55.3）、lark-attendance（55.0）、lark-skill-maker（55.0）。当前工作流已有飞书插件化技能覆盖文档/云盘/知识库/权限场景，与该家族存在功能重叠，具体差异未确认。

- **来源**：Linkly Top 100
- **价值判断**：官方发布方可信度高，但与现有飞书集成重叠，边际价值待验证
- **与当前栈关联**：飞书是当前主力消息通道；若官方家族覆盖现有插件缺失的能力（如视频会议、考勤），才有收编意义
- **来源等级**：official
- **来源名称**：Feishu Open Platform + Linkly

- **来源**：Linkly Top 100
- **价值判断**：当前栈无图像生成能力，属可选补充而非刚需
- **与当前栈关联**：仅在需要配图产出时有价值，优先级低
- **来源等级**：community
- **来源名称**：ClawHub + Linkly

### 6. mcp-lark

ClawHub 社区技能，描述为"Lark/Feishu Skill via OpenAPI MCP servers（300+ tools）"。与现有飞书插件是两条不同技术路线（MCP OpenAPI 直连 vs 插件 API），覆盖面更广但维护方为社区，可靠性未确认。

- **来源**：ClawHub 搜索（关键词 feishu lark）
- **价值判断**：工具数量占优，但社区维护、质量未知；作为飞书集成的备选路线观察
- **与当前栈关联**：现有飞书集成稳定运行，无替换动机
- **来源等级**：community
- **来源名称**：ClawHub

### 7. SkillOpt（生态观察，不计入技能数）

微软官方研究仓库（github.com/microsoft/SkillOpt），GitHub API 核验：18,241 stars、1,719 forks，描述为"text-space optimizer that trains reusable natural-language skills for frozen LLM agents"，通过轨迹驱动编辑与验证门控更新产出可部署的 best_skill.md。它不是可直接安装的技能，而是技能优化方法论/框架，作为 agent-skills 生态的趋势信号记录。

- **来源**：GitHub API 检索（agent-skills + SKILL.md，共 1,667 个仓库）
- **价值判断**：官方背书的"技能自动优化"方向，与当前手工维护技能的方式形成对照
- **与当前栈关联**：长期关注；若其方法论可迁移到现有技能库的迭代流程，值得研究
- **来源等级**：official
- **来源名称**：GitHub API
