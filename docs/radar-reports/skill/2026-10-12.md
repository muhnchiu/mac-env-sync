- **来源**：Linkly Top 100（#95-100 区间）+ GitHub API 直接核验
- **价值判断**：与当前 Azure 告警邮件分析、App Insights 查询与 KQL 诊断流程直接对口，官方组织维护，可信度高
- **与当前栈关联**：现有告警分析依赖自建脚本，azure-diagnostics、appinsights-instrumentation、azure-kusto 可作为对照或增强方案
- **来源等级**：official
- **来源名称**：GitHub / Linkly

飞书官方域名（open.feishu.cn）发布的技能系列在 Linkly 榜单在列 6 席：lark-markdown、lark-apps、lark-vc-agent、lark-task、lark-attendance、lark-skill-maker（WIS 55.0-55.9）。各技能完整功能边界未确认，从命名看覆盖文档、应用、视频会议、任务、考勤与技能制作。ClawHub 侧另有 mcp-lark（OpenAPI MCP，自述 300+ 工具）与 feishu-lark-cli 等社区实现，生态活跃。

- **来源**：Linkly Top 100（#85/86/92/94/98/99）
- **价值判断**：发布方为飞书官方域名，可信度高于社区封装；与当前重度使用飞书协作的场景相关
- **与当前栈关联**：当前已有飞书文档/云盘/知识库集成能力，官方 lark 系列可能补齐应用管理、任务、考勤等未覆盖面
- **来源等级**：official（发布方归属来自 Linkly 页面标注，未做官网级复核）
- **来源名称**：Linkly / ClawHub
