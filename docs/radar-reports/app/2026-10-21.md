## 今日最值得关注

### 1. Plex 多漏洞被真实利用，攻击者已植入挖矿程序

小众软件安全提醒：Plex 多个安全漏洞已被黑客用于真实攻击，入侵服务器后安装挖矿程序和代理软件；同时 AOMEI 备份软件与远程桌面软件 AnyViewer 的更新渠道被劫持（媒体来源为火绒安全实验室报道）。Plex 属影音媒体服务器，若台账某机装有 Plex 媒体服务，需立即核对版本并升级。AOMEI Backupper / AnyViewer 不在三机台账内，但若有 Windows 侧使用需同样处理。

- **Cask**：无（Plex 在 macOS 走 `brew install --cask plex-media-server`，非本台账登记项；升级前确认官方 changelog 覆盖对应 CVE）
- **价值判断**：当前最需行动项；涉及正在被真实利用的漏洞。
- **与台账关联**：台账未登记 Plex 与 AOMEI；若三机或关联 Linux 服务器装有 Plex，属立即排查范围。
- **来源等级**：media（小众软件，引述火绒安全实验室）
- **来源名称**：小众软件

### 2. PwnEscape：Linux 内核严重漏洞，一台 VPS 可攻陷宿主机

小众软件报道 Linux 内核漏洞 PwnEscape（CVE-2026-99999），评分 9.3 分严重级；研究人员借此获得 Vercel 提供的 5 万美金奖金（媒体说法，待官方确认）。若三机环境涉及 Docker / 虚拟机 + 远端 VPS，需关注内核补丁。macOS 侧不直接适用，但关联 Linux 部署需排查。

- **Cask**：无（内核漏洞，非应用）
- **价值判断**：严重但针对 Linux 内核，与三机 macOS 无直接装项关联；关联 VPS/容器环境需跟踪补丁。
- **与台账关联**：台账无 Linux 内核相关登记；ngrok / Docker 类如涉 Linux VPS 则需留意。
- **来源等级**：media
- **来源名称**：小众软件

### 3. Tsrs：Cloudflare 将 TypeScript 移植到 Rust

Cloudflare 官方博客发布 Tsrs，把 TypeScript 移植到 Rust。这是开发工具链生态的重大实验，值得关注后续是否成为官方工具链的一部分。对当前使用 Node/TypeScript 项目无直接替换压力，可作为生态跟踪项。

- **Cask**：无（编译器实验，非桌面工具）
- **价值判断**：high；生态观察，暂无安装动作。
- **与台账关联**：不冲突；与现有开发工具链（Ghostty / VS Code Insiders 等）无重叠。
- **来源等级**：official
- **来源名称**：Cloudflare Blog

### 4. Google 开源 TorchTPU：TPU 的原生 PyTorch 后端

HN 首页：Google 开源 TorchTPU（`google-pytorch/torch_tpu`），为 TPU 提供原生 PyTorch 后端。对跑 PyTorch 训练/推理的 GPU/TPU 工作流有意义；三机当前无 TPU 环境，属前瞻跟踪。

- **Cask**：无（Python 库，`pip` / `uv` 渠道）
- **价值判断**：medium-high；无 TPU 硬件则暂不适用。
- **与台账关联**：台账无 PyTorch/TPU 相关登记；miniforge (p14) 理论上可试，但当前无 TPU 设备。
- **来源等级**：official
- **来源名称**：GitHub (google-pytorch/torch_tpu)

### 5. Karakeep v0.34：网页抓取与离线阅读升级（开源 29k 星）

小众软件报道开源 Web 书签工具 Karakeep 0.34.0（2026-10-18 发布），改进网页抓取、移动端离线阅读与服务器性能；GitHub 星数超 29700（媒体说法，未独立核实）。与 Obsidian（台账在用）功能部分重叠（知识管理/书签归档），但 Karakeep 偏 Web 侧抓取，Obsidian 偏本地 Markdown，可直接观察是否补进工具链。

- **Cask**：无 cask（Docker 自托管形态为主）
- **价值判断**：high；有潜力但当前自托管门槛存在。
- **与台账关联**：与 Obsidian 部分重叠；若需要 Web 侧书签归档可试，否则先 watch。
- **来源等级**：media
- **来源名称**：小众软件

### 6. Typora 2.0 Early Preview：Markdown 编辑器大版本

小众软件报道 Typora 2.0 发布预告，称 V1 可免费升级至 V2；新增 Markdown 功能细节待官方页确认。台账中 typora 未登记，且当前 Markdown 阅读主力为 Obsidian，Typora 属替代选项观察。

- **Cask**：`typora`（如需安装走 brew cask）
- **价值判断**：medium；与 Obsidian 重叠，无立即替换必要。
- **与台账关联**：Obsidian 为在用主力 Markdown/知识库工具，Typora 属同赛道。
- **来源等级**：media
- **来源名称**：小众软件

### 7. DeepInfer：DeepSeek 高性能推理框架（HN 2102 分）

HN 首页最高分：DeepSeek 开源 DeepInfer，高性能推理框架。与 Strata 0.2（小众软件报道，跑本地大模型）同属本地推理赛道；三机 p14 已有 LM Studio / Ollama，DeepInfer 可作为对比观察。媒体未给出 macOS 专属性能数据，未确认 Apple Silicon 表现。

- **Cask**：无（框架/库，Python 渠道）
- **价值判断**：medium-high；与现有 Ollama 赛道重叠，需实测后再定。
- **与台账关联**：p14 已有 LM Studio 与 Ollama，无冲突，属同赛道。
- **来源等级**：community（HN 首页）
- **来源名称**：Hacker News

### 8. 腾讯 WorkBuddy 教育版发布（媒体报道）

小众软件报道腾讯 10 月 19 日 WorkBuddy 教育公益版，面向在职教师，AI 备课/PPT/作业设计。与开发者/办公工具链无直接重叠，属办公 AI 侧观察项。

- **Cask**：无
- **价值判断**：low；目标用户为教师群体，与三机环境无关。
- **与台账关联**：不重叠。
- **来源等级**：media
- **来源名称**：小众软件
