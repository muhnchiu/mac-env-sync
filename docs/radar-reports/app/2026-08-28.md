## 今日最值得关注

### 1. superfile — 终端文件管理器

小众软件推荐。开源(MIT)、免费、TUI、跨平台(Win/macOS/Linux)。界面现代，支持预览/书签/插件。30天 869 安装、365天 7984 安装，社区活跃。

- **Cask**：无 cask，但有 formula：`brew install superfile`（已验证）
- **价值判断**：终端里漂亮的现代化文件管理器，弥补 cd+ls 查找体验差的痛点。适合经常在终端工作的人。
- **与台账关联**：与 Finder/Sublime 不冲突，定位互补（终端场景）。收编进 Brewfile.core 作为 CLI 工具。

### 2. ntfsmac — Apple Silicon 原生 NTFS 读写

小众软件推荐。开源、免费、macOS 专用(M 芯片)。无需内核扩展或关闭 SIP 即可读写 NTFS 移动硬盘，安全且轻量。

- **Cask**：无 cask 无 formula（`brew search ntfsmac` 无结果）
- **价值判断**：对有 Windows 移动硬盘的 Mac 用户非常实用。
- **与台账关联**：与 Transmit 不冲突（Transmit 是网络传输，ntfsmac 是本地 NTFS 挂载）。观望，暂不入 brew 体系。

### 3. Menuist — Mac 右键菜单增强

小众软件推荐。付费、macOS 专属、新上架。把新建文件、移动、预览、分享等高频操作收进右键菜单。

- **Cask**：无（新应用，尚未收录）
- **价值判断**：弥补 macOS 右键菜单先天不足，类似 Windows 的右键体验。
- **与台账关联**：与 Alfred 工作流部分重叠，付费应用且无 cask。观望，待 cask 收录后考虑。

### 4. Afterglow — 经典 After Dark 屏保现代复刻

HN 首页 81 分。免费、macOS 专属、怀旧向。在 macOS 上运行经典 After Dark 屏幕保护程序。

- **Cask**：无（`after-dark-classic` cask 已 deprecated）
- **价值判断**：情怀满满，无生产力价值。
- **与台账关联**：不收编。

### 5. Krokiet — 开源磁盘清理工具

小众软件推荐。开源、跨平台。扫描磁盘上的无用文件（缓存、日志、残留配置等）。

- **Cask**：无
- **价值判断**：CleanMyMac/DaisyDisk 的免费替代候选。
- **与台账关联**：与 DaisyDisk、CleanMyMac X 功能重叠。观望，当前双保险已满足需求。

### 6. singular-lite — Agent 隔离框架（Git-worktree 隔离）

HN Show HN 3 分。开源、CLI、开发者工具。L0/L1/L2 agent 分级、lease/gate/audit 机制、Git-worktree 隔离。

- **Cask**：无（`brew search singular` 返回数学代数系统，非同一项目）
- **价值判断**：AI agent 安全开发框架，概念前沿但尚处早期。
- **与台账关联**：不收编。GitHub 关注即可。
