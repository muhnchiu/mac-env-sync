## 今日最值得关注

### 1. PRBar — macOS 菜单栏 GitHub PR 计数器

Show HN 新项目，开源 Swift 写的 macOS 菜单栏小工具，实时显示你的 GitHub 开放 PR 数量。轻量实用，开发者日常 glance 一下就知道有没有 PR 等着 review。

- **Cask**：无（GitHub 开源项目，需手动 build 或 future cask）
- **价值判断**：极轻量，针对有 GitHub PR 流程的开发者，菜单栏一瞥即知状态，适合常开 PR 的团队。
- **与台账关联**：与 Alfred 工作流互补，但不重叠；台账无此类 GitHub 状态监控工具。

### 2. Shine — 终端 Markdown 预览 + 文档 linter

Show HN 开源项目（GitHub: Nithish-Yenaganti/shine），终端内直接预览 Markdown 渲染效果并做文档 lint。CLI 工具，适合经常写 Markdown 文档的开发者。

- **Cask**：无（CLI 工具，走 cargo/npm 安装）
- **价值判断**：终端原生 Markdown 预览避免频繁切窗口，linter 功能对文档质量有保障，轻量无依赖。
- **与台账关联**：与 marktext（停更）和 Obsidian 形成互补——Shine 做快速终端预览/lint，Obsidian 做深度编辑。

### 3. Runyte — 模态编辑器 + 集成终端 + 文件管理器

Show HN 新品，三合一设计：模态编辑器（Vim 风格）、内嵌终端、文件管理器一体化。目标是一体化开发环境减少窗口切换。

- **Cask**：无（极早期项目，官网下载）
- **价值判断**：概念吸引人但极早期，稳定性和插件生态远不如 Neovim/VS Code，适合尝鲜和关注走向。
- **与台账关联**：与 Ghostty（主力终端）+ VS Code Insiders（主力编辑器）功能重叠，但定位是「一体化精简」，非替代。

### 4. MSSH — 5MB 单文件 SSH 客户端（Windows/macOS）

小众软件报道，轻量桌面 SSH 终端，多会话、SFTP、快捷键，体验接近 Xshell。单文件 5MB，配置完全本地，开箱即用。

- **Cask**：无（官网下载，极轻量）
- **价值判断**：极小体积替代重量级 SSH 客户端，适合临时场景或 USB 便携。但主力 SSH 需求已由 Termius + Transmit 覆盖。
- **与台账关联**：与 Termius（云同步）功能重叠但定位不同——MSSH 是零配置便携版，Termius 是跨平台云端。与 WindTerm/Navicat 也有部分重叠。

### 5. Loudkit — 本地 TTS 引擎（Swift/Go/Rust/TS 多语言实现）

Show HN 开源项目（GitHub: loudreader/loudkit），本地文本转语音，提供 Swift、Go、Rust、TypeScript 四种原生实现。完全离线，不依赖云服务。

- **Cask**：无（开源库/CLI，按语言生态安装）
- **价值判断**：离线 TTS 对隐私敏感场景有价值，多语言绑定意味着可以嵌入各种应用。但语音质量和自然度需实测对比。
- **与台账关联**：与 OpenClaw 的 TTS 能力（ElevenLabs sag）互补——云端 TTS 质量更高，Loudkit 适合离线/隐私场景。

### 6. Konode — 跨浏览器同步工具

小众软件报道，理想中的浏览器同步方案：标签页、扩展、历史、书签、密码、Cookie 跨浏览器同步。解决 Chrome 同步不能用、Edge 同步绑定微软账号的痛点。

- **Cask**：无（浏览器扩展形态）
- **价值判断**：痛点真实存在（多浏览器用户同步是老大难），但安全风险需评估——同步 Cookie/密码意味着高权限数据流转。
- **与台账关联**：与 Google Chrome + Microsoft Edge 双浏览器并存的现状直接相关，但安全性需审慎评估后再用。

### 7. ZestSSH — 付费 SSH 客户端（开发者毕业作品转商业化）

Show HN 项目，开发者从毕业设计做成有人付费的产品。SSH 客户端赛道，与 Termius、MSSH 竞争。

- **Cask**：无（官网付费下载）
- **价值判断**：SSH 客户端赛道已饱和（Termius 云同步、Transmit 堡垒机、WindTerm、Navicat），付费新品难以突围，除非有独特功能。
- **与台账关联**：与 Termius（在用）+ Transmit（堡垒机专用）+ SecureFX 重叠度高，不收编。

### 8. iTerm2 Buddy — iTerm2 的 iOS 辅助客户端

小众软件报道，iTerm2 推出 iPhone 客户端，但不是终端模拟器，而是连接到 macOS 的远程辅助工具，可在手机上触发 Mac 端操作。

- **Cask**：无（iOS App Store）
- **价值判断**：对 iTerm2 重度用户有价值（远程触发命令/脚本），但非独立终端，依赖 Mac 端运行。mini 服务器场景可能有用途。
- **与台账关联**：iTerm2 在台账（mini/p13 手动装，在用），Buddy 是其生态延伸，不影响现有配置。

## 建议动作

**立即试用：**
1. PRBar — 轻量菜单栏 GitHub PR 监控，开发流程直接受益。GitHub 开源，clone build 即可。
2. Shine — 终端 Markdown 预览 + lint，日常写文档/README 有用。cargo 或 npm 安装。

**跟踪观察：**
- Runyte — 模态编辑器+终端+文件管理器一体化，关注项目成熟度和插件生态发展。
- Loudkit — 离线多语言 TTS 引擎，关注语音质量改善和 brew 集成进展。
- Konode — 跨浏览器同步工具，关注安全审计和社区信任度建设。

**收藏：**
- iTerm2 Buddy — iTerm2 生态延伸，远程触发 Mac 命令场景备用。
- binthere — 临时密码/API 密钥自毁分享，比直接贴聊天记录安全。

**不收编：** MSSH（Termius 覆盖）、ZestSSH（SSH 客户端已饱和，付费无增量）、CodePress/Charter（AI Agent 基础设施方向，当前非急需）。
