## 今日最值得关注

### 1. Chromium 全版本主动利用漏洞 CVE-2026-85046

HN 首页 158 分/71 评。Chromium 沙箱 RCE 漏洞正在被主动利用，影响所有基于 Chromium 的浏览器（Chrome、Edge 等）。NVD 已收录。台账中 Google Chrome 和 Microsoft Edge 均为三机在用核心浏览器，需确认各机已更新到最新版本。

- **Cask**：无（浏览器自带更新机制，检查 Chrome/Edge 是否已拉取最新补丁）
- **价值判断**：安全告警优先级最高，建议立即检查三机浏览器版本。
- **与台账关联**：Google Chrome（core）和 Microsoft Edge（core）均为三机在装，直接受影响。

### 2. Radicle -- 去中心化代码托管，GitHub/GitLab 的替代品

小众软件报道。Radicle 是免费、开源的 P2P 代码托管网络，不依赖任何中心化服务器。无需注册账号，代码通过 gossip 协议在节点间同步。对于关注代码主权和抗审查的开发者有实际价值。CLI 工具 + 可选的 web 界面。

- **Cask**：无（通过 `radicle-node` 或官方安装脚本部署，非 brew cask 形态）
- **价值判断**：对私有多仓库和敏感项目有备份托管价值，但当前生态规模小，不足以替代 GitHub 作为主力的。
- **与台账关联**：台账中已退役 Sourcetree，Git 操作走 CLI + Orca。Radicle 可作为特定场景补充，不冲突。

### 3. CleanShot X 5.0 Studio Mode -- macOS 截屏录屏大更新

小众软件报道。CleanShot X 5.0 新增工作室模式：自动平滑缩放、鼠标跟随、更丰富的剪辑功能。是 macOS 上最专业的截图录屏工具之一。付费软件。

- **Cask**：`cleanshot`（cask 存在，但为付费应用，安装后需购买授权）
- **价值判断**：功能确实强大，但台账中已有 Shottr（截图）+ Kap（录屏）组合覆盖日常需求，升级动力不足。
- **与台账关联**：与台账中 Shottr（截图）和 Kap（录屏）功能高度重叠，两者免费且已满足日常使用。

### 4. Sageling -- 本地 AI agent for Mac，Qwen 3.5 9B 经 MLX 原生运行

Show HN。Sageling 是一个 macOS 本地 AI agent，通过 MLX 框架在 Apple Silicon 上原生运行 Qwen 3.5 9B 模型。无需 GPU 服务器或云 API，全部在本地内存中推理。适合隐私敏感场景和离线使用。

- **Cask**：无（官网下载，尚在早期阶段）
- **价值判断**：MLX 本地推理是 Mac 上的趋势方向，但 9B 模型能力有限，目前更像是玩具。台账中 p14 已有 LM Studio + Ollama 覆盖本地推理需求。
- **与台账关联**：与 p14 的 LM Studio、Ollama 功能重叠，且后者生态更成熟。

### 5. Ccswitch -- 在多个 Claude Code 账号间切换

Show HN。开源工具（GitHub: 2hmad/ccswitch），用于在多个 Claude Code 账号之间快速切换。对于同时管理多个组织 Claude Code 订阅的开发者实用。

- **Cask**：无（GitHub 项目，CLI 工具）
- **价值判断**：如果有多账号 Claude Code 使用场景，实用小工具。当前台账中 Claude 为单机手动装，暂无多账号需求。
- **与台账关联**：与台账中 Claude（手动装，待收编）相关，但当前无多账号痛点。

### 6. Mongotar -- Files to Prompt, and Back

Show HN。开源工具（GitHub: sebastiancarlos/mongotar），实现文件到提示词的打包与反向解析。类似 `files-to-prompt` 但增加双向转换能力，方便将代码库批量喂给 LLM 分析后再写回。

- **Cask**：无（GitHub 项目，Rust 实现，可能 cargo install）
- **价值判断**：开发者与 LLM 交互的实用工具，尤其是代码库级别分析场景。轻量，值得试。
- **与台账关联**：无直接重叠，属于开发工作流增强。

### 7. VLM Run Gateway -- 一套 API 跑开源 OCR、VLM 和视觉模型

Show HN。提供统一 API 网关，背后可挂载多种开源 OCR 引擎、视觉语言模型（VLM）。适合需要 OCR/图像理解的开发场景，避免逐个集成。

- **Cask**：无（服务端工具，pip/docker 部署）
- **价值判断**：OCR 和视觉模型统一接口有价值，但当前需求场景不明确。适合收藏跟踪。
- **与台账关联**：无直接重叠，属于 API 层工具。

### 8. Rust React Compiler 原生集成进 Vite

HN 首页 106 分/19 评。Rust 编写的 React Compiler 现已原生集成进 Vite 构建流程，无需额外配置即可享受编译时优化。对前端构建链有直接影响。

- **Cask**：无（npm 生态，Vite 插件形态）
- **价值判断**：前端开发重要进展，如果项目用 Vite + React 可直接受益。当前工作以 Java 后端为主，前端为辅，跟踪即可。
- **与台账关联**：与台账中微信开发者工具前端场景相关，但非直接工具链。

### 9. InkGist (墨萃) -- 处理看不完的标签页

小众软件报道。墨萃（InkGist）帮助处理浏览器中大量打开的标签页：快速阅读网页内容，需要的收藏，不需要的抛弃。适合"标签页囤积症"用户。

- **Cask**：无（官网/发现频道下载，浏览器扩展或桌面应用）
- **价值判断**：标签页管理是常见痛点，但同类工具众多（OneTab、Tab Wrangler 等），需验证实际效果。
- **与台账关联**：无直接重叠，属于浏览器效率增强，三机均可使用。

### 10. Fermat's Last Theorem in Lean 4 -- Anthropic 形式化数学项目

HN 首页 53 分 + 449 分（Anthropic 研究帖）。Anthropic 将费马大定理的形式化证明在 Lean 4 中实现，开源在 GitHub。展示了 AI 辅助形式化数学验证的前沿能力。

- **Cask**：无（Lean 4 生态，GitHub 开源）
- **价值判断**：学术和前沿 AI 研究的标杆项目，实际使用价值有限，但值得了解 AI 在形式化验证中的进展。
- **与台账关联**：无重叠，纯知识关注。
