## 今日最值得关注

### 1. Terminal-browser — 终端里的真浏览器（Show HN）

GitHub 项目，在终端内嵌入真实浏览器引擎。与你现有 Ghostty + iTerm2 终端工作流契合度高，适合无 GUI 服务器场景或 SSH 会话中快速查页。

- **Cask**：无（GitHub 源码，需编译）
- **价值判断**：终端浏览器赛道还有 carbonyl 等，尚未有成熟方案。
- **与台账关联**：观望，star 增长后再评估。

### 2. Saccade — 为 AI Agent 提供实时语义浏览器（Show HN）

让 AI agent 在浏览网页时获得"语义级"的真实页面状态，而非 OCR 或截图。

- **Cask**：无（GitHub: nanlogic/saccade）
- **价值判断**：当前 3 分非常早期，但方向对 agent 生态有价值。
- **与台账关联**：收藏观察，如果你在 Claude/ChatGPT 的 agent 能力上投入精力，这是个值得关注的基建。

### 3. 49 IDE — 面向 Agent 的 2D 画布 IDE（Show HN）

把 agent 的工作流可视化到 2D 画布上，区别于传统线性对话。18 分说明有一定关注度。

- **Cask**：无（GitHub: alpbahadur/49-ide）
- **价值判断**：你已有 VS Code Insiders + Claude/ChatGPT 的 agent 工作流，除非提供显著增量不必切换。
- **与台账关联**：观望。

### 4. Darling — 在 Linux 上运行 macOS 软件（darlinghq.org）

Darling 项目持续活跃，HN 55 分。

- **Cask**：无（Linux 侧项目，macOS 不需要）
- **价值判断**：如果未来需要在 Linux 环境跑 macOS-only 的工具，这是唯一开源方案。
- **与台账关联**：纯知识储备。

### 5. OpenClaw 2.0 正式发布 — 小众软件报道

933 位贡献者、16000+ PR 的重大更新。

- **Cask**：openclaw（npm 全局包，非 cask）
- **价值判断**：你本身就在 OpenClaw 生态里，如果辅机还有旧版可以升级了。
- **与台账关联**：确认三机 OpenClaw 版本一致，辅机跑 `openclaw update`。

### 6. Chrome 彻底移除 Manifest V2 扩展（含 uBlock Origin）

8 月 31 日是 Chrome 应用商店移除 MV2 扩展的最后期限。uBlock Origin（MV2 版）已从商店下架。

- **Cask**：无
- **价值判断**：直接关系到日常浏览体验。
- **与台账关联**：检查三机 Chrome 扩展，uBlock Origin 用户需迁移到 uBO Lite 或替代品。

### 7. 护眼宝 — 用 6 只宠物强制提醒休息（小众软件）

不锁屏、不打断，通过桌面宠物动画提醒休息。

- **Cask**：无（发现频道项目）
- **价值判断**：台账里没有护眼类软件（macmon/Stats 是监控不是护眼），这个填补空缺。
- **与台账关联**：可试用，体验好再登记入台账。

### 8. Ubuntu 26.04.1 LTS 发布

### 9. 内网穿透工具「网云穿」2.2 版（小众软件）

轻量级内网穿透方案。

- **Cask**：无

- **与台账关联**：不安装。Tailscale 已覆盖需求，增加工具只会增加台账复杂度。

## 建议动作

**立即试用：**

1. **检查 Chrome 扩展迁移**：三机 Chrome 确认 uBlock Origin 是否已迁移到 MV3 版（uBO Lite）。MV2 扩展从今天起不再更新。
2. **确认 OpenClaw 2.0 升级**：辅机跑 `openclaw --version` 确认版本，低于 2.0 则升级。

**跟踪观察：**

- 护眼宝：从发现频道下载试用。如果体验好，登记入台账效率系统类。当前台账无护眼软件，这是个空白位。
- Saccade / 49 IDE / Terminal-browser：三个 Show HN 项目都在极早期，star 上百后再评估。

**收藏：**

- Darling（Linux 跑 macOS 软件的唯一开源方案）
- FrameOS（智能相框 OS，有闲置屏幕时考虑）

**今日总结**：今天雷达没有"必装不可"的新软件。最值得行动的是 Chrome MV2 扩展迁移——这不是新装软件，但影响日常体验。护眼宝填补了台账空白，可以试一下。其余多为早期项目或知识储备。
