## 今日最值得关注

### 1. Tailcat — Tailscale 官方出品的 netcat 替代

Tailscale 团队做的安全网络工具，基于 WireGuard 数据平面做加密隧道传输，网络调试/渗透测试场景很实用。开源（GitHub）。

- **Cask**：无（Go 二进制，`brew search` 无结果），可 `go install` 或从 GitHub releases 下载
- **价值判断**：网络调试/渗透测试场景很实用。
- **与台账关联**：Tailscale 在台账③已装（组网骨干），Tailcat 是配套工具，互补关系。

### 2. superfile — 终端文件管理器

TUI 文件管理器，跨平台（Win/Mac/Linux），界面现代，支持预览/书签/插件。小众软件推荐，社区热度不错。开源免费。

- **Cask**：无 cask，但有 formula：`brew install superfile`（stable 1.6.0，已 bottled）
- **价值判断**：弥补 cd+ls 查找体验差的痛点，适合经常在终端工作的人。
- **与台账关联**：与 Finder/Transmit 不冲突，定位互补（终端场景）。值得加装进 Brewfile.core。

### 3. Mold — 大规模并行链接器

C/C++/Rust 项目编译加速利器，比 lld 更快。开源，已被广泛采用。HN 132 分讨论新论文。

- **Cask**：无 cask（是开发库），但有 formula：`brew install mold`（stable 2.42.0，bottled）
- **价值判断**：开发者编译加速必备。
- **与台账关联**：台账无链接器类工具，填补空白。值得加装。

### 4. ntfsmac — Apple Silicon 原生 NTFS 读写

解决 Mac 插 NTFS 移动硬盘只读的痛点，开源，基于 user-space FUSE 实现，无需内核扩展/SIP 修改。小众软件专文推荐。

- **Cask**：无（`brew search` 无结果），需从 GitHub release 手动装
- **价值判断**：实用痛点解决，尤其插移动硬盘时。
- **与台账关联**：台账无 NTFS 工具，填补空白。无 cask，手动装后收编。

### 5. Wallps — macOS 桌面/锁屏分别设动态壁纸

轻量小工具，桌面和锁屏用不同动态壁纸，纯前端/开发者作品。开源免费。

- **Cask**：无（GitHub Pages 分发）
- **价值判断**：纯装饰性，优先级低。
- **与台账关联**：不收编。

### 6. Contextual — AI 编程助手的本地代码库记忆

解决 AI coding agent 上下文窗口不够的问题，本地索引代码库供 agent 检索。方向对，但早期阶段。

- **Cask**：无，需从官网了解安装方式
- **价值判断**：方向好但太早期，与 OpenClaw + AI 工作流有重叠。
- **与台账关联**：观望，等成熟。

### 7. YASS — 开源股票筛选器（含 point-in-time 回测）

开源量化工具，支持历史回测不引入未来数据。

- **Cask**：无（GitHub 项目，Python 包）
- **价值判断**：对金融/量化开发有兴趣的话值得收藏。
- **与台账关联**：不收编，非当前场景。

### 8. OpenExecutive — 开源 AI CEO

HN 587 分的热帖产物，"CEO 裁掉开发者换 AI，开发者做开源 AI CEO"。娱乐属性强，但作为 AI agent 实验项目有学习价值。开源。

- **Cask**：无（GitHub 项目）
- **价值判断**：娱乐+学习价值，非生产力工具。
- **与台账关联**：不收编。

### 9. Clink — 嵌入式 C++23 流处理引擎

面向嵌入式场景的流处理框架，C++23 新特性实践。小众但技术含量高。

- **Cask**：无（GitHub 项目）
- **价值判断**：适合 C++ 系统开发者关注。
- **与台账关联**：不收编。

### 10. Menuist — macOS 右键菜单增强工具

把新建文件、移动、预览、分享等高频操作收进右键菜单，减少 Finder 操作步骤。小众软件专文推荐。免费。

- **Cask**：无（App Store 或独立分发）
- **价值判断**：效率工具链已经很丰富，非刚需。
- **与台账关联**：与 Alfred 5 部分重叠，可选。

1. **superfile** — `brew install superfile`，开源免费 MIT 协议，formula 已 bottled。台账①加行 → Brewfile.core 加条目 → install → push。
2. **Mold** — `brew install mold`，编译加速用，formula 已 bottled。台账①加行 → Brewfile.core 加条目 → install → push。

**跟踪观察：**

- Tailcat：常做网络调试时作为 Tailscale 配套加装，`go install` 或 GitHub release。
- Contextual：等后续版本，AI agent 记忆赛道尚早期。

**收藏：**

- Menuist（右键菜单增强，等 cask 收录后考虑）

**不收编**：YASS / OpenExecutive / Clink — 非当前场景或非生产力工具。
