## 今日最值得关注

### 1. OpenStock

开源股票行情追踪平台，提供实时股价、个性化提醒和公司详情。定位是付费行情平台的开源替代品。TypeScript 编写，今日 GitHub Trending 第一（844 stars today），社区关注度极高。

- **平台**：Web（跨平台，浏览器使用）
- **类型**：开源；免费
- **安装方式**：GitHub Release / Docker / Web
- **Homebrew**：暂无
- **项目状态**：活跃开发
- **来源信号**：GitHub Trending Daily #1（844 stars today）
- **核心价值**：开源免费的实时行情追踪，替代付费金融数据平台
- **与台账关联**：无明显关联 — 当前软件栈无金融工具
- **建议**：跟踪观察 — 开源方向有价值，但当前无金融数据需求

### 2. Project NOMAD

离线优先的知识和教育服务器，内置 Wikipedia、数千本图书、课程、地图，可选本地 AI，全部运行在自有硬件上。TypeScript 编写，GitHub Trending 今日 394 stars。定位是"个人知识库 + 离线教育资源"，适合 Mac mini 作为家庭服务器场景。

- **平台**：macOS / Linux / Web（Self-hosted）
- **类型**：开源；免费
- **安装方式**：Docker / GitHub Release
- **Homebrew**：暂无
- **项目状态**：活跃开发，早期项目
- **来源信号**：GitHub Trending Daily（394 stars today）
- **核心价值**：离线知识服务器，Mac mini 家庭场景天然适配
- **与台账关联**：补充能力 — 与 Obsidian（知识管理）方向不同，NOMAD 是知识消费端（Wikipedia/图书/课程），Obsidian 是知识生产端
- **建议**：跟踪观察 — 方向与 Mac mini 家庭服务器定位契合，但项目仍较早期，等成熟度提升后再评估

### 3. akitaonrails/ai-memory

为 AI 编程 CLI 提供长期记忆的解决方案，支持在不同 agent 厂商之间传递上下文和 handoff。Rust 编写，GitHub Trending 今日 167 stars。解决的是 AI coding agent 跨会话记忆和厂商切换时的上下文丢失问题。

- **平台**：macOS / Linux / Cross-platform（CLI）
- **类型**：开源；免费
- **安装方式**：GitHub Release / cargo
- **Homebrew**：暂无
- **项目状态**：活跃开发，早期项目
- **来源信号**：GitHub Trending Daily（167 stars today）
- **核心价值**：解决 AI agent 长期记忆和跨厂商 handoff，与当前 OpenClaw + Claude Code 工作流直接相关
- **与台账关联**：直接相关 — 当前使用 OpenClaw（MEMORY.md 机制）和 Claude Code，agent 记忆和 handoff 是实际痛点
- **建议**：立即试用 — 与当前 AI coding 工作流直接相关，值得实际测试是否能改善 OpenClaw/Claude Code 的记忆连续性

### 4. Codex-X

OpenAI Codex 桌面端/CLI 的可视化管理工具，支持 Provider/API 切换、会话同步、提示词注入、Skills/MCP 管理、TOML 配置可视化。Rust 编写，跨平台。今日 GitHub Trending 50 stars。

- **平台**：macOS / Windows / Linux（跨平台桌面）
- **类型**：开源；免费
- **安装方式**：GitHub Release
- **Homebrew**：暂无
- **项目状态**：活跃开发，早期项目
- **来源信号**：GitHub Trending Daily（50 stars today）
- **核心价值**：Codex/CLI agent 的可视化管理层，API 切换和会话同步解决实际痛点
- **与台账关联**：直接相关 — 当前使用 Codex++（mini 手动装），Codex-X 功能更完整（Provider 切换 + Skills/MCP 管理 + TOML 可视化）
- **建议**：立即试用 — 与现有 Codex++ 功能重叠但有明显优势，值得对比评估是否替代

### 5. Foremerge

检测并行 coding agent 之间的意图冲突。当多个 AI agent 同时修改代码时，Foremerge 分析各 agent 的修改意图，在合并前发现逻辑冲突。Show HN 40 points。

- **平台**：macOS / Linux / Cross-platform（CLI）
- **类型**：开源；免费
- **安装方式**：GitHub Release
- **Homebrew**：暂无
- **项目状态**：早期项目
- **来源信号**：Show HN（40 points, 11 comments）
- **核心价值**：多 agent 并行编程时的冲突检测，解决 AI coding 实际痛点
- **与台账关联**：间接相关 — 当前 OpenClaw + sub-agent 架构可能触发类似场景
- **建议**：跟踪观察 — 方向有价值，但当前 sub-agent 并行编程场景不多

### 6. Lossless-memory

个人 AI 记忆系统，不做摘要、不做压缩，完整保留所有记忆。Show HN 60 points, 21 comments，是今日 Show HN 热度最高的项目之一。

- **平台**：未确认（GitHub 项目）
- **类型**：开源；免费
- **安装方式**：GitHub Release
- **Homebrew**：暂无
- **项目状态**：早期项目
- **来源信号**：Show HN（60 points, 21 comments）
- **核心价值**：无损记忆存储，不做 AI 摘要，保留原始数据
- **与台账关联**：间接相关 — 与 OpenClaw MEMORY.md 机制理念不同，OpenClaw 是精选摘要，Lossless 是全量保留
- **建议**：跟踪观察 — 理念有趣但当前 OpenClaw 记忆机制已能满足需求
