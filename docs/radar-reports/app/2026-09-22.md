## 今日最值得关注

### 1. Transom - macOS 浏览器多配置管理工具

Transom 是一个开源的 macOS 应用，用于轻松管理多个浏览器配置文件。对于需要在不同账号/环境间切换的开发者来说，解决了 Chrome/Edge 原生 profile 管理不够灵活的痛点。项目托管在 GitHub，采用 Swift 开发。

- **Cask**：无（项目较新，尚未收录 Homebrew）
- **价值判断**：开源免费，macOS 原生应用，解决多账号浏览的实际痛点，比 Chrome 原生 profile 管理更灵活。
- **与台账关联**：台账中 Chrome 和 Edge 均已收编，Transom 可作为浏览器配置管理的补充工具，不冲突。

### 2. HTTPS Capture - 苹果全平台抓包工具终身限免

HTTPS Capture 是一款支持 iPhone/iPad/Mac 的抓包与 HTTPS 解密、API 调试工具，目前在 App Store 终身限免（未上架国区）。支持局域网抓包、URL 重写、JS 脚本、Mock、Hosts、断点调试等完整功能。

- **Cask**：无（App Store 应用，非 brew 体系）
- **价值判断**：限免机会难得，功能覆盖移动端+桌面端抓包，比单纯桌面端工具有额外价值。
- **与台账关联**：台账中 Proxyman（mini+p13）已承担桌面端抓包，但 HTTPS Capture 额外覆盖 iOS/iPadOS 抓包，是移动端调试的稀缺工具，互补而非替代。

### 3. Differential - 语义分组的终端 diff 审查工具

Differential 是一个 TUI 界面的 diff 审查工具，特点是将 diff 按语义分组展示，而非传统的逐行对比。开源项目，托管在 GitHub。

- **Cask**：无（CLI 工具，预计可通过 cargo/npm 安装）
- **价值判断**：开源免费，终端原生，语义分组是 diff 工具的创新点，适合 code review 场景。
- **与台账关联**：台账中 Sourcetree 已退役（改用 Orca 原生 diff），Differential 可作为终端 diff 工具的补充，与 Orca 的 GUI diff 不冲突。

### 4. Cloudflare Python Workers 正式可用

Cloudflare 宣布 Python Workers 正式发布（GA），开发者可以用 Python 编写 serverless 边缘函数，无需 Node.js 运行时。支持标准库和第三方包，直接部署到 Cloudflare 边缘网络。

- **Cask**：无（平台服务，非本地应用）
- **价值判断**：对 Python 开发者是重大利好，降低 serverless 上手门槛，免费额度足够个人使用。
- **与台账关联**：非桌面软件，但与开发工作流直接相关，台账中 ngrok（core）已收编用于本地隧道，Cloudflare Workers 可作为云端 serverless 补充。

### 5. Atuin - Shell 命令历史搜索与同步

Atuin 是一个开源的 shell 历史管理工具，支持搜索、同步跨机器的命令历史记录。用 Rust 编写，支持 zsh/bash/fish，可自建同步服务器。

- **Cask**：`atuin`（Homebrew formula，非 cask，CLI 工具）
- **价值判断**：开源免费，跨机器同步命令历史对多 Mac 环境（mini/pro13/pro14）非常实用，Rust 实现性能好。
- **与台账关联**：台账中三机均有 Ghostty/iTerm2/Warp 等终端，Atuin 可作为终端层的通用增强，与现有终端工具互补不冲突。

### 6. Kev - 基于 Qwen3.5 的轻量决策模型

Kev 是一个构建在 Qwen3.5 之上的微型决策模型系列，由 ChatGPT 研究员 Diogo Almeida 开发。不聊天、不写代码，只做判断选择，比传统大模型快 20-200 倍，成本低 40-400 倍。HN 热度 400 分。

- **Cask**：无（模型/Python 包，通过 pip 安装）
- **价值判断**：开源免费，思路新颖（AI 做决策而非生成），适合自动化流程中的路由/分类/判断环节，成本极低。
- **与台账关联**：台账中 Claude/ChatGPT 用于通用 AI 对话，Kev 定位完全不同（决策引擎），可作为开发中 AI agent 流程的组件，不重叠。

### 7. PGSTY Silo - MinIO 无缝替代

PGSTY Silo 是从 MinIO fork 而来的开源 S3 对象存储，只改了一行代码，可无缝替代 MinIO。在 MinIO 许可证变更后，提供了保持代码兼容性的替代方案。

- **Cask**：无（服务端软件，Docker/二进制部署）
- **价值判断**：开源免费，MinIO 生态的保底方案，如果有 S3 对象存储需求值得了解。
- **与台账关联**：台账中无对象存储相关软件，PGSTY Silo 属于基础设施层，与桌面软件台账无直接关联，但开发场景可能用到。

### 8. Turfs - Mac 桌面区域划分工具

Turfs 是一款 macOS 桌面管理应用，在桌面上划分区域（fences），将窗口或文件组织到不同区域中。来自 Product Hunt。

- **Cask**：无（较新应用，需确认是否有 cask）
- **价值判断**：macOS 桌面整理工具，概念类似于 Windows 的 Fences，适合多窗口工作场景。
- **与台账关联**：台账中 Rectangle（mini+p13）负责窗口布局，Turfs 更偏桌面文件/窗口区域管理，功能有部分重叠但侧重点不同。

### 9. VernLLM - 无网关的 LLM 回退方案

VernLLM 是一个开源的 LLM 回退方案，无需 API 网关即可在多个 LLM 提供商之间自动切换。轻量级，适合个人开发者在不同模型间做容错。

- **Cask**：无（CLI/库，通过 pip/npm 安装）
- **价值判断**：开源免费，解决多 LLM 提供商切换的实际痛点，比 LiteLLM 等网关方案更轻量。
- **与台账关联**：台账中无 LLM 网关/路由工具，VernLLM 属于开发工具链补充，与现有软件不冲突。

### 10. Wake Me Up - iOS 远程网络唤醒应用

Wake Me Up 是一款免费的 iOS 应用，支持通过 WOL（Wake-on-LAN）远程唤醒 PC、Mac、NAS、服务器等设备。界面极简，一个按钮即可开机。

- **Cask**：无（iOS 应用，App Store）
- **价值判断**：免费，iOS 原生，对于三机 Mac 环境的远程管理有实际价值（如远程唤醒 mini）。
- **与台账关联**：台账中 AnyDesk/ToDesk/Windows App 用于远程控制，但都无法唤醒睡眠中的设备。Wake Me Up 补充了 WOL 唤醒环节，是远程管理链的前置工具。
