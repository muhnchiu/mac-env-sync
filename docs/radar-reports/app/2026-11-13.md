## 今日最值得关注

### 1. Chrome 高危 0day CVE-2026-125350 已被实际利用

小众软件报道 Google Chrome 曝出已被黑客实际利用的高危漏洞 CVE-2026-125350（CVSS 8.8），存在于 Chrome 的 XML 组件中，攻击者可通过恶意网页触发内存错误，Google 已紧急发布更新。媒体报道，待官方确认利用规模与更新细节。

- **Cask**：`google-chrome` 已在台账（mini ✓ / p13 m / p14 m）
- **价值判断**：浏览器安全事件，需立即确认各机 Chrome 已更新到修复版本。
- **与台账关联**：google-chrome 为 core 条目，三台均在用。
- **来源等级**：media
- **来源名称**：小众软件

### 2. Microsoft 为 Mac 推出 Process Explorer

小众软件报道微软把 Windows 经典进程管理工具 Process Explorer 带到 macOS，可深入查看进程占用、网络连接与文件句柄，信息维度比「活动监视器」更全。具体版本与下载渠道待确认。

- **Cask**：未确认（brew search 无 process-explorer cask）
- **价值判断**：对排查「某进程为什么占 CPU / 连了哪些服务器」这类问题有直接价值，属于轻量第三方监控工具。
- **与台账关联**：台账监控项为 Stats（系统级实时指标）与 macmon（终端侧），均非进程级深度排查工具；无重叠，属补位。
- **来源等级**：media
- **来源名称**：小众软件

### 3. ExcalidrawZ：本地原生 Excalidraw（macOS/iOS）

HN 热帖：ExcalidrawZ 是 Excalidraw 的本地原生客户端，支持 macOS 与 iOS，已入 Homebrew cask（excalidrawz，2.5.1，auto_updates，macOS 14+，30 天安装 213）。

- **Cask**：`excalidrawz`（原生 macOS/iOS 客户端，自动更新）
- **价值判断**：Excalidraw 已有网页版可本地使用，原生客户端主要是壳体验与离线便利，增量有限。
- **与台账关联**：视觉思考已用 Obsidian Canvas + Mermaid/markmap（见台账 XMind 退役备注），功能重叠度高。
- **来源等级**：ecosystem
- **来源名称**：Hacker News
