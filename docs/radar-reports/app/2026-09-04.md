## 今日最值得关注

### 1. Audacity 4.0 — 开源音频编辑器大版本更新（HN 1035 分/232 评）

4.0 架构重写。免费开源。

- **Cask**：`audacity`（可验证）
- **价值判断**：偶尔处理音频用得上，免费开源，标杆级工具。
- **与台账关联**：值得收编。台账类别④，token `audacity`。流程：台账加行 → Brewfile 加条目 → chezmoi push。

### 2. DrawDB Pro — 在线数据库 schema 设计工具

支持团队协作 + AI agent 集成（drawdb.app）。Web 端免费，GitHub 开源。

- **Cask**：无（Web 应用）
- **价值判断**：需要设计 schema 时浏览器打开即可。
- **与台账关联**：与 DBX 互补不冲突（DBX 是查询管理，DrawDB 是 schema 设计）。收藏不装。

### 3. Devbar — 浏览器开发工具，指向要改的地方留评论，agent 帮你提交

面向 agent 时代的新交互范式（devbar.sh）。

- **Cask**：无
- **价值判断**：与 Claude Code / Orca 工作流部分重叠，交互方式不同但目标一致。
- **与台账关联**：不收编。

### 4. Aidcrew — 多模型 coding agent 团队

每个 agent 跑不同模型，统一终端管理。GitHub 开源（antoniociccia/aidcrew）。

- **Cask**：无
- **价值判断**：多模型 fleet 概念有新意，但与现有 Claude / Codex++ 核心功能重叠。
- **与台账关联**：不收编。

### 5. Agentray — macOS 原生 agent，界面就是一个文件夹

交互方式新颖（Show HN）。

- **Cask**：无
- **价值判断**：概念有趣但实际用例不明确。
- **与台账关联**：继续观察。

### 6. Addom (ADDOM) — 开源无遥测 AI coding harness 和编辑器

对标 Cursor/Claude Code（GitHub: JosPMSilva/ADDOM）。

- **Cask**：无
- **价值判断**：与已装 Claude / Codex++ 重叠。
- **与台账关联**：不收编。

### 7. Bridle — 把 agent 上下文交接给同事的 agent

团队协作新思路（bridle.network）。

- **Cask**：无
- **价值判断**：已有 handoff skill 做上下文交接，Bridle 是 SaaS 化的同类概念。
- **与台账关联**：不收编。

### 8. NGPDFs — 50 个 PDF 工具，文件不上传本地处理

隐私友好（ngpdfs.com）。

- **Cask**：无
- **价值判断**：PDF 处理偶尔需要，Web 端即够用。
- **与台账关联**：收藏，台账无专门 PDF 工具但 Web 端足够。

### 9. Radicle — 去中心化代码托管

GitHub/GitLab 的开源替代，p2p 协议，无需服务器。

- **Cask**：无
- **价值判断**：去中心化托管理念好，但团队协作场景不匹配公司 Git 工作流。
- **与台账关联**：暂不入台账。

### 10. CleanShot 5.0 — macOS 截屏录屏大更新

Studio Mode 自动缩放/鼠标跟随/剪辑（cleanshot.com）。已有 cask `cleanshot`（付费）。

- **Cask**：`cleanshot`（付费）
- **价值判断**：与已装 Shottr 功能重叠度高，Shottr 免费够用。
- **与台账关联**：不收编，Shottr 也在快速迭代。
