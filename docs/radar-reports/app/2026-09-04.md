# 软件雷达日报 · 2026-09-04

> 数据源：HN / Product Hunt / 少数派 / 小众软件 · 台账：app-inventory.md

## 【今日最值得关注】

1. **Audacity 4.0** — 开源音频编辑器大版本更新（HN 1035分/232评），4.0 架构重写。免费开源，官方 cask `audacity` 可验证。
2. **DrawDB Pro** — 在线数据库 schema 设计工具，支持团队协作 + AI agent 集成（drawdb.app）。Web 端免费，GitHub 开源。
3. **Devbar** — 「指向要改的地方，留评论，agent 帮你提交」的浏览器开发工具（devbar.sh）。面向 agent 时代的新交互范式。
4. **Aidcrew** — 多模型 coding agent 团队，每个 agent 跑不同模型，统一终端管理。GitHub 开源（antoniociccia/aidcrew）。
5. **Agentray** — macOS 原生 agent，界面就是一个文件夹，交互方式新颖（HN Show HN）。
6. **Addom (ADDOM)** — 开源、无遥测的 AI coding harness 和编辑器，对标 Cursor/Claude Code（GitHub: JosPMSilva/ADDOM）。
7. **Bridle** — 把 agent 上下文交接给同事的 agent，团队协作新思路（bridle.network）。
8. **NGPDFs** — 50 个 PDF 工具，文件不上传本地处理，隐私友好（ngpdfs.com）。
9. **Radicle** — 去中心化代码托管，GitHub/GitLab 的开源替代。p2p 协议，无需服务器。
10. **CleanShot 5.0** — macOS 截屏录屏大更新，Studio Mode 自动缩放/鼠标跟随/剪辑（cleanshot.com）。官方 cask `cleanshot`（付费）。

## 【与已装重复】

- **CleanShot 5.0** vs **Shottr**（已装）：Shottr 免费够用，CleanShot 5.0 Studio Mode 是付费升级。功能重叠度高，不替换。
- **Aidcrew / Addom** vs **Claude / Codex++**（已装）：已有 Claude（手动装）、Codex++ 等多套 coding agent。Aidcrew 多模型 fleet 概念有新意，但与现有工具核心功能重叠。
- **Devbar** vs **Claude Code / Orca**：浏览器内视觉标注→agent 修改的思路与现有 Claude Code 工作流部分重叠，交互方式不同但目标一致。
- **DrawDB Pro** vs **DBX**：DBX 是数据库客户端（查询/管理），DrawDB 是 schema 设计工具，定位互补不冲突。
- **NGPDFs** vs 台账：无专门 PDF 工具，填补空白但 Web 端即够用。
- **Bridle** vs **Claude Code handoff**：已有 handoff skill 做上下文交接，Bridle 是 SaaS 化的同类概念。

## 【建议动作】

1. **Audacity 4.0** → ✅ 值得收编。`brew install --cask audacity`，免费开源，偶尔处理音频用得上。台账类别④，token `audacity`。流程：台账加行 → Brewfile 加条目 → chezmoi push。
2. **DrawDB Pro** → 📎 收藏不装。Web 端用即可（drawdb.app），需要设计 schema 时浏览器打开。
3. **NGPDFs** → 📎 收藏。PDF 处理偶尔需要，ngpdfs.com 浏览器用，不必装本地 app。
4. **Radicle** → 👀 观察。去中心化托管理念好，但团队协作场景不匹配公司 Git 工作流，暂不入台账。
5. **CleanShot 5.0 / Aidcrew / Addom / Devbar / Agentray / Bridle** → ⏸ 均不收编。功能与现有工具重叠或场景不匹配。Agentray 概念有趣但实际用例不明确，继续观察。
