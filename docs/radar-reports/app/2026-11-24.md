## 今日最值得关注

### 1. 微软 To Do 关闭，Superlist 官方 cask 可替代

微软宣布关闭 To Do，用户反弹明显；To Do 创始人早已做出替代品 Superlist（协作 To-do 应用），小众软件报道并给出迁移建议。Superlist 已有 Homebrew cask（superlist，1.59.0，auto_updates，macOS >= 12），当前台账无对应条目；三机目前未安装 To Do 类协作清单工具（效率系统类以 Alfred/Alfred 启动器为主），因此这是新增可选项而非替换项。

- **Cask**：`superlist`（Homebrew cask，已验证存在，1.59.0 auto-updates）
- **价值判断**：官方 cask 存在、免费开源协作清单，适合作为 To Do 迁移目标先试用。
- **与台账关联**：台账无 To Do / Superlist 条目；若试用满意再走"台账加行 + Brewfile + adopt/bundle"流程。
- **来源等级**：media
- **来源名称**：小众软件

### 2. Ladybird 浏览器进入 alpha

Ladybird 独立开源浏览器项目宣布进入 alpha 阶段，HN 首页 1322 分。它是一个从零开发的浏览器引擎（WebKit 替代方向）+ 浏览器组合，目前 alpha 意味着功能仍不完整，日常替代 Chrome/Edge 尚早。Homebrew 主索引中未搜到 ladybird cask（搜索命中无关的 ladybug），安装渠道待确认。

- **Cask**：无（brew search 未命中，安装渠道待确认）
- **价值判断**：引擎层重大进展，值得关注但暂不建议作为主力浏览器试用。
- **与台账关联**：台账浏览器基线为 Chrome / Edge / 115Browser，Ladybird 与三者定位不重叠，属于"新引擎"观察项。
- **来源等级**：community（官方项目博客，经 HN 首页放大）
- **来源名称**：Hacker News / ladybird.org

### 3. GLM-5.4 发布：面向通用编码的循环 Transformer

Z.ai 官方博客宣布 GLM-5.4，主打 generalized coding 与首个 loop transformer 架构，HN 首页 1030 分。这是模型能力信息，非 App 本身；对本地 AI 工作流的意义在于编码模型能力提升（台账中 Claude / ChatGPT / Codex 等 AI 工具可对接的模型池扩大）。官方博客为官方来源，具体 benchmark 数字未经独立复现。

- **Cask**：无（模型能力更新，非桌面应用）
- **价值判断**：官方发布可信，值得阅读博客了解架构与能力边界，待确认实际编码场景表现。
- **与台账关联**：与台账 AI 类工具（Claude / ChatGPT / Codex++）形成互补，无需安装动作。
- **来源等级**：official
- **来源名称**：Z.ai 官方博客

### 4. Stalwart：可直接替代 Microsoft Exchange 的邮件服务器

Stalwart 官方博客称其产品现为 Exchange 的直接替代（drop-in replacement），HN 107 分。面向自托管邮件基础设施；对三机 macOS 工作流而言属于服务器侧工具，本机无 Exchange 自托管需求。Homebrew 主索引未搜到 stalwart cask（命中无关的 start），安装渠道待确认。

- **Cask**：无（brew search 未命中，安装渠道待确认）
- **价值判断**：对企业邮件基建有价值，与当前三机环境不匹配，先观察。
- **与台账关联**：台账无 Exchange / 自托管邮件条目，无重叠。
- **来源等级**：ecosystem（官方博客发布，经 HN 传播）
- **来源名称**：Stalwart 官方博客

- **Cask**：无（brew search 未命中，渠道待确认）
- **价值判断**：新奇 > 实用，探索即可。
- **与台账关联**：无重叠，非台账工具类别。
- **来源等级**：community

### 6. Kagi Mail 公开 beta

Kagi 推出 Kagi Mail 公开 beta，HN 328 分。隐私搜索厂商进军邮件，产品仍处 beta，未确认是否提供免费档与 macOS 客户端。台账邮件基线为系统自带 Apple Mail（Filo 已退役），若 Kagi Mail 后续成熟且定位不重叠，再评估。

- **Cask**：无（beta 阶段，未确认 macOS 客户端分发渠道）
- **价值判断**：beta 产品，先观察。
- **与台账关联**：与 Apple Mail 功能部分重叠，当前不构成替换理由。
- **来源等级**：official（Kagi 官方博客）
- **来源名称**：Kagi Blog

### 7. Strata 0.2.18 新增 220B 开源模型 Hy4-Flash，门槛涨到 64GB 内存

小众软件报道本地大模型工具 Strata 更新 0.2.18，新增对腾讯混元 Hy4-Flash 的支持，入门内存要求升至 64GB。Strata 未确认是否有官方 brew cask；64GB 门槛意味着当前 Apple Silicon 开发机（未确认具体配置）若内存不足则无法运行。属于本地 AI 工具演进信息。

- **Cask**：无（未确认 Strata 官方分发渠道）
- **价值判断**：模型支持面扩大是好事，但内存门槛上涨收窄了可用人群，待确认。
- **与台账关联**：台账 p14 已有 Ollama / LM Studio 本地模型栈，Strata 与之定位相近，暂不需要安装。
- **来源等级**：media
- **来源名称**：小众软件
