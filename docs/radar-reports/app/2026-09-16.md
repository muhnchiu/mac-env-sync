## 今日最值得关注

### 1. Capsule -- 单文件 Web App + SQLite 自动持久化

HN 首页 272 分。Capsule 是一个框架，让你创建的 web app 天生自带数据存储：数据自动保存到 SQLite，无需后端配置。适合快速搭建小型工具和数据收集应用，定位轻量级 local-first 方案。

- **Cask**：无（Web 框架，非桌面应用）
- **价值判断**：local-first + zero-config 持久化思路好，适合内部工具和原型开发，但非 macOS 桌面软件。
- **与台账关联**：与台账中 local-first 理念一致（Obsidian/Transmit 手动装模式），但属不同类别，不产生直接替代。

### 2. Amika -- 多人云端工作站，给 AI 编程 agent 和人类共用

HN Show HN，6 分但概念新颖。Amika 提供云端工作站环境，让 AI coding agent 和人类开发者在同一界面协作，支持多 agent 并行。定位是"AI 时代的共享 IDE"。

- **Cask**：无（云端 SaaS，app.amika.dev）
- **价值判断**：方向对路（AI agent 协作是趋势），但当前规模小、闭源 SaaS，适合观察不适合收编。
- **与台账关联**：与台账中 Claude / Codex++ / VS Code Insiders 形成功能重叠，但形态不同（云端 vs 本地），不替代现有工具链。

### 3. tmux-seamless-remote -- 跨 SSH 嵌套 tmux 的无缝窗格导航

HN Show HN。解决一个经典痛点：SSH 到远端再开 tmux 后，窗格切换键冲突。这个工具让你在本地和远端 tmux 之间无缝导航，不用记住上下文切换快捷键。

- **Cask**：无（CLI 工具，GitHub: klntsky/tmux-seamless-remote）
- **价值判断**：精准痛点，开源轻量，立刻可用。tmux 重度用户必试。
- **与台账关联**：台账中 Ghostty 是主力终端，tmux 为终端复用核心插件。此工具增强 tmux 远程体验，直接补强现有工具链。

### 4. Inkling -- 让 Claude Code 输出 HTML 而非 Markdown

HN Show HN。Inkling 是一个桥接工具：向 Claude Code 请求文档时，直接得到排版好的 HTML 而非 Markdown。省去手动转换步骤，适合需要交付文档的场景。

- **Cask**：无（GitHub: MeetVys/inkling，CLI/Skill 型工具）
- **价值判断**：小而美，解决 Claude Code 用户的具体痛点。开源，可直接集成到现有 workflow。
- **与台账关联**：台账中 Claude 已在装（mini），此工具是 Claude 的增强插件，零成本叠加。

### 5. FileLever -- 本地优先的文件夹同步，写入前预览

HN Show HN。FileLever 做 local-first 文件同步，核心特色是"写入前预览"（preview-before-write）：你可以先看到同步将要做什么改动，再决定是否执行。比 rsync/git 安全感更强。

- **Cask**：无（filelever.com，桌面应用待确认）
- **价值判断**：预览同步是差异化亮点，local-first 理念好。但项目很新，生态未建立，先跟踪。
- **与台账关联**：与台账中 Transmit（手动装，SFTP/FTP）和 mac-env-sync（chezmoi+git）形成功能交叉，但定位不同（FileLever 是实时同步，现有方案是版本控制/手动传输）。

### 6. Agenttik -- 多项目并行 + AI agent 协作

HN Show HN。Agenttik 让你同时挂多个项目，每个项目分配 AI agent 并行工作。适合需要在不同仓库间切换的开发场景。

- **Cask**：无（GitHub: pausan/agenttik）
- **价值判断**：多 agent 并行是当前 AI 编程工具的前沿方向。开源项目，可试可用，但成熟度待验证。
- **与台账关联**：与台账中 Claude / Codex++（单项目 agent）形成升级关系——从单项目到多项目并行。不替代但可补充。

### 7. UPDF AI Agent -- PDF 编辑器内置 AI Agent

小众软件报道。UPDF 在 PDF 编辑器中内置 AI agent：选中文字直接让 AI 修改，一句话改文档。从"读 PDF"升级到"AI 改 PDF"。

- **Cask**：`updf`（待确认是否在 brew 范围内，UPDF 有 macOS 版）
- **价值判断**：PDF 编辑 + AI 是实用组合，但 UPDF 是商业软件（非完全免费），且与台账中 marktext（停更）和 Obsidian 的文档场景不同。
- **与台账关联**：台账中 marktext 已停更，Obsidian 是主力笔记。UPDF 填补的是 PDF 编辑空白，但非刚需。

### 8. Trancy Air -- 电脑上随处翻译，还能自动输入英文

小众软件报道。Trancy Air 是桌面级翻译工具：屏幕任何位置可取词翻译，支持 OCR 识别不可复制的文字，还能自动帮你在输入框打英文。比传统翻译软件更贴合"用电脑"的场景。

- **Cask**：无（Trancy 系列以浏览器扩展为主，Air 版可能是独立桌面应用）
- **价值判断**：OCR + 翻译 + 自动输入三合一，实用性强。但 Trancy 系列商业模式待确认（免费+订阅）。
- **与台账关联**：台账中 p14 装了 DeepL。Trancy Air 功能更丰富（OCR+自动输入），但 DeepL 翻译质量更稳。可作补充而非替代。

### 9. Building a Linux GPU Driver for the M4 Mac Mini in One Month

HN 首页 131 分。一位开发者在一个月内为 M4 Mac Mini 写了 Linux GPU 驱动。技术深度文章，对 Asahi Linux/M1 系列芯片在 Linux 上的适配有直接贡献。

- **Cask**：无（技术博客/驱动开发）
- **价值判断**：不是软件，但与 Mac 硬件 + Linux 生态高度相关。对 mini 用户中关注 Linux on Apple Silicon 的人有参考价值。
- **与台账关联**：台账中 mini 是 Apple Silicon Mac，此项目影响未来 mini 装 Linux 的可行性，但不改变当前 macOS 工具链。

### 10. PI-Desktop -- 300 亿 Token 搓出来的 Agent 桌面端

小众软件发现频道热榜第一。开发者花两个月、消耗 300 亿 token 搓出一个 AI Agent 桌面端应用。定位是本地 AI agent 的桌面 GUI。

- **Cask**：待确认（小众软件论坛帖子，可能有 GitHub 仓库）
- **价值判断**：社区项目，热度高，代表"AI agent 桌面化"趋势。但 300 亿 token 的产物成熟度存疑，先观察。
- **与台账关联**：与台账中 Claude / ChatGPT 桌面端形成概念重叠，但 PI-Desktop 侧重点不同（本地 agent 调度 vs AI 聊天客户端），不替代。
