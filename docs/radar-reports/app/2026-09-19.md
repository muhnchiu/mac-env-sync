## 今日最值得关注

### 1. Agentgit — 面向 AI Agent 的 Git 托管，无需账号/Token/密钥

HN Show HN 热帖（6 分）。提供一个专为 AI Agent 设计的 Git 仓库托管服务，无需注册账号、无需 token、无需密钥即可推送代码。对 agentic 开发工作流（如 Claude Code、Codex 等自动提交场景）是有益补充，解决了 AI Agent 频繁创建 fork/PR 时 token 管理的痛点。

- **Cask**：无（Web 服务，非本地应用）
- **价值判断**：AI Agent 基础设施方向的早期探索，适合观察 Agent 生态演进，当前功能较基础。
- **与台账关联**：与台账中 Claude、Codex++ 等 AI 开发工具形成上下游关系；台账已退役 Sourcetree 转 Orca 原生 Git 流，Agentgit 补的是 Agent 侧的托管缺口，不冲突。

### 2. CRT — 本地代码审查工具，专为 Agentic 开发设计

HN Show HN 项目（github.com/imron/crt）。定位是 agentic 开发场景下的本地 code review 工具，帮助开发者在 AI Agent 大量生成代码时快速审查变更。开源，Go 实现。

- **Cask**：无（GitHub 源码，需自行编译或 go install）
- **价值判断**：在 AI 辅助编码爆发期，本地 review 工具填补了 GitHub PR review 之外的单机审查场景，实用思路。
- **与台账关联**：台账中已退役 Sourcetree，Git diff/PR review 改由 Orca 原生 + diff 标注回灌顶替。CRT 可作为 Agentic 场景的增量补充，但与现有 Orca 流程有功能重叠。

### 3. TypeSeer — macOS 全局文本自动补全（设备端运行）

HN Show HN 项目（typeseer.com）。在 macOS 上为所有文本输入框提供 on-device 自动补全，不依赖云端，隐私友好。对经常在各类应用中输入重复文本的开发者有实际效率提升。

- **Cask**：无（官网下载，尚未进入 Homebrew）
- **价值判断**：on-device 全局补全是 Alfred Snippets 的进阶版，若补全质量过硬则价值较高。
- **与台账关联**：与台账中 Alfred 5（Snippets 功能）和 github-copilot-for-xcode（代码补全）功能重叠。TypeSeer 覆盖全应用场景，但 Alfred Snippets 已满足基本需求，增量价值需验证。

### 4. Cloudflare Quick Tunnels — 免费零配置隧道，无需账号

HN 首页热帖（539 分/237 评）。Cloudflare 推出的快速隧道服务，无需注册账号即可将本地服务暴露到公网，一条命令生成临时公网 URL。对本地开发调试 webhook、分享临时预览等场景极其实用。

- **Cask**：无（Cloudflare 云服务，CLI 工具 `cloudflared` 有 brew formula：`brew install cloudflared`）
- **价值判断**：免费、零配置、大厂背书，是 ngrok 的有力替代品。
- **与台账关联**：台账中 ngrok 已在 core Brewfile（三机通用）收编。Cloudflare Quick Tunnels 功能高度重叠且免费，值得作为 ngrok 的替代或备选方案评估。

### 5. package-doctor — 开源 Python 依赖扫描器，检测被利用/未维护的包

HN Show HN 项目（github.com/binuka200/package-doctor）。扫描 Python 项目依赖，识别已知被利用漏洞或长期未维护的包。开源，CLI 工具。

- **Cask**：无（Python pip 包，`pip install package-doctor`）
- **价值判断**：供应链安全是持续刚需，轻量级 CLI 扫描器适合集成到 CI/CD。
- **与台账关联**：台账中无 Python 依赖安全扫描工具，属空白领域增量。与 mac-env-sync 的安全审计思路一致。

### 6. PGSTY Silo — MinIO Fork，无缝替代 MinIO

小众软件报道。MinIO 许可证变更后社区 fork，声称只改一行代码即可无缝替代 MinIO，保持 S3 API 完全兼容。对使用 MinIO 的项目可在不改动任何代码的情况下平滑迁移。

- **Cask**：无（Docker/二进制部署，非 macOS 桌面应用）
- **价值判断**：基础设施层面的 fork，对 MinIO 用户有直接迁移价值；非 Mac 桌面工具但值得知晓。
- **与台账关联**：台账中无 MinIO 或对象存储相关软件，属基础设施领域，与三机软件基线无直接关联。

### 7. HiDNS — 统一管理 22+ 平台域名 DNS 解析

小众软件报道。支持阿里云、DNSPod、Cloudflare 等 22+ 平台的域名 DNS 统一管理界面，解决多平台域名分散管理的痛点。

- **Cask**：无（Web 服务，发现频道产品）
- **价值判断**：对持有多个平台域名的用户有实际效率提升，但适用面较窄。
- **与台账关联**：台账中 SwitchHosts 管本地 hosts 切换，HiDNS 管云端 DNS 解析，层次不同但概念相近。非直接替代，功能互补。

### 8. Seal — 身后信件与密码传承工具，开源

HN Show HN 项目（github.com/jasonepage/Seal）。加密存储信件和密码，在你去世后自动向家人释放。开源，注重隐私。

- **Cask**：无（GitHub 开源项目）
- **价值判断**：数字遗产管理是冷门但真实的需求，开源加密方案增加信任度。
- **与台账关联**：台账中无密码管理或数字遗产类工具，属空白领域。与现有软件基线无冲突。

### 9. Xcode 27.1 Beta — 苹果开发者工具更新

HN 首页（110 分/63 评）。Xcode 27.1 Beta 发布，开发者社区关注度较高。

- **Cask**：无（Apple Developer 中心下载，台账已标注"重件，不入 cask"）
- **价值判断**：必装更新，对 p14 的 Xcode 用户直接相关。
- **与台账关联**：台账已登记 Xcode（p14 手动装，在用）。Beta 版本建议跟踪但不在生产环境升级。

### 10. macOS 27 Golden Gate 正式版新特性

少数派详细报道。macOS 27 正式版发布，仅支持 Apple Silicon，包含多项新功能。同时 watchOS 27 也带来动态应用网格、智能叠放等变化。

- **Cask**：无（系统更新）
- **价值判断**：系统级更新，三机均为 Apple Silicon，建议择机升级。
- **与台账关联**：直接影响三机软件基线。系统升级可能导致部分手动安装的软件兼容性变化，升级后需跑 `audit-manual-apps.sh` 核对。
