## 今日最值得关注

### 1. ImHex — 逆向工程十六进制编辑器（开源/免费）

HN 热文"用 ImHex 逆向未知文件格式"再度带火。内置模式匹配、反汇编、数据可视化，开发者逆向利器。

- **Cask**：`imhex`（当前 disabled，Gatekeeper 不通过，需手动从官网下载）
- **价值判断**：值得收编，虽然 cask 当前 disabled，但可从官网手动安装，后续 cask 恢复后再 adopt。
- **与台账关联**：台账新增"开发工具"类，状态标注"手动装/cask disabled"。

### 2. WebLLM — 浏览器内 LLM 推理引擎（开源/免费）

mlc-ai/web-llm，纯浏览器跑 LLM，WebGPU 加速，无需后端。

- **Cask**：无（npm/lib 项目）
- **价值判断**：适合前端/AI 方向探索，开发参考价值高。
- **与台账关联**：开发参考项目，非桌面应用，不入台账。

### 3. Sol — macOS 音乐播放器（开源/免费）

Show HN 新品，支持 Subsonic 协议，轻量快速。

- **Cask**：⚠️ `sol` 存在但是不同软件（ospfranco/sol 启动器），音乐播放器版无 cask
- **价值判断**：与网易云定位完全不同，Sol 面向本地/Subsonic 音库。
- **与台账关联**：不入台账，可共存。

### 4. PuPPT — PPT/PPTX 幻灯片渲染器（开源/Golang）

artpar/puppt，纯 Go 实现，无外部依赖，可渲染和内联编辑 PPT/PPTX。

- **Cask**：无（Go 库/CLI）
- **价值判断**：对需要程序化处理 PPT 的开发者有价值。
- **与台账关联**：不入台账。

### 5. Cinderella — GitHub 半成品仓库估值（免费/Web）

cinderella.fyi，输入 GitHub 仓库地址评估未完成项目价值。

- **Cask**：无（Web 工具）
- **价值判断**：对技术尽调、项目收购场景有趣。
- **与台账关联**：Web 工具，bookmark 即可。

### 6. NoiseVanish — 音视频背景噪声清除（付费）

noisevanish.com，"review-first"降噪流程，面向创作者。

- **Cask**：无
- **价值判断**：与已装 IINA 无功能重叠，独立降噪工具。
- **与台账关联**：暂不收编。

### 7. Mousetrapped — macOS 光标恢复工具（开源/免费）

uncSoft/Mousetrapped，解决 macOS 光标卡死/丢失问题的小工具。

- **Cask**：无（需手动编译或 release 下载）
- **价值判断**：系统级小工具，台账无同类。
- **与台账关联**：暂不入台账，有需求再装。

### 8. Meta-Stripper — 图片元数据清除（免费）

metastripper.devkram.de，批量清除图片 EXIF/元数据，保留图像质量。

- **Cask**：无
- **价值判断**：隐私场景实用，台账无专用元数据清除工具。
- **与台账关联**：可从官网下载试用，若好用考虑加入台账"效率系统"类。

### 9. CoOS — 桌面 agent 构建本地 CRM/ERP（概念/早期）

pirol.ai，AI agent 在桌面应用里动态构建 CRM/ERP 插件。

- **Cask**：无
- **价值判断**：概念超前，目前太早期。
- **与台账关联**：不收编。

### 10. CleanShot 5.0 — 截图录屏大更新（付费）

新增 Studio Mode（自动平滑缩放、鼠标跟随、剪辑）。已有 cask `cleanshot`（4.8.10），与已装 Shottr 功能重叠。

- **Cask**：`cleanshot`（可验证，已上架，付费）
- **价值判断**：Shottr 截图够用，CleanShot 的 Studio Mode 录屏缩放确实强，但付费且 Shottr 也在快速迭代。
- **与台账关联**：暂不收编，持续观察 Shottr 是否补齐录屏能力。
