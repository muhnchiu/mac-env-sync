# 软件雷达日报 2026-09-03

## 今日最值得关注

**1. ImHex — 逆向工程十六进制编辑器（开源/免费）**
HN 热文"用 ImHex 逆向未知文件格式"再度带火。内置模式匹配、反汇编、数据可视化，开发者逆向利器。⚠️ brew cask `imhex` 因 Gatekeeper 不通过已于 2026-09-01 被 disabled，当前需手动从官网下载安装。
- Cask: `imhex`（当前 disabled，需手动装）

**2. WebLLM — 浏览器内 LLM 推理引擎（开源/免费）**
mlc-ai/web-llm，纯浏览器跑 LLM，WebGPU 加速，无需后端。适合前端/AI 方向探索，开发参考价值高。无 cask（npm/lib 项目）。
- Cask: 无

**3. Sol — macOS 音乐播放器（开源/免费）**
Show HN 新品，支持 Subsonic 协议，轻量快速。已有 cask `sol`（2.1.356），但注意 cask `sol` 实际是 ospfranco/sol 启动器/命令面板，**并非同一个项目**。音乐播放器 Sol 来自 fulltimefeline.com，无 brew cask。
- Cask: ⚠️ `sol` 存在但是不同软件（启动器），音乐播放器版无 cask

**4. PuPPT — PPT/PPTX 幻灯片渲染器（开源/Golang）**
artpar/puppt，纯 Go 实现，无外部依赖，可渲染和内联编辑 PPT/PPTX。对需要程序化处理 PPT 的开发者有价值。无 cask（Go 库/CLI）。
- Cask: 无

**5. Cinderella — GitHub 半成品仓库估值（免费/Web）**
cinderella.fyi，输入 GitHub 仓库地址评估未完成项目价值。对技术尽调、项目收购场景有趣。Web 工具，无 cask。
- Cask: 无

**6. NoiseVanish — 音视频背景噪声清除（付费）**
noisevanish.com，"review-first"降噪流程，面向创作者。与已装 IINA 无功能重叠。无 cask。
- Cask: 无

**7. Mousetrapped — macOS 光标恢复工具（开源/免费）**
uncSoft/Mousetrapped，解决 macOS 光标卡死/丢失问题的小工具。开源轻量。无 cask（需手动编译或 release 下载）。
- Cask: 无

**8. Meta-Stripper — 图片元数据清除（免费）**
metastripper.devkram.de，批量清除图片 EXIF/元数据，保留图像质量。隐私场景实用。无 cask。
- Cask: 无

**9. CoOS — 桌面 agent 构建本地 CRM/ERP（概念/早期）**
pirol.ai，AI agent 在桌面应用里动态构建 CRM/ERP 插件。概念超前，目前太早期。无 cask。
- Cask: 无

**10. CleanShot 5.0 — 截图录屏工具（付费）**
CleanShot 5.0 大更新加入 Studio Mode（自动平滑缩放、鼠标跟随、剪辑）。已有 cask `cleanshot`（4.8.10）。与已装 Shottr 功能重叠。
- Cask: `cleanshot`（可验证，已上架）

## 与已装重复

| 新品 | 已装软件 | 重叠度 | 判断 |
|---|---|---|---|
| CleanShot 5.0 | Shottr | 高 | Shottr 截图够用；CleanShot 的 Studio Mode 录屏缩放确实强，但付费且 Shottr 也在快速迭代。**不值得替换**，除非录屏需求频繁。 |
| Sol（音乐播放器） | 网易云音乐 | 低 | 定位完全不同，Sol 面向本地/Subsonic 音库，网易云是流媒体。可共存。 |
| Meta-Stripper | 无直接竞品 | — | 台账无专用元数据清除工具，属于新能力补充。 |
| Mousetrapped | 无直接竞品 | — | 系统级小工具，台账无同类。 |

## 建议动作

1. **ImHex**：值得收编。虽然 cask 当前 disabled，但可从官网手动下载安装，后续 cask 恢复后再 adopt。台账新增"开发工具"类，状态标注"手动装/cask disabled"。
2. **CleanShot 5.0**：已有 cask `cleanshot`，但与 Shottr 重叠，**暂不收编**。持续观察 Shottr 是否补齐录屏能力，若不能再看 CleanShot。
3. **Meta-Stripper**：轻量工具，可从官网下载试用。若好用考虑加入台账"效率系统"类。无 cask，暂不入 Brewfile。
4. **WebLLM**：开发参考项目，非桌面应用，不入台账。值得 bookmark 关注技术方向。
5. **其余项目**（Sol/PuPPT/Cinderella/NoiseVanish/CoOS/Mousetrapped）：均为小众或早期产品，暂不收编。持续观察。
