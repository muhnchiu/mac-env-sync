## 今日最值得关注

### 1. Sonic Pi — 用代码现场编曲/做音乐（HN 首页 156 分）

老牌开源工具，用代码实时编曲/做音乐，今天被 HN 重新顶上热榜。免费、开源、维护活跃。

- **Cask**：`sonic-pi`（已验证，当前版本 5.0.0）✅
- **价值判断**：今日唯一验证通过的标准 cask 新品。
- **与台账关联**：可收入台账，建议先单机试用（如 p14——那台有 GarageBand/音乐向环境）。

### 2. slotstream — 在 48GB Mac 上跑 104GB Qwen3.8 模型（Show HN 210 分）

靠 slot/缓存复用把超大模型塞进小内存，实测 ~12 tok/s。开源，GitHub: carloslfu/slotstream。

- **Cask**：无（已验证），需源码构建
- **价值判断**：对本地模型玩家是真正的硬货。
- **与台账关联**：不是 LM Studio / Ollama 的替代，是互补——它解决"模型比内存大"的场景。p14 下次跑大模型撞内存墙时再手动试。

### 3. WhisprNote — macOS 本地语音输入 + 自动补全（Show HN）

不上云、不用注册账号，隐私优先的听写工具。

- **Cask**：无（已验证）
- **价值判断**：方向对口（语音转文字本地化），但较新，成熟度待观察。
- **与台账关联**：若对隐私敏感或系统听写不够用可试。

### 4. Pairmark — 让 Claude Code 和 Codex 赛跑对打（Show HN）

在你的 repo 上让两个 coding agent 盲评交叉裁决的开源 CLI。

- **Cask**：无（已验证），GitHub: Hemanshu-Upadhyay/pairmark
- **价值判断**：正在用两个 coding agent 的人可以拿来做选型依据。
- **与台账关联**：一次性试用价值，不入台账。如果近期在纠结 Claude Code vs Codex 的场景分工，可临时 clone 跑一轮对比。

### 5. CoolDeck — Coolify 的键盘优先终端 UI（Show HN）

- **Cask**：无（已验证）

### 6. Terraplane — webhook 触发的 Terraform PR 流（Show HN）

- **Cask**：无（已验证）

### 7. CleanShot X 5.0 — 截图录屏大更新（Product Hunt + 小众软件）

新增 Studio Mode：自动平滑缩放、鼠标跟随、更丰富剪辑。付费。

- **与台账关联**：不值得替换，现有免费组合更契合台账"能 brew 就 brew"的原则。
