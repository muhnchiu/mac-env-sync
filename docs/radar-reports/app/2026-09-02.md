# 软件雷达日报分析 · 2026-09-02

> 数据源：HN 首页/Show HN、Product Hunt、少数派、小众软件；台账：mac-env-sync/docs/manuals/app-inventory.md
> cask 验证：本日逐项跑过 `brew info`，结论如实标注

## 【今日最值得关注】

1. **Sonic Pi**（HN 首页 156 分）— 用代码现场编曲/做音乐的老牌开源工具，今天被 HN 重新顶上热榜。免费、开源、维护活跃。
   ✅ **有官方 cask：`sonic-pi`**（已验证，当前版本 5.0.0）。今日唯一验证通过的标准 cask 新品。

2. **slotstream**（Show HN 210 分）— 在 48GB 内存的 Mac 上跑 104GB 的 Qwen3.8 模型（~12 tok/s），靠 slot/缓存复用把超大模型塞进小内存。开源，GitHub: carloslfu/slotstream。对本地模型玩家是真正的硬货。
   ❌ 无 cask/formula（已验证），需源码构建。

3. **WhisprNote**（Show HN）— macOS 本地语音输入 + 自动补全，不上云、不用注册账号，隐私优先的听写工具。方向对口（语音转文字本地化）。
   ❌ 无 cask（已验证）；较新，成熟度待观察。

4. **Pairmark**（Show HN）— 在你的 repo 上让 Claude Code 和 Codex 赛跑对打、盲评交叉裁决的开源 CLI。正在用两个 coding agent 的人可以拿来做选型依据。
   ❌ 无 cask（已验证），GitHub: Hemanshu-Upadhyay/pairmark。

5. **CoolDeck**（Show HN）— Coolify 的键盘优先终端 UI（开源，Go）。只有在自托管 Coolify 时才有意义。
   ❌ 无 cask（已验证）。

6. **Terraplane**（Show HN）— webhook 触发的 Terraform PR 流，runner 跑在你自己的网络里。开源基础设施工具，适合有 IaC 场景的团队。
   ❌ 无 cask（已验证）。

7. **Cleanshot X 5.0**（Product Hunt + 小众软件双上榜）— 大版本更新，屏幕录制新增 Studio Mode：自动平滑缩放、鼠标跟随、更丰富剪辑。截图录屏领域的标杆更新，但付费。
   ❌ 无 cask（`cleanshot-x` 已验证不存在，brew 已不收录）。

8. **Weedout**（Show HN 143 分）— Safari 扩展，隐藏 YouTube 上标注「AI 生成」的视频。小而美的信息流净化。
   ❌ 无 cask，Safari 扩展形态。

9. **Camsend / Campsend**（Show HN）— 开源版 WeTransfer 大文件传输。注意是 Web 服务而非本地 app，可自托管。
   ❌ 无 cask（已验证）。

10. **Aster Disk**（Show HN）— Mac 磁盘占用可视化，「什么在占空间、什么可以安全删」，仅 Mac App Store 分发。
    ❌ 无 cask（已验证），mas 专属。

## 【与已装重复】

- **CleanShot X vs Shottr + Kap**：完全重叠。截图（Shottr）+ 录屏（Kap）组合已覆盖日常，CleanShot 5.0 的 Studio Mode（自动缩放/鼠标跟随）确是增量亮点，但它付费且已无 cask。**不值得替换**，现有免费组合更契合台账「能 brew 就 brew」的原则。
- **Aster Disk vs DaisyDisk + CleanMyMac**：完全重叠（磁盘可视化 + 清理两样都在用）。**不值得收编**。
- **slotstream vs LM Studio / Ollama（p14）**：不是替代关系，是互补——它解决「模型比内存大」的场景。如果 p14 本地模型遇到内存瓶颈，值得试。
- **WhisprNote vs 系统听写**：部分重叠，差异在本地化 + 自动补全 + 全局无云端。若对隐私敏感或系统听写不够用可试。

## 【建议动作】

1. ✅ **收编 Sonic Pi**（唯一符合「免费+开源+官方 cask」全条件的）：台账加一行（token `sonic-pi`，建议先单机试用，如 p14——那台有 GarageBand/音乐向环境）→ `Brewfile.<host>` 加条目 → install → push。
