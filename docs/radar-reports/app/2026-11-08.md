## 今日最值得关注

### 1. OpenSSH 十年老漏洞：超长密码绕过认证

据媒体报道，OpenSSH 存在一个隐藏约 10 年的严重安全漏洞（CVE-2026-123158）。攻击者无需知道真实密码或私钥，只需输入超长字符串，就可能绕过 Linux 账户的密码锁定机制，直接登录系统甚至获得 root 权限。这是当前使用 OpenSSH 进行远程管理的所有 Linux/macOS 系统的安全隐患。

- **Cask**：无（系统自带 OpenSSH，需通过 `brew upgrade openssh` 或系统更新升级）
- **价值判断**：严重安全漏洞，需确认系统是否已打补丁，否则存在被远程入侵风险。
- **与台账关联**：三台 Mac 及远端 Linux 服务器（含多乐士测试环境 172.102.10.93）均依赖 SSH，需检查版本并升级。
- **来源等级**：media
- **来源名称**：小众软件 / OpenSSH

### 2. Itsycal 更新 0.28.0：支持显示苹果提醒事项

Itsycal 是一款经典的 macOS 菜单栏日历工具，小巧免费，点击菜单栏即可查看日历和日程。0.28.0 版本新增加了对苹果"提醒事项"（Reminders）的支持，可以在菜单栏同时查看日程和待办事项。有 Homebrew cask 可安装。

- **Cask**：`itsycal`（Homebrew cask 可用）
- **价值判断**：轻量免费，补齐了菜单栏同时查看日历和待办的空白，可与 Reminder 应用替代部分场景。
- **与台账关联**：台账未登记 Itsycal，属于新功能菜单栏工具，可试用后决定是否收编。
- **来源等级**：ecosystem
- **来源名称**：小众软件 / Homebrew

- **Cask**：未确认（未查到 Homebrew cask，需手动安装或等待收编）
- **价值判断**：刘海屏利用工具中有潜力，但功能与现有 Alfred/Obsidian 等有重叠，暂不收编。
- **与台账关联**：台账无同类工具，属新增观察项。

### 4. Claude Code "Don't Ask Again" 功能导致密码泄露

Hacker News 报道（115 分/87 评），apiiro 安全团队发现 Claude Code 的"不再询问"（Don't Ask Again）功能导致用户在 1,122 个公开 GitHub 仓库中泄露了密码和敏感凭证。这暴露了 AI 编程工具在安全边界处理上的系统性风险。

- **Cask**：无（Claude Code 为 CLI 工具）
- **价值判断**：AI 编程工具使用安全问题，所有使用 Claude Code 的用户需检查是否误提交凭证。
- **与台账关联**：台账中 Claude 为手动安装（mini 在用），需确认本地配置是否存在类似泄露风险。
- **来源等级**：ecosystem
- **来源名称**：Hacker News / apiiro

### 7. 小众软件：QNAP NAS 漏洞 Plex2Shell 正被利用

据媒体报道，QNAP 威联通 11 月 6 日发布安全公告，警告黑客正在利用名为 Plex2Shell 的漏洞链攻击运行 Plex Media Server 的 NAS 设备，已有 NAS 疑似遭入侵。

- **Cask**：无（NAS 服务端安全问题）
- **价值判断**：家中 NAS 若运行 Plex，需立即检查是否受影响并升级。
- **与台账关联**：台账中未登记 QNAP/Plex，属外部环境安全提醒。
