## 今日最值得关注

### 1. Tin: full-text search for Postgres

PlanetScale 推出的 Postgres 全文搜索引擎，号称比 pg_trgm 快数十倍，基于 BM25 排序。开源，对使用 Postgres 的后端项目有直接价值。HN 185 分热度不错。

- **Cask**：无（Postgres 扩展，通过 pgx 或源码编译安装，非桌面应用）
- **价值判断**：如果项目有 Postgres 全文搜索需求，值得评估；PlanetScale 出品质量有保障。
- **与台账关联**：台账无数据库搜索引擎类工具，与 DBX（数据库客户端）互补但不重叠。

### 2. CUA-S1: A System One Model for Computer Use

GitHub 开源项目 trycua/cua，提供"系统一"风格的计算机操作 AI 模型（快思考路径）。HN 59 分/7 评，Show HN 新品。开源可本地部署。

- **Cask**：无（Python/模型项目，pip 安装）
- **价值判断**：AI 操作电脑方向持续火热，开源模型可本地跑，对比 Claude Computer Use 有差异化（System One 快思考）。
- **与台账关联**：与台账中 Claude、ChatGPT、Codex++ 等 AI 桌面助手方向一致，但定位为开源替代方案。

### 3. Rubrol: Sub-10ms PDF engine using Typst

用 Typst 替代 Headless Chrome 做 PDF 渲染，号称亚 10ms 延迟。Show HN 新品，适合需要高性能 PDF 生成的后端场景。

- **Cask**：无（服务端引擎，非桌面应用）
- **价值判断**：对于有 PDF 批量生成需求的后端服务有实际意义，Typst 生态值得关注。
- **与台账关联**：台账无 PDF 生成工具，与 WPS Office 的 PDF 阅读功能不重叠。

### 4. Kibana-agent: query Kibana logs from CLI

GitHub 开源项目 hyzyla/kibana-agent，让你从命令行直接查询 Kibana 日志，无需打开浏览器翻界面。Show HN 新品。

- **Cask**：无（npm/pip CLI 工具）
- **价值判断**：对使用 ELK 栈的团队非常实用，减少切到浏览器翻 Kibana 的摩擦。不过当前工作环境以 Azure Monitor + App Insights 为主，直接价值有限。
- **与台账关联**：台账无日志查询 CLI 工具；Azure 告警邮件监控流程是独立 IMAP 链路，不经过 Kibana。

### 5. ENZO: open source locally usable full fledged AI platform

GitHub 开源项目 theguysudo/ENZO，目标是做完整的本地 AI 平台（对话/Agent/工具链），可离线运行。Show HN 7 分/1 评。

- **Cask**：无（自部署平台）
- **价值判断**：本地 AI 平台方向持续有新项目，但成熟度和实用性参差不齐。ENZO 还很早期，跟踪观察。
- **与台账关联**：与台账中 Ollama、LM Studio、Cherry Studio 定位重叠，但 ENZO 更偏"全栈平台"而非模型运行器。

### 6. Jev-lint: semantic linter with plain English rules

GitHub 开源项目 zdenham/jev-lint，用自然语言描述规则做语义 lint。Show HN 4 分。属于 Jev 生态（近期多个 Jev 相关项目上 HN）。

- **Cask**：无（CLI 工具）
- **价值判断**：自然语言规则 lint 思路有趣，但 Jev 生态整体还很早期，实用性待验证。
- **与台账关联**：台账无 lint 类工具（代码 lint 走编辑器内置），不直接相关。

### 7. HTTPS Capture (限免)

iOS/macOS 抓包与 API 调试工具，支持 HTTPS 解密、局域网抓包、URL 重写、Mock 等。小众软件推荐，App Store 终身限免（非国区）。

- **Cask**：无（App Store 应用）
- **价值判断**：功能与 Proxyman 高度重叠，但限免+跨平台（含 iOS）是差异点。如果需要在 iPhone 上抓包有额外价值。
- **与台账关联**：与台账中 Proxyman（mini+p13 在用）功能重叠度高。已有 Proxyman 的情况下收编价值不大，除非需要 iOS 抓包。

### 8. HiDNS: 统一管理 22+ 平台域名 DNS 解析

支持阿里云、DNSPod、Cloudflare 等 22+ 平台的 DNS 统一管理工具。小众软件发现频道推荐。

- **Cask**：无（Web 应用或自部署）
- **价值判断**：对有多平台域名管理需求的人非常有用。当前管理域名不多时收益有限。
- **与台账关联**：台账无 DNS 管理工具，与 SwitchHosts（hosts 管理）定位不同。

### 9. PGSTY Silo: MinIO Fork, 无缝替代 MinIO

从 MinIO fork 的开源 S3 对象存储，只改一行代码实现无缝替代。适合 MinIO 停更后继续使用已有项目。小众软件推荐。

- **Cask**：无（服务端存储）
- **价值判断**：MinIO 生态的重要替代方案。如果有项目依赖 MinIO，值得收藏备用。
- **与台账关联**：台账无对象存储相关工具。与 oss-browser（阿里云 OSS 客户端）不重叠。

### 10. Set: offline Markdown note-taking with device-to-device sync

离线 Markdown 笔记应用，支持设备间直接同步（不走云）。Show HN 新品，2 分。

- **Cask**：无（独立应用，Web/Desktop）
- **价值判断**：离线+P2P 同步思路好，但 Obsidian + iCloud 同步已经很好用，迁移成本高。
- **与台账关联**：与台账中 Obsidian（三机在用）、marktext（停更）定位重叠。Obsidian 生态更成熟，不收编。

## 与已装重复 / 功能重叠

| 新品 | 台账中重叠软件 | 重叠度 | 判断 |
|------|---------------|--------|------|
| HTTPS Capture | Proxyman | 高 | 已有 Proxyman，除非需要 iOS 抓包否则不收编 |

| ENZO (AI Platform) | Ollama / LM Studio / Cherry Studio | 中 | 定位偏全栈平台，但现有组合更灵活 |

| PGSTY Silo | oss-browser | 低 | 一个是存储引擎，一个是客户端，不重叠 |

## 建议动作

**立即试用：**
1. Tin (Postgres 全文搜索) - 如果当前项目有 PG 全文搜索场景，找个测试库跑一下基准对比
2. Kibana-agent - 如果有 Kibana 环境可以装一个 CLI 查询工具，日常排查更顺手

**跟踪观察：**
- CUA-S1: AI 操作计算机方向持续演进，关注开源模型进展
- Rubrol: Typst 生态值得长期关注，PDF 高速渲染有后端价值
- PGSTY Silo: MinIO 替代方案，有需要时备用

**收藏：**
- HiDNS (多平台 DNS 管理，需要时可用)
- 小众软件提到的 10 款 GitHub 工具合集中 Atuin（shell 命令历史搜索同步），值得单独看

**不收编：** HTTPS Capture（Proxyman 已覆盖）、Set（Obsidian 已覆盖）、ENZO（现有 AI 工具组合更灵活，平台太早期）、Jev-lint（Jev 生态早期，实用性未验证）
