## 今日最值得关注

### 1. Sill -- 住在壁纸上的 macOS 系统监控

开源 MIT 许可的 macOS 系统监控工具，以壁纸上一条波浪曲线展示过去 15 分钟的系统负载：波形是 CPU 负载，密度是内存占用，颜色是负载程度。仅 1.2MB，空闲时仅占 0.27% 单核、13MB 内存，无需任何权限或特权辅助进程。由 PTthe13 开发，GitHub 开源，macOS 14+ 支持 Apple Silicon 和 Intel。签名了 Developer ID 但未公证，首次启动需手动放行。

- **Cask**：无（GitHub Releases 下载 dmg，[github.com/PTthe13/sill](https://github.com/PTthe13/sill)）
- **价值判断**：极致轻量、零权限、视觉优雅，是菜单栏监控的有趣替代方案。
- **与台账关联**：台账已有 `stats`（core，菜单栏系统监控）和 `macmon`（core，终端侧）。Sill 走完全不同的视觉路线（壁纸叠加），不冲突但功能重叠。

### 2. Lumae -- 免费 macOS 屏幕录制/截图工具，支持 MCP 编辑

Show HN 新品，免费 macOS 屏幕录制和截图工具。核心卖点：录制后可自动生成缩放、光标跟踪、字幕，并支持通过 MCP（Model Context Protocol）让 AI Agent 编辑录制片段。开源，GitHub 发布 dmg。当前 v0.4.1，尚在早期阶段。

- **Cask**：无（GitHub Releases 下载 dmg，[lumae.app](https://lumae.app)）
- **价值判断**：MCP 集成是亮点，符合 AI 原生工作流趋势；免费开源有吸引力。
- **与台账关联**：台账已有 `shottr`（截图）和 `kap`（录屏 GIF）。Lumae 的差异化在于 AI 辅助编辑和 MCP 接入，但功能覆盖面不如 Shottr/Kap 成熟。

### 3. Termique -- 跨平台 SSH 客户端，端到端加密同步

Show HN 新品，SSH 客户端，支持 macOS/Windows/Linux/iOS 全平台。核心特性：多会话终端、SFTP、端口转发、SSH 密钥管理、命令审计日志、AI 终端助手（上下文感知当前主机）。端到端加密同步（AES-GCM），服务器只存密文。Pro 计划 $5/月，是 Termius 的三分之一价格。安全设计上强调服务器无法读取凭据。

- **Cask**：无（官网下载，[termique.app](https://termique.app)）
- **价值判断**：跨平台同步+安全设计不错，但与 Termius 定位高度重叠且更贵（Termius 已在 core）。
- **与台账关联**：台账已有 `termius`（core，账号云同步）。Termique 是直接的竞品，价格略低但生态成熟度远不如 Termius。

### 4. Konode -- 开源浏览器同步扩展

小众软件推荐，开源浏览器同步扩展，支持所有 Chromium 系浏览器和 Firefox，甚至跨浏览器同步。不提供云存储，使用用户自有的 WebDAV/Nextcloud/坚果云等作为后端。支持同步标签页、扩展、浏览历史、书签、密码、Cookie 等。数据加密后传输，服务端只存密文。自动同步、冲突解决机制完善。

- **Cask**：无（浏览器扩展，[GitHub 开源](https://github.com/)）
- **价值判断**：自托管同步方案解决了 Chrome 同步不可用的问题，对国内用户尤其实用。
- **与台账关联**：台账无浏览器同步工具条目。Chrome/Edge 均在 core 但同步依赖各自账号体系。Konode 可作为补充层。

### 5. MSSH -- 5MB 单文件 SSH 客户端

小众软件推荐，面向开发者和运维的轻量 SSH 桌面客户端。多会话、内置 SFTP、快捷键手感接近 Xshell。资料库本地优先（默认完全本地，不注册不联网），可选接入 NAS 或本地服务端做多机同步。绿色便携，解压即用，7z 包约 5MB，单文件约 16MB。当前 v0.4.0 公测，免费。支持 Windows 10/11 和 macOS。

- **Cask**：无（官网下载，[maple-ssh](https://www.appinn.com/maple-ssh/)）
- **价值判断**：极致轻量、本地优先、离线可用，适合内网/无公网场景。
- **与台账关联**：台账 SSH 客户端已有 `termius`（core，云同步）和 `transmit`（手动，堡垒机）。MSSH 走本地优先路线，与 Termius 的云端同步路线互补，但 Transmit 已覆盖堡垒机场景。

### 6. Lab -- 本地优先的无服务端 LLM 浏览器客户端

Show HN 新品，本地优先（local-first）、无服务端的浏览器 LLM 客户端。直接在浏览器中运行，连接本地或远程 LLM API，无需后端服务。适合需要轻量级 LLM 交互界面的开发者。

- **Cask**：无（Web 应用，[labstudio.tech](https://labstudio.tech)）
- **价值判断**：本地优先理念好，但桌面端已有 Cherry Studio/LM Studio 等成熟方案。
- **与台账关联**：台账 p14 已有 `cherry-studio`、`lm-studio`、`ollama` 等 LLM 客户端。Lab 覆盖面窄，增量价值有限。

### 7. YazSes -- 离线按住说话的语音听写工具

Show HN 新品，离线、按住说话（hold-to-talk）的语音听写工具，支持 Linux/macOS/Windows。开源（GitHub），跨平台。核心场景：不需要在线服务、不需要常驻后台的简单语音转文字。

- **Cask**：无（GitHub 开源，[github.com/MSKazemi/yazses](https://github.com/MSKazemi/yazses)）
- **价值判断**：离线听写有特定场景价值，但 macOS 自带听写功能已覆盖大部分需求。
- **与台账关联**：台账无语音听写专用工具。macOS 系统自带听写（Function 键触发）可用。

### 8. UPDF AI Agent -- PDF 编辑器内嵌 AI 代理

小众软件推荐，UPDF 在 PDF 编辑模式中内嵌了 AI Agent 功能：选中文本直接调用 AI 编辑，可改写、翻译、总结等。将 AI Agent 概念融入 PDF 编辑器，而非仅做 AI 阅读（如现有 ChatPDF 类工具）。支持保留原始布局的 PDF 翻译（PDFidelity 功能）。

- **Cask**：无（独立应用，[updf.com](https://www.updf.com/)）
- **价值判断**：AI 直接改 PDF 文本是有意思的切入点，但 UPDF 是商业软件且与现有工作流关联不大。
- **与台账关联**：台账无 PDF 编辑器条目（WPS/Keynote 覆盖部分场景）。如需 PDF AI 处理可作为候选。

### 9. Build Visualizer for Bun -- 理解编译时间的可视化工具

HN 首页，开发者用 Bun 构建了一个编译时间可视化工具，帮助理解大型项目的编译瓶颈。Web 端工具，分析构建数据并可视化展示各阶段耗时。

- **Cask**：无（Web 工具，[lalitm.com/post/buildprof](https://lalitm.com/post/buildprof/)）
- **价值判断**：构建可视化是小众但实用的开发辅助工具，适合前端/全栈开发者。
- **与台账关联**：台账无构建分析工具条目。VS Code Insiders 是主力编辑器，此为 Web 工具不冲突。

### 10. Real-SWE -- 企业级真实代码库 AI 模型基准测试

HN 首页，在私有、真实的企业级代码库上对 AI 模型进行基准测试。区别于 SWE-bench 等公开数据集，使用真实企业代码库测试模型的实际工程能力。

- **Cask**：无（Web 服务，[withspecific.com/benchmarks/real-swe](https://withspecific.com/benchmarks/real-swe)）
- **价值判断**：对评估 AI 编程助手有参考价值，但非软件工具。
- **与台账关联**：台账已有 `claude`、`chatgpt`、`codex` 等 AI 编程工具。此为评测参考，非需安装的软件。
