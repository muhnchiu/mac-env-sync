## 今日最值得关注

### 1. Hydra -- 开源代理式终端，带 PTY 守护进程

Show HN 上热度最高的终端类项目（8分/3评）。Hydra 提供了一个带 PTY daemon 的代理式终端，支持本地运行、可被 AI agent 调用，定位类似"AI 原生终端"。开源、Rust 实现，GitHub 可用。

- **Cask**：无（GitHub 开源项目，需源码安装或 cargo install）
- **价值判断**：将终端与 AI agent 深度绑定的方向值得跟踪，PTY daemon 设计解决了 agent 长会话保活问题。
- **与台账关联**：与台账中 Ghostty（主力终端）、iTerm2、Warp（待退役）形成对照。Hydra 走的是"终端即 agent 运行时"路线，与 Ghostty 的纯终端定位不同，属于补充而非替代。

### 2. Desert Ant Labs -- 本地快速端侧 AI 模型

HN 首页 377 分/90 评，Meta（原 Facebook AI）团队介绍的新型本地端侧模型方案，强调在设备上快速运行。对关注本地 AI 推理的开发者有参考价值。

- **Cask**：无（研究项目/SDK，非桌面应用）
- **价值判断**：端侧 AI 推理是趋势，但目前更偏研究性质，落地工具链不成熟。
- **与台账关联**：与台账中 Ollama（p14）、LM Studio（p14）属同一赛道。如果 Desert Ant Labs 出桌面端或 CLI 工具，可作为 Ollama 的替代观察。

### 3. Ambient Context v1.0.0 -- 为 AI 助手补全上下文

Show HN 新品，GitHub 开源（dragthelake/ambient-context），发布 v1.0.0。定位是为 AI 编程助手提供缺失的项目上下文，解决 AI 助手"看不到全局"的痛点。

- **Cask**：无（GitHub 开源项目，大概率 CLI/插件形态）
- **价值判断**：上下文不足是当前 AI 编程的核心瓶颈之一，v1.0.0 说明已可用于生产。
- **与台账关联**：与台账中 Claude（桌面客户端）、VS Code Insiders + Copilot 的 AI 编程工作流直接相关。可作为 Claude Code / Copilot 的上下文增强层试用。

### 4. EmbedFlow -- 无需重新嵌入即可升级嵌入模型

Show HN（5分/1评），GitHub 开源（arnsri33/embedflow）。解决 RAG 系统升级 embedding 模型时需要全量重新嵌入的痛点，支持模型迁移映射。

- **Cask**：无（Python 库/CLI 工具）
- **价值判断**：RAG 基础设施工具，解决实际工程痛点（换模型代价巨大）。如果做过 RAG 会有共鸣。
- **与台账关联**：台账无直接重叠。属后端/AI 工程工具，对三机软件基线无直接影响，但开发实践中实用。

### 5. binthere -- 临时安全分享密码和 API 密钥

小众软件推荐。解决"把密码/API Key 发给别人但不想留在聊天记录里"的问题，类似 Pastebin 但面向密钥场景，阅后即焚式设计。

- **Cask**：无（Web 服务）
- **价值判断**：解决日常开发协作中的真实痛点，比直接贴微信/飞书安全得多。
- **与台账关联**：与台账中 SwitchHosts（管理 hosts 含敏感信息）、Transmit（堡垒机凭据）场景相关。属协作安全工具，轻量实用。

### 6. iTerm2 Buddy -- iTerm2 的 iOS 客户端

小众软件报道。iTerm2 推出 iPhone 客户端，但不是"手机上的终端"，而是连接到 macOS 的辅助终端，用于远程触发 Mac 上的终端任务。

- **Cask**：无（iOS 应用，App Store 渠道）
- **价值判断**：对 iTerm2 重度用户有吸引力，可在手机端触发 Mac 终端任务。但需要 Mac 常开。
- **与台账关联**：台账中 iTerm2 三机在装（待收编）。iTerm2 Buddy 是官方延伸产品，不改变 iTerm2 本身的收编计划。可选择性试用。

### 7. Computer-use MCP Server -- Rust 实现的跨平台电脑操控 MCP 服务

Show HN 新品，GitHub 开源（zavora-ai/computer-use-mcp），Rust 实现。提供跨平台的电脑操控 MCP 服务端，可被 AI agent 调用执行屏幕操作。

- **Cask**：无（GitHub 开源，Rust 项目）
- **价值判断**：MCP 生态中 computer-use 能力是刚需，Rust 实现性能和跨平台有保障。
- **与台账关联**：与 OpenClaw 的 computer-use skill 直接相关。可作为现有 computer-use 方案的开源替代或补充观察。

### 8. Pushin -- 无美国参与的欧洲 Git 托管服务

小众软件推荐。来自欧洲的 Git 代码托管平台，强调数据不经过美国司法管辖，适合对数据主权有要求的团队。

- **Cask**：无（Web 服务）
- **价值判断**：对有 GDPR 合规需求或数据主权敏感的团队有价值。日常开发可作 GitHub 的镜像备份。
- **与台账关联**：台账中 git 仓库管理以 GitHub 为主（Sourcetree 已退役，改用 Orca + GitHub）。Pushin 可作为 GitHub 的镜像/备份方案观察。

### 9. SearchEngineSuite -- 源码搜索引擎

Show HN（3分），GitHub 开源（mrmcsoftware/SearchEngineSuite）。定位是"快速在源码中搜索内容的搜索引擎"。

- **Cask**：无（开源工具）
- **价值判断**：代码搜索是高频需求，但 ripgrep/fd 已很成熟，增量价值需验证。
- **与台账关联**：与现有 ripgrep（终端搜索）、VS Code 全局搜索功能重叠。可作为轻量替代方案观察，暂不需要收编。

### 10. Botbin -- AI Agent 工件 Pastebin

Show HN 新品（botbin.io），定位是"AI agent 工件的粘贴板"，用于分享 AI agent 运行产生的中间结果、日志、配置等。

- **Cask**：无（Web 服务）
- **价值判断**：AI agent 工作流越来越多，产物分享是真实需求。轻量工具，门槛低。
- **与台账关联**：与 Claude/AI agent 工作流相关。属辅助工具，不影响台账基线。
